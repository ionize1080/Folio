# Folio PDF Studio 1.0 RC1 P2

适用：此前交付的 **1.0.0 RC1 / RC1 P1 Windows x64 完整运行包**。已包含 P1 的书签拆分修复，无需先装 P1。

## 安装

1. 保存文档，完全退出 Folio。
2. 找到 Folio.exe 所在目录，备份 `resources/app.asar` 和 `resources/native` 目录。
3. 解压本补丁，将其中的 **resources 文件夹合并复制** 到 Folio.exe 旁的同名目录，替换同名文件。**本次不能只替换 app.asar，也不要先删除旧 resources。**
4. 启动程序，界面版本应显示 **1.0.0 RC1 P2**。

不必重新下载 Electron、Python 或离线 AI 模型。若需回退，退出程序后还原上述备份。Windows 文件属性中的数字版本仍可为 1.0.0.0，以应用界面的 P2 为准。

## 修复内容

- **识别后不能编辑**：修复把所有带裁剪文字都设成只读的问题。能证明矩形裁剪完整包含文字时，允许段落替换；仍拒绝真正切掉字形、复杂曲线裁剪及不能可靠映射的对象。你提供的年报第 12 页，599 个文字对象可进入段落编辑，几何分组得到 4 个候选段落。
- **两端对齐**：中文按字符边界分配间距，英文按词间空格分配；段落末行不拉伸。调整直接写入 PDF 字位，预览、选区和保存输出使用同一结果。兼容中英混排、字体切换及同页不同宽度的接续框。
- **栏宽与缩进**：去掉自动给识别段落添加的约一个字宽的右侧余量；切换对齐方式保持当前栏宽，必要时向下扩展。显式选择向右扩展仍可增加宽度。修复首行缩进选择器未被排版引擎识别的问题。
- **字体列表**：单行字体名称以自身字体显示，取消示例行、字体样式及覆盖说明行；详细信息保留在悬停提示。去重、缓存目录、延迟搜索，仅加载可见嵌入字体的名称字形。系统字体直接使用本机字族；字体请求走独立进程，不再为每一行传送和临时写入整份 PDF。嵌入子集若缺少名称字符，缺失字形仍由系统字体显示。
- **OCR 校对闪烁、跳回页首**：阻止识别框点击冒泡到整页导航；同页点击不重新加载，不清空选中条目。明确点击后的定位不会被程序触发的连续滚动覆盖，实际滚轮浏览会恢复自动换页。
- **OCR 选区过高**：文字层以字体的上升部、下降部和完整行度量拟合识别框，不再拿句号、短横线等字形的微小墨迹高度作为缩放基准。
- **内置字体完整性**：取回的 RC1 源码包内 `NotoSansSC.ttf` 不完整，已用包内完整可变字体源重新生成静态字体，包含 30,890 个码位；补丁附带完整替换文件。

## 已完成的验证

- 74 项 JavaScript 核心及联动测试通过，包含原有 P1 书签拆分回归，以及新增 3 项 OCR 连续浏览事件测试。
- 新增 8 组原生输出验证：中文/英文/混排两端对齐、首行缩进与段落末行、不同栏宽接续、裁剪安全判断、字体及小型名称预览、OCR 文字层几何，以及两份用户 PDF 的编辑保存重开。
- 年报第 12 页、年鉴第 9 页完成实际编辑、保存、重开和渲染检查；未编辑的第一页，以及编辑页的页眉/页脚抽查区域像素一致。
- 16 pt OCR 测试行包含中文、句号、短横线、英文升降部、混排、倾斜和纵向文字。PyMuPDF 字符框不超过 17 pt；随程序使用的 PDF.js 读出的文字高度为约 11.1–11.3 pt。隐藏文字层没有改变页面像素。
- 原有 0.9 原生回归的 5 组场景通过，覆盖表格行高、叠放、原页面前后层级、溢出及字体替代。
- 补丁 app.asar 的变更文件与源码逐一核验，其他文件与 P1 逐一哈希对比；原生模块及字体、ZIP 均核验。

**验证边界**：本次未在 Windows 真机启动，也未完成 Chromium 全界面回归。当前环境没有可运行的 Chromium，下载未成功。OCR 联动采用实际控制器的事件/布局宿主测试，不等同于完整浏览器视觉验收；字体列表在你的 Windows 字体库上的实际加载速度需使用后确认。本次测试重点是排版、写入和校对联动，未重新跑 OCR 识别模型的准确率或速度测试。

## 已保存文件的注意事项

新补丁会修正之后重新生成的 OCR 文字层。已经保存进其他 PDF 的旧文字层不会仅因升级而自动改变；如仍出现大选区，请从原始 PDF 重新识别并应用，或在仍保有原文与 OCR 校对结果的工作会话中重新应用。

已有的编辑文本框保留其存储宽度；新版识别段落才使用去掉额外右侧余量的初始宽度。旋转、非零原点、特殊单位及复杂嵌套对象的原有编辑范围限制仍然存在。

源码补丁可覆盖到 RC1 或 P1 源码根目录；运行包补丁用于 Folio.exe 所在目录，二者不要混用。
