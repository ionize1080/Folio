# Folio PDF Studio 1.7.2

本版重點保證已應用修改、預覽與最終 PDF 一致。

- 追加 PDF 保留文字、表格、圖像和 OCR 修改，包括同一會話先保存再追加；保存、追加和頁面對比共用帶版本校驗的導出快照。
- 表格切換失敗立即清空舊預覽，遲到結果不能啟用錯誤目標；保留網格以外的勾號等裝飾，共用路徑無法可靠分離時提示使用單元格文字編輯。
- 普通與流式保存均在替換前驗證文件身份和 SHA-256，發現外部改寫、替換或刪除時提示另存副本或重開。
- 新文字超出原 PDF 裁剪時明確拒絕並保留草稿；補上引擎可能省略的原始裁剪追蹤，防止預覽有字、保存截字。
- 通用圖像入口保留透視參數，過期替圖讀取不寫入新選中的對象；三種適配模式的替圖均可在保存 PDF 後冷重開再編輯。
- 編輯背景每張限制 6MP、單邊 8192px；中性替圖、調整及透視共享解碼前尺寸保護。
- 目錄原鏈接不能繞過重名、頁眉或短標題疑點，OCR 與條目識別證據共同約束自動勾選；手動頁碼狀態即時更新。
- 修復書籤連續 Shift 多選、輸入法組合輸入守衛、模態標題、菜單焦點、鍵盤調欄寬、雙側欄聯合預算、空規則名與 FitR 目標頁尺寸。
- 源碼包僅採用受控清單和明確運行資源，附逐文件哈希；新增 main/PR 驗收及 quick/full 命令，更新修復工具的版本提示隨配置變化。

完整[評審採納與後續事項](REVIEW-2026-10-07-response.md)已隨源碼提供。Stencil/默認色空間、獨立填描排版、OCR 緩存租約、通用資源清理與完整 IPC schema 尚待專項實現。沒有聲明已完成真實輸入法、讀屏人工驗收或代碼簽名。
