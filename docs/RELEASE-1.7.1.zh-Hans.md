# Folio PDF Studio 1.7.1

本版修正智能目录识别的条目准确性，并简化批量生成书签的操作。入口仍是“更多工具 → 智能目录识别”，菜单图标已补齐。

- 一键完成目录检测、条目提取和实际页码定位，高置信度项自动勾选。
- 新增跨全部分页的“全选可生成项”、取消全选、搜索和待复核/未定位/已选筛选。可以显式批量采用首选候选；这些条目仍标记为待复核。
- 改用紧凑的可编辑列表，详细校准与预览按需展开，去除条目卡片内的嵌套滚动。高级设置默认折叠，保留手动目录范围、阅读方向与离线 OCR。
- 排除重复页眉和当前页码，统一连续目录页的缩进层级，保留标题末尾括号和引号；示例/图表索引单独作为可选范围。
- 利用目录内的 PDF 跳转链接，并用目标页正文标题交叉验证。错误或无法确认的链接只作为候选，不会自动覆盖有正文证据的位置。

针对用户提供的 `acrobat-sdk-js-dev-guide.pdf`，真实 PDF.js/界面/匹配工作线程测试识别正文目录第 3–8 页共 291 项，全部自动定位；标题、物理页码和层级逐项与 PDF 原有 291 个书签一致（比较标题时忽略章节编号、空白与标点）。标题括号保留另有独立回归测试。这个结果只适用于该样本，不表示任意艺术目录都能自动正确识别。

验证包括 181 项单元测试、跨页批量选择与筛选、真实 PDF 保存/重新打开、端侧 OCR、原有艺术目录回归，以及完整 Windows 发行检查。对比完整源书签的 Acrobat 测试在本地用户样本上执行，未将其 PDF 分发到仓库。

发布流程增加草稿恢复、网络重试和逐附件哈希检查；遇到连接超时可恢复同一发布，拒绝覆盖不同提交或不同文件。继续保留 1.6.2 的升级修复功能。

安装：下载本 Release 的 `portable-win-x64.zip`，解压并运行 `Folio.exe`；也可使用应用内更新。识别和校准仍在本地运行。复杂或低清艺术目录可能需要人工复核，保存 PDF 后书签才写入文件。
