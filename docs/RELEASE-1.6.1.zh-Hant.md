# Folio PDF Studio 1.6.1

修復 Windows 便攜版「安裝並重新啟動後沒有升級／程式結束」問題，保留 1.6.0 的編輯功能和三種介面語言。

更新器改用可靠的 PowerShell 啟動方式，只有實際完成驗證準備後才關閉 Folio。每次安裝保留獨立啟動記錄，並在替換前要求交接確認。重新啟動沿用使用者設定目錄，核對版本與處理程序；啟動失敗自動復原舊目錄。更新視窗提供進度、上次安裝結果與重試。

## 從舊版本升級

1.3–1.6 的更新器無法可靠地安裝自身修復。請同時下載本頁的 `Folio-PDF-Studio-1.6.1-portable-win-x64.zip` 和 `Folio-PDF-Studio-1.6.1-update-repair.zip`。儲存文件並結束 Folio，解壓縮修復工具，執行 `Repair-Folio-Update.cmd`，選取原來的 `Folio.exe` 與下載的便攜 ZIP。工具驗證後在原目錄安裝，啟動新版並保留同級舊版備份，原捷徑仍然有效。

也可以將完整便攜包解壓縮至新目錄後執行；使用者設定保留在 Windows 使用者設定目錄。請勿選取 GitHub 自動產生的 Source code ZIP。

Windows 發行流程執行單元、封裝、編輯、原生、多語言及實際更新／復原測試，全部通過後才公開附件。程式仍未簽章；其他程式占用安裝目錄時可能無法替換，此時保留舊版並記錄錯誤，不強制終止其他應用程式。
