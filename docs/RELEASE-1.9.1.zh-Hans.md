# Folio PDF Studio 1.9.1

本版集中改进教材嵌入中文字体、分段、原位增删和带标签 PDF 的保存重开。

- 识别教材中的旧 Apple TrueType 字体格式，保留已有字形，避免整段误换字体。
- 保留字体压缩时的共享字宽，并从已保存 PDF 的可靠字宽记录恢复旧问题文件，避免新插入的汉字在再次编辑后叠在一起。
- 保存文件未写明字重时，从嵌入字体恢复实际字重，避免原有粗体在再次编辑时被误换成常规体。
- 共享字体缓存完整写入后再原子发布，避免字体选择与排版并发时读到未写完的字体或元数据。
- 缺字匹配只加载评分所需的字形轮廓，保留相同候选和评分，降低首次推荐等待。
- 界面刷新或渲染进程退出后释放遗留原文资源，避免反复重开触及资源上限；正在运行的原生任务继续保留所需文件。
- 宽行距正文按重复行距分段，保留真实段间距；换行处六位代码不再误识别为标题。
- 表格底色不再当成边线，减少虚假小单元格。
- 支持中文提取软换行内长短增删的局部排版，尽量保持原始基线。
- 原文字已经覆盖的背景图片、已证明不含文字的背景复合图形不再误报冲突；前景及未知内容继续检查。
- 完整连续的同一语义段落可跨多个 MCID 保存，保留结构树及 ParentTree；局部标签范围和链接仍受保护。
- 统一保存与重开时的裁切边界容差；负词间距按真实字形前进量校验。
- 快速预览与精排使用一致的缺字推荐，输入不再等待字体评分完成。
- 背景预览保留标签语义上下文；独立绘制的拼音与基字对应被破坏时明确阻止保存，避免悄悄标错字。
- 修复带书签元数据的整本保存误报；连续保存保留原始书签目标和缩放参数。
- 局部换行遵守中文行首、行末标点禁则；独立菱形列表项分别识别，同一项目的续行保持在一起。
- 不再让没有绘制面积的纯空格阻挡扩框，页面实际留白可用于长插入；可见文字、图形和单元格边界仍会限制扩展。

自动化测试中，完成编辑并保存仍出现数秒至数十秒的等待，包含动作等待与调度。预览状态计时未绑定本次输入，可能捕获陈旧状态，不能作为有效的新布局延迟；报告记录了这一限制和独立的前台补测。密集练习题、交错对象仍有分段与编辑限制；独立注音暂不支持随基字自动移动。跨原行重排可能丢失 PDF 的逐字间距，装饰性底色也尚未完整识别为文字容器；带超框提示继续完成编辑可保存越出原框和底色的文字，重开按已保存文字重新推断范围后可能不再提示。

[深度编辑测试报告](DEEP-EDIT-1.9.1.zh-Hans.md)记录 20 个选定页面、多位置长短插入与删除、整本保存、真实键盘测试，以及本机 PDF-XChange 与 Acrobat 的实测观察。阻止和失败不计作成功，不宣称已达到完整竞品水平。发布附件不包含原始样本 PDF 或提取正文。
