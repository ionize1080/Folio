# Folio PDF Studio 1.9.1

本版集中改进教材嵌入中文字体、分段、原位增删和带标签 PDF 的保存重开。

- 识别教材中的旧 Apple TrueType 字体格式，保留已有字形，避免整段误换字体。
- 缺字匹配只加载评分所需的字形轮廓，保留相同候选和评分，降低首次推荐等待。
- 宽行距正文按重复行距分段，保留真实段间距；换行处六位代码不再误识别为标题。
- 表格底色不再当成边线，减少虚假小单元格。
- 支持中文提取软换行内长短增删的局部排版，尽量保持原始基线。
- 原文字已经覆盖的背景图片、已证明不含文字的背景复合图形不再误报冲突；前景及未知内容继续检查。
- 完整连续的同一语义段落可跨多个 MCID 保存，保留结构树及 ParentTree；局部标签范围和链接仍受保护。
- 统一保存与重开时的裁切边界容差；负词间距按真实字形前进量校验。

[深度编辑测试报告](DEEP-EDIT-1.9.1.zh-Hans.md)记录 20 个选定页面、多位置长短插入与删除、整本保存、真实键盘测试，以及本机 PDF-XChange 与 Acrobat 的实测观察。阻止和失败不计作成功，不宣称已达到完整竞品水平。发布附件不包含原始样本 PDF 或提取正文。

完整解压便携 ZIP 后运行 Folio.exe。验证附件记录测试源码和实际应用程序的 SHA-256 哈希。
