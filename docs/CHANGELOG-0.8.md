# Folio PDF Studio 0.8.0

本版针对多栏年鉴编辑、图片变色、表格、原字体匹配及页面空间进行修复。

## 页面编辑

- 不再根据共享 BT/ET 指令组把整页合成一个文本框。原生文字几何结合本地版面 AI 分段，重复栏起点用于约束栏界。
- 精确移除选中文字，用数值 TJ 保留文字推进量；不保留隐藏的旧文字。未选段落及栏保持原位。
- 编辑背景使用 PDF.js 直接渲染 PDF，和阅读模式保持相同色彩处理；不再通过整页 SVG 转换嵌入图片。
- 文字超出当前高度时，保持栏宽，寻找下方空白并由 Story 实际排版确认扩容。到达邻近文字、图片、边框或页边时停止。
- 冲突依据字形范围；两个文本框相交但文字分离允许提交。实际冲突在页面上用橙色框标出。空间不足以非弹窗状态提示保留草稿。
- 同栏段落可接续。不同原生栏保持独立，避免“接续”意外吞并栏间留白。工具栏的双栏/三栏续排仍用于主动设置的新布局。

## 字体与间距

- 默认复用支持的嵌入 TrueType 字体，包括 Identity-H 中文 CIDFontType2 子集、带 Unicode cmap 的普通 TrueType；常见 Helvetica / Times / Courier 标准字体使用 MuPDF 对应字体。依据 PDF ToUnicode 和 CIDToGIDMap 重建 Unicode cmap，保留字形轮廓。
- 继承实际页面字号（含文字变换比例）、颜色、段内字体切换、行距、首行缩进、字距与词距。插入文字继承所在位置的样式；整段字号、颜色、字距等工具操作统一覆盖对应属性。
- Story 本身忽略 CSS letter-spacing，因此按点值调整字体 advance metrics 后再排版；字距参与断行、光标定位和输出，不是显示后平移。
- 支持的原字体缺少新增字符时，仅该字符使用内置替代字体，状态栏显示替代字数。工具栏显示匹配到的字体名称。
- 原字体无法安全复用时显示“内置替代字体”或具体回退说明。不是对所有 PDF 的原样无损排版承诺：Type1/CFF 的非零字距、特殊编码、任意纵排、复杂水平缩放、逐字符 TJ 字偶调整等尚未完整匹配。

## 表格

- 检测有线表格的行列及合并单元格范围。点击页面编辑栏“表格”可显示网格，点击单元格直接输入。
- 支持文字和字号/颜色等样式修改、空单元格填写；Tab 提交并进入下一格，Shift+Tab 返回上一格。
- 保留原表格线。文字在单元格内排版，不跨越边框。单元格满时保留草稿并提示。
- 当前不含插删行列、交互式合并拆分单元格、整行自动增高或无框表格的可靠结构编辑。

## 界面

- 品牌栏 42 px、主工具栏 42 px、阅读导航栏 36 px、编辑栏 38 px；均为 CSS 像素。
- 搜索入口移到顶栏，实际搜索框按需浮动，不再单独占一行。
- 常用工具保持可见，批量规则、目标校准、留白、文字预览和属性等归入“更多工具”。统一线性图标。
- 默认书签栏 250 px、属性栏窄列；已有用户的侧栏设置保留。字体匹配信息和编辑状态使用紧凑显示。

## 使用

完整解压 Windows x64 运行包，双击 Folio.exe。不要只拷贝 EXE。
Ctrl+S 应用当前草稿并保存；Ctrl+Enter 应用本段；Esc 取消本段。仅进入编辑、未输入，不会提交重排。
本地字体缓存由原 PDF 在本机生成，未向云端传输。

## 验证边界

以用户提供的 12 页年鉴开展原生 PDF 回归和 Chromium 界面自动化。Windows 可执行文件版本、原生运行时和打包源文件经过一致性校验；真实 Windows 启动、中文输入法和混合 DPI 仍需实机验收。
