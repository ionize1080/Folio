# Folio PDF Studio 1.2.2

修复两类年鉴无法编辑的问题，并修正连续保存过程中暴露的文字布局问题。

- 普通矩形裁剪的照片可使用曲线、色阶、亮度、对比度等图像调整；保存保留原裁剪，修改只作用于选中实例。入口：更多工具 → 编辑对象 → 选中 image → 右侧图像调整。
- 无结构树、无结构归属的普通嵌套 Form 可展开编辑；仅在展开副本中移除无归属 MCID，保留语言、替代文字、资源隔离及原共享对象。交通年鉴不再因此整页只读。
- 排除子集字体中没有轮廓和字宽的残留字符映射，避免连续编辑出现不可见数字；替代文字产生的语义框不再误当成原始字位。
- 固定字位下的等宽替换保留负字距，避免保存重开后意外换行；绘制交错检查使用与原对象一致的边界，减少紧邻目录引导点时的误拒绝。
- 新增 7 组原生专项，以及真实 Windows EXE 的嵌套文字编辑、矩形裁剪照片调整、保存重开与共享实例隔离检查。所有发布附件仍由完整 Windows 工作流门控，附验收报告及 EXE/app.asar 哈希。

本地使用用户提供的两份样本（9 页和 20 页）逐页检查。文字页恢复编辑入口不代表每种复合对象都可以编辑；实际连续修改和同页/跨页像素对照范围记录于[专项验收文档](EDITOR-1.2.2-audit.md)。公开回归使用合成样本，不包含用户原文件。

真实标签结构、透明组、可选内容及非矩形图片裁剪仍按保护规则处理；扫描封面需使用图片调整或 OCR。长文本重排仍需检查溢出及字体替代。保留 qpdf 解密、旧版发布及备份；既有功能与限制见 [1.2.1 发布说明](RELEASE-1.2.1.md)。
