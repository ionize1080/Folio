# Folio PDF Studio 1.3.0

## 页面内图像工作区

主工具栏「编辑图像」→ 在当前 PDF 页面点击图片 → 右侧选择调整项目 → 在页面中查看实际合成结果 → 应用 / 完成。取消丢弃本次未应用的调整；应用后支持文档撤销/重做。原始图片实例不被覆盖，工程继续保留原图与参数。

- 高 DPI 曲线画布、输入直方图、RGB / 红 / 绿 / 蓝通道；最多 16 控制点，精确输入输出、拖动和方向键，保形三次插值 / 线性两种模式，自动与通道重置。
- 色阶：总通道和分通道的输入黑场、白场、中间调及输出黑白场；自动低比例截断。
- 亮度、对比度、色温、色调、自然饱和度、清晰度、去薄雾、颗粒、曝光 EV / 位移 / 灰度系数、色相 / 饱和度 / 明度。
- 分阴影 / 中间调 / 高光的色彩平衡，六色黑白，照片滤镜和保留明度，RGB 通道混合矩阵与单色模式。
- 颜色查找内置暖色 / 冷色 / 电影预设，导入 2–33 阶 `.cube` 3D LUT（0–1 域、三线性插值），强度调节。
- 九色域可选颜色（相对 / 绝对），反相、色调分离、阈值，多色标渐变映射。
- 扫描保色 / 灰度增强、高斯模糊、锐化；百分比裁剪、图片替换、适配；调整前对照、JSON 预设保存/载入。

页面预览由实际 PDF 合成产生，保留图片前后的文字与矢量对象、裁剪和透明度。颜色算法为 Folio 的独立实现，不宣称与 Adobe 闭源实现逐像素一致。处理采用 8 位 RGB；不提供 Photoshop 图层蒙版绘制、HDR / 16 位工作流或 CMYK 印前分色。调整组合采用固定顺序；重排调整层不在本版范围。

## 自动更新

「关于 / 使用说明 → 检查更新」，选择仅正式版或包含预发布。默认不联网，可选择启动时自动检查。检查与下载复用统一 HTTP 代理（首选项和关于页共用；留空使用系统代理）。正式版通道读取 GitHub Releases 的非预发布版本，不下载 main 分支源码作为程序。

下载采用流式写入、大小校验和 SHA-256 校验，支持取消。保存或关闭当前文档后，点击安装并重启。Windows 独立辅助进程等待 Folio 退出、检查 ZIP 路径与打包校验值、解压后替换，替换失败尝试回滚。旧文件夹保留为同级 `.backup-时间`；用户配置仍在原用户配置目录。程序目录内自行放置的其他文件可在备份目录取回。

**更新保持当前目录名**，避免破坏快捷方式。新 ZIP 名包含版本号，内部文件夹固定为 `Folio-PDF-Studio`。旧版 1.2.2 不含更新器，首次升级需手动解压 1.3.0，以后可在软件内更新。自动安装适用于 Windows x64 便携包，不申请管理员权限；无写入权限时保留旧版并写入用户配置目录 `updates/install.log`。

## 验证和下载

发布流程必须通过数值参考、原生 PDF 修改、真实 Windows 便携 EXE 控件和保存重开、Windows 更新辅助进程、既有文字编辑 / 年鉴 / OCR / 书签回归，才会创建正式 Release。所发 EXE/asar 的哈希与 Windows 实测报告对应。精确结果与构建链接见随 Release 发布的 validation.json。

下载完整 portable-win-x64.zip 并解压运行 Folio.exe，无需另装 Python、Node 或 OCR 模型。source.zip、validation.json 与 SHA256.txt 同步提供。
