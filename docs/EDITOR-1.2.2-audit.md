# 1.2.2 年鉴编辑修复验收

## 问题与处理

巍山样本第 4 个 PDF 页面（印刷页 94）的照片仅裁去约 1 pt 边缘，却因部分裁剪被整张判为只读。图片写回沿用原 Do 位置和外层裁剪；允许普通矩形裁剪，文字的部分字形裁剪以及非矩形图片裁剪仍保护。

交通样本第 2–20 页的正文封装在两层普通 Form 中。原文档没有结构树、页面和容器没有结构归属，但内部保留 MCID。此前一律保护此标记导致整页只能看到 Form。现在只在这些无归属普通容器的展开副本中移除 MCID，保留原共享资源、语言和 ActualText；真实标签/透明组/可选内容仍保护。

连续保存又暴露出四处边界：子集字体保留空字形 cmap、ActualText 的语义框被当作字位、等宽替换误判负字距，以及相邻目录引导点的绘制边界误报。分别通过过滤空字形、停用不可信语义锚点、保留原字宽容许范围及统一边界引擎处理。

## Windows 发布门禁

`tests/editor-yearbook.py` 生成与用户结构对应的合成文件，检查嵌套 MCID、结构保护、ActualText、空字形、负字距、真实绘制交错、图片裁剪与共享实例隔离。

`tests/electron-p8.cjs` 在打包 Folio.exe 中实际选择文字、输入、保存、重开，并检查裁剪照片的曲线入口、调整应用、裁剪外像素及共享页。与原有六组 EXE 验收一同执行；`publish-p8.py` 校验全部报告和附件哈希后才能发布。

该修复不将复杂透明 Form、任意标签结构、非矩形图片裁剪或扫描封面承诺为可直接改字。新增或大幅延长文字仍须检查溢出和字体替代。
