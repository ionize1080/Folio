# Folio PDF Studio 1.7.0

新增入口：**更多工具 → 智能目錄識別**。

1. 檢測候選目錄頁，預覽並人工增刪目錄範圍。默認檢查前 50 頁，可改成全書或指定範圍。
2. 提取條目，修改標題、原始頁碼、層級和順序，刪除誤識別項或補充條目。
3. 獨立搜索各條標題的實際頁碼。結合正文標題、PDF 頁面標籤和頁邊印刷頁碼列出候選，自動排除已選目錄頁，允許各條偏移不同及目錄數字錯誤。
4. 預覽目錄原文和目標頁，採用候選或手動填實際頁碼，再生成已選書籤。支持追加、替換、整批撤銷；保存 PDF 後書籤才寫入文件。

支持橫排、旋轉及斜排文字、豎排、多欄、上標頁碼、換行標題、頁碼前置，以及點線、符號、空白或矢量線連接。頁碼解析覆蓋多種 Unicode 阿拉伯數字、中文數字及大寫、羅馬數字、帶前綴編號。字母頁碼 a/b/c 可顯式啟用；啟用後 c/i/v/x 優先按字母解釋。

可選端側 AI 使用現有 RapidOCR / ONNX CPU 模型，輔助無文字或少文字頁面，複用已校對 OCR。文檔留在本機，不上傳，也不調用雲端大模型。這是 OCR 加幾何及證據規則，不是通用視覺語言模型。

仍有識別邊界：任意藝術字、弧形排版、嚴重模糊掃描、雙語交錯、複雜層級及模型不支持的掃描語言可能需要人工修正。評分表示規則證據強度，不是正確率。目錄漏檢時可手動填寫頁面；整本掃描書開啟 OCR 會較慢。未匹配或衝突目標不會直接套用目錄數字。自動勾選項也請核對標題和層級。

同時整合既有書籤的逐條頁碼校準，保留 1.6.2 自動升級修復。舊版升級助手無法啟動時，可獨立解壓新版便攜包，或使用本 Release 的一次性修復工具並選擇原安裝目錄。

驗證包含幾何與數字規則測試、真實 PDF 提取/保存/重新打開、離線 OCR、本地及網上樣本探索測試，以及完整 Windows 發行迴歸。樣本處理數量不等同於準確率；詳見 `SMART-TOC-VALIDATION.json` 和 Release 驗證附件。
