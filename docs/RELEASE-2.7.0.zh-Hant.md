# Folio PDF Studio 2.7.0

本版增加增量保存、書籤質量檢查和更完整的頁面整理，並壓縮界面橫欄，提高文檔的縱向可閱讀高度。

- **增量保存**：追加變化對象，複用未變的圖片、字體等資源，覆蓋原生頁面編輯快照及頁面整理輸出。內容未變時複用已解析快照；資源處理、序列化、文件校驗和寫入顯示進度。首選項保留完整重寫模式。
- **書籤統計 / QC**：重複或空標題、層級、目標頁和動作檢查，可主動檢查公網鏈接；支持批量嘗試修復、僅刪除節點或刪除子樹。新增每 N 頁生成、標題模板、頁碼篩選和保持樹結構的排序。
- **閱讀體驗**：按字符精確命中，統一顏色的文字選區；滾輪行數、定位線顯隱及顏色可調。書籤跳轉先計算最終座標，再一次定位，修復頁頂抖動。
- **頁面整理**：範圍、奇偶和鼠標框選；插入、空白頁、逐頁配對替換、批註與表單選項、旋轉、裁剪、保持比例縮放、僅調整紙張、提取和拆分。
- **高亮與批註**：內置配色及自定義顏色、透明度、線寬和線型；支持下劃線、波浪線、刪除線、矩形、墨跡及半透明手繪標記。
- **圖像 / 矢量工作室**：在 PDF 背景上用手柄調整畫布；自動擴展只在內容越界時增大畫布，不自動縮小。保持作品繪製比例，避免圓形因放置尺寸不同變成橢圓。同一會話可反覆打開，保存 `.folio` 工程會保留可編輯源文件和自動畫布選項。
- **緊湊界面**：Windows 自繪標題欄常駐保存、撤銷、重做，連接文件標籤和窗口按鈕；閱讀工具移至底欄，常用頁仍保留對應操作。採用清晰文字層級、統一間距、可見焦點和剋制動效。
- **更新**：兼容 Chrome 的請求頭、經過校驗的並行下載和斷點續傳、Markdown 更新說明。
- **打印**：縮略圖多選、範圍及奇偶篩選、份數、逐份、灰度和長／短邊雙面。講義支持自定義行列、四種排列順序、邊框、頁邊距、間距、子頁面尺寸，並可拖動位置及等比縮放。小冊子支持左右裝訂、自動補白、分帖和正反面分開打印。預覽和輸出使用同一佈局，也可存為 PDF；直接選擇打印機可保留應用內設置，同時保留系統對話框入口。

本地完整性驗證使用 3 份實際 PDF，覆蓋 69 個連續修改狀態、4,960 頁比對：MuPDF 逐頁比較普通保存與增量保存的文字和畫面；PDFium 獨立檢查抽樣頁渲染；pypdf 遍歷可達對象引用。範圍包括文字及原生段落編輯、圖片、矢量、OCR 文字、批註、表單、元數據、書籤，以及頁面插入、刪除、排序、替換、旋轉、裁剪、縮放、提取和撤銷。這是對已測樣本的驗證，不代表任意 PDF 均無兼容問題。

96 MiB、300 頁、1,000 個書籤的本地基準中，修改一個書籤標題只追加 **414 字節**、更新一個對象。序列化及內存組裝約快 **3 倍**；該數字不含磁盤校驗與刷盤，實際總耗時隨文件和磁盤變化。

發佈流程改為只構建、歸檔一次，由四個並行任務驗證同一 ZIP，安裝與更新檢查單獨並行。原先較慢的界面、作品放置和頁面整理測試也拆開執行。最後發佈階段校驗提交、運行編號及文件哈希，不再重複構建和執行整套測試。

實際調用 Microsoft Print to PDF 驅動驗證：8 頁小冊子輸出為 4 個頁序正確的 A4 橫向打印面，四頁一面的灰度講義輸出為 2 個 A4 縱向打印面。獨立像素檢查驗證了頁面位置、顏色和物理尺寸，並據此修復系統對話框覆蓋方向、驅動 DPI 不匹配導致打印縮小的問題。自動化還覆蓋右側裝訂、補白、手動背面、邊框、間距、拖動與 PDF 輸出。

增量文件會保留歷史修訂；需要清除舊內容或回收歷史體積時，請使用完整重寫。網絡鏈接被阻止訪問時標記為“無法確認”。打印採用渲染頁面，默認 300 DPI，可選 150 / 600，並限制單頁內存；不會改變原 PDF 中的矢量內容。實體打印機的雙面進紙與驅動特有能力仍需設備驗證。本版不宣稱已完全覆蓋 Acrobat 或 PDF-XChange 的全部功能。
