# Folio PDF Studio 1.6.1

修复 Windows 便携版“安装并重启后没有升级／程序退出”的问题，保留 1.6.0 的编辑功能和三种界面语言。

- 修复更新器以 `detached: true` 启动 PowerShell 时，进程返回成功却不执行脚本的问题；只有实际完成校验准备后才关闭 Folio。
- 每次安装独立保存脚本、启动日志和结果，脚本启动失败也能追查。
- 增加安装交接确认；准备期间关闭或崩溃，不会直接替换程序目录。
- 重启沿用用户配置目录，并核对新版本和启动进程；启动失败自动恢复旧目录。
- 更新窗口显示准备进度和上次安装结果，失败后支持重试。

## 从旧版升级

1.3–1.6 的更新器无法可靠地安装自身修复。请同时下载本页的 `Folio-PDF-Studio-1.6.1-portable-win-x64.zip` 和 `Folio-PDF-Studio-1.6.1-update-repair.zip`。

保存文档并退出 Folio，解压修复工具，双击 `Repair-Folio-Update.cmd`，依次选择原来的 `Folio.exe` 和刚下载的便携 ZIP。工具校验本次发行包后原目录安装、启动新版，并在同级保留旧版备份；原快捷方式继续有效。不要选择 GitHub 自动生成的 Source code ZIP。

也可以将完整便携包解压到新目录后运行；用户设置仍保存在原 Windows 用户配置目录。

## 验证和限制

发布流程执行 Windows 单元、打包、编辑／原生／多语言回归，以及真实 PowerShell 回滚和通过正式更新器启动的 Electron 升级测试。所有检查通过后才公开附件；验证报告绑定源码提交及二进制校验值。

程序仍未签名。其他程序占用安装目录时可能无法替换，此时保留旧版并记录错误，不强制终止其他应用。
