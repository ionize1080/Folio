# Folio PDF Studio 1.7.3

本版改进教材、技术手册和统计年鉴的智能目录识别。

- 智能目录入口移至主工具栏。目录 OCR 与耗时较长的正文 OCR 分开控制，选项直接可见。
- 双栏目录按先左后右读取；跨页保持层级；识别教材单元、课号、篇目及技术手册的显式章节编号。
- 保留无页码分组标题和漏识别页码的扫描条目，明确标记待复核，避免静默丢失。
- 密集扫描目录漏掉细小页码时，对页码栏单独提高分辨率重识别，保留 OCR 置信度和人工确认要求。
- 正文匹配兼容课号、装饰符号和作者署名；优先完整编号标题，降低表格单元格和单位署名的误匹配。
- 对无缩进年鉴利用字体类别辅助判断层级；取消勾选父项后，子项不会误挂到上一章节。
- 缓存正文规范化文本，减少匹配时的重复计算。

使用本机三本教材、两本技术手册、四本年鉴进行实测，并完成算法回归、浏览器交互和发行程序真实离线 OCR 检查。validation 附件绑定实际测试包哈希。第三方样本 PDF 不随发布包分发。

目录提取不等于完整、准确的书签树。重名标题、低清扫描、中英对照行和复杂年鉴层级仍需复核；正文 OCR 建议先缩小范围。原 PDF 书签仅用作独立评估参照，不参与生成算法。

下载 portable Windows x64 ZIP，完整解压后运行 Folio.exe。支持英文、简体中文和繁体中文。
