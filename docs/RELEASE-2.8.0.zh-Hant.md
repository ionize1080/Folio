# Folio PDF Studio 2.8.0

保留並完善現代介面：功能區、三欄書籤規則編輯器、OCR 校對工作區和頁面組織器統一了視覺風格，支援明暗主題。

- **連續開啟檔案更穩定**：新檔案在背景準備好第一頁後，才切入同一個視窗。載入期間原文件保持可用。分頁保留頁碼、選取範圍、復原記錄及未儲存修改；重複開啟相同路徑會回到原分頁。密碼對話框可正常操作，載入失敗或取消會保留原文件。
- **功能區切換更即時**：各分類控制項只建立一次，切換時重複使用，不再反覆拆裝，也不會改變文件顯示區域。鍵盤切換、收合狀態與按鈕可用狀態保持一致。
- **書籤工作區**：重用未改變的書籤列；調整目標座標只更新定位標記；規則預覽快取文字擷取結果並自動更新。修正色彩預設未標記修改、連續重新命名殘留重複列等問題。
- **頁面組織**：支援鍵盤排序、空白鍵預覽、縮圖縮放、框選與拖入 PDF 和圖片。旋轉重用縮圖快取，關閉時清理待完成的繪製。頁面調整可直接套用到目前文件，之後再儲存。
- **效能與可靠性**：捲動只檢索附近頁面，減少重複啟用和文字版面複製；OCR 快取清理保護正在使用或寫入的結果。Electron 更新至 44.11.3，並修正鎖定相依套件中的已知問題。

本機 Windows 小型 PDF 樣本實測：已開啟文件切換中位耗時約 **4–8 ms**；功能區點擊處理 P95 約 **0.5 ms**，下一影格約 **13 ms**；三種語言共 96 次切換中，功能控制項重複拆裝為 **0 次**。這不是所有檔案的速度承諾，首次開啟仍受檔案複雜度、儲存、解密及繪製影響。

發佈須通過同一提交的 GitHub Actions 平行驗證，包括原生編輯、OCR、儲存完整性、列印、AI 工作流程及現代介面。最終可攜版另行通過四組平行測試，共 **29 個驗收腳本**，並驗證檔案雜湊及測試來源。發佈附件包含可攜版、原始碼、驗收報告與 SHA-256 校驗值。
