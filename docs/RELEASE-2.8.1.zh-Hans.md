# Folio PDF Studio 2.8.1

关闭原文件保护时，首次保存也会在核对原始字节后直接追加修改，后续继续增量保存。外部程序更改过文件时，仍会阻止不安全的覆盖。

- 相邻文本选区合并为连续的行色块，段落编辑后也适用。阅读首选项新增独立的选区边框开关，默认关闭；复制内容保持原样。
- 拖动选区时复用本次手势的页面和字符测量结果；普通滚动不再反复测量、重绘未变化的选区。
- 长书签只在确实放不下时占两行，短标题保持原来的行高；列表仍按可见区域加载。首选项分类切换立即完成，避免控件在点击过程中移动。
- 合并最新 modern design 的字体工作台、预览控件和窗口尺寸调整。字体信息复用，字符覆盖检查不再单独请求；长文本在大字号下仍显示可容纳的预览。

本机完成 9 个 PDF、99 轮保存检查，覆盖指定的已整理金融报告、表单、扫描件，以及文字、图像、矢量、OCR 层、书签修改、撤销重做、完整重写和重新打开。MuPDF、PDFium、pypdf 独立核对输出。三个同时打开的文档也通过并发保存、实际本地 OCR、修改隔离和 18 次标签切换。测试编辑副本，原始样本未改变。

本机小型样本的一次 30 步文本拖动中，字符几何测量从 686 次降至 35 次；普通滚动无需测量选区字符。按实际处理时间调度保存后，1 万条新书签的序列化从约 1.44 秒降至 0.19 秒（三次本机测量）；后续单条改名只追加一个对象。这些是指定场景的测量结果，不是对所有 PDF 的速度承诺。

发布必须通过同一提交的 GitHub Actions 并行检查。最终便携 ZIP 另行分五组运行 33 个验收脚本。公开 CI 使用生成样本和固定版本的公开 PDF，不上传用户本机文档。附件提供源码、验收证据和 SHA-256 校验值。
