# Folio PDF Studio 1.7.0

新增入口：**更多工具 → 智能目录识别**。

1. 检测候选目录页，预览并人工增删目录范围。默认检查前 50 页，可改成全书或指定范围。
2. 提取条目，修改标题、原始页码、层级和顺序，删除误识别项或补充条目。
3. 独立搜索各条标题的实际页码。结合正文标题、PDF 页面标签和页边印刷页码列出候选，自动排除已选目录页，允许各条偏移不同及目录数字错误。
4. 预览目录原文和目标页，采用候选或手动填实际页码，再生成已选书签。支持追加、替换、整批撤销；保存 PDF 后书签才写入文件。

支持横排、旋转及斜排文字、竖排、多栏、上标页码、换行标题、页码前置，以及点线、符号、空白或矢量线连接。页码解析覆盖多种 Unicode 阿拉伯数字、中文数字及大写、罗马数字、带前缀编号。字母页码 a/b/c 可显式启用；启用后 c/i/v/x 优先按字母解释。

可选端侧 AI 使用现有 RapidOCR / ONNX CPU 模型，辅助无文字或少文字页面，复用已校对 OCR。文档留在本机，不上传，也不调用云端大模型。这是 OCR 加几何及证据规则，不是通用视觉语言模型。

仍有识别边界：任意艺术字、弧形排版、严重模糊扫描、双语交错、复杂层级及模型不支持的扫描语言可能需要人工修正。评分表示规则证据强度，不是正确率。目录漏检时可手动填写页面；整本扫描书开启 OCR 会较慢。未匹配或冲突目标不会直接套用目录数字。自动勾选项也请核对标题和层级。

同时整合既有书签的逐条页码校准，保留 1.6.2 自动升级修复。旧版升级助手无法启动时，可独立解压新版便携包，或使用本 Release 的一次性修复工具并选择原安装目录。

验证包含几何与数字规则测试、真实 PDF 提取/保存/重新打开、离线 OCR、本地及网上样本探索测试，以及完整 Windows 发行回归。样本处理数量不等同于准确率；详见 `SMART-TOC-VALIDATION.json` 和 Release 验证附件。
