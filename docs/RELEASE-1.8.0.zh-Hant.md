# Folio PDF Studio 1.8.0

本版支持一鍵跳過全部 OCR 待校對建議，修復目錄漏頁和書籤層級問題，並統一更換摺頁式圖標。

- 新增“跳過全部待校對並應用”：保留識別文字、原置信度及未確認狀態，不必逐條處理數千條建議。缺字檢查仍保留；應用後可撤銷，保存 PDF 後才寫入文件。
- 改進帶空格的點引導線、西班牙語目錄標題、字母附錄編號、稀疏目錄尾頁，以及通欄摘要下方的偏心雙欄目錄。
- “篇／部分”標題成為數字章節的父級；同頁後半部分的圖表或示例索引不再混入主目錄。修復 xcolor 手冊第 3 頁目錄遺漏。
- 候選目錄頁增加勾選框，便於補頁、排除誤選頁後重新提取。
- 修復 Type1 字體的 PDF 編碼覆蓋和子集連字：編輯相鄰文字時，原文 ff 連字不再少字。加入普通排版、快速排版及保存重開的迴歸檢查。
- 工具欄、歡迎頁、窗口和 Windows 程序資源統一使用原創摺頁圖標，並提供小尺寸圖標。

## 測試範圍

新下載 CTAN 與 R 項目的 20 份公開 PDF，另檢查本地 29 份不重複 PDF。覆蓋目錄提取、層級、真實頁面正文編輯、OCR 可搜索文字層、書籤保存重開、原生引擎和瀏覽器交互。4 份公開手冊沒有印刷目錄，不生成目錄書籤屬於預期。最終結果及程序哈希見 validation 附件；不附帶第三方樣本或私人文檔內容。

自動勾選數量不代表準確率。掃描年鑑抽查 21 頁目錄／檢測頁與 12 頁正文，並非逐頁遍歷全書；模糊目標仍需核對。無法解析的原字體需要明確選擇替代字體，純掃描頁需先 OCR 才能編輯其文字。

## 安裝

完整解壓 Windows x64 portable 壓縮包，運行 `Folio.exe`，保留所有資源目錄和 DLL。支持英文、簡體中文和繁體中文。保留供舊版使用的 update-repair 修復包，升級說明參見 1.6.2 發佈說明。
