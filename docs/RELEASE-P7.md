## Folio PDF Studio 1.2.0 RC1-P7

修复普通嵌套包装 PDF 无法编辑、标题使双栏串文、ActualText 旧语义、流资源误复用，以及紧文本框末字等宽替换的重排问题。新增嵌套文字诊断和与已知图形/替代文字特征相符的有效 PDF 版本声明。

普通包装按每次调用隔离资源，保留矩阵、裁剪和其他页面；透明组、结构关联、可选内容等复杂容器继续保护。该能力是受限包装兼容，不是任意嵌套 PDF 的全功能编辑。

本版本发布门禁包括 129 项 JS 单元测试、P7/P6 原生专项、旧版本及 OCR/加密/书签/表格回归、10 份公开文档 50 页，以及同一打包 Windows EXE 的编辑、撤销、保存重开。附件中的 validation.json 提供实际成功记录；SHA256.txt 可核验源码和 portable 包。

本地另检查用户提供的 20 页年鉴：无编辑时 MuPDF 全页像素/文本一致，PDFium 单通道差异不超过 1/255；四次独立文字替换后各自其余 19 页像素一致。它不代表完整大年鉴、Windows 原件、中文输入法或印刷分色已验收。完整结果及剩余问题见源码内 `docs/RC1-P7-editor-audit.md`。

下载 **portable-win-x64.zip**，完整解压后运行 `Folio.exe`，无需另装 Python、Node 或 OCR 模型。**source.zip** 包含源码及离线运行资源。P7 继续作为预发布版本；保留旧 Release。
