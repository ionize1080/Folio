# Folio PDF Studio 1.7.1

本版修正智能目錄識別的條目準確性，並簡化批量生成書籤的操作。入口仍是“更多工具 → 智能目錄識別”，菜單圖標已補齊。

- 一鍵完成目錄檢測、條目提取和實際頁碼定位，高置信度項自動勾選。
- 新增跨全部分頁的“全選可生成項”、取消全選、搜索和待複核/未定位/已選篩選。可以顯式批量採用首選候選；這些條目仍標記為待複核。
- 改用緊湊的可編輯列表，詳細校準與預覽按需展開，去除條目卡片內的嵌套滾動。高級設置默認摺疊，保留手動目錄範圍、閱讀方向與離線 OCR。
- 排除重複頁眉和當前頁碼，統一連續目錄頁的縮進層級，保留標題末尾括號和引號；示例/圖表索引單獨作為可選範圍。
- 利用目錄內的 PDF 跳轉鏈接，並用目標頁正文標題交叉驗證。錯誤或無法確認的鏈接只作為候選，不會自動覆蓋有正文證據的位置。

針對用戶提供的 `acrobat-sdk-js-dev-guide.pdf`，真實 PDF.js/界面/匹配工作線程測試識別正文目錄第 3–8 頁共 291 項，全部自動定位；標題、物理頁碼和層級逐項與 PDF 原有 291 個書籤一致（比較標題時忽略章節編號、空白與標點）。標題括號保留另有獨立迴歸測試。這個結果只適用於該樣本，不表示任意藝術目錄都能自動正確識別。

驗證包括 181 項單元測試、跨頁批量選擇與篩選、真實 PDF 保存/重新打開、端側 OCR、原有藝術目錄迴歸，以及完整 Windows 發行檢查。對比完整源書籤的 Acrobat 測試在本地用戶樣本上執行，未將其 PDF 分發到倉庫。

發佈流程增加草稿恢復、網絡重試和逐附件哈希檢查；遇到連接超時可恢復同一發佈，拒絕覆蓋不同提交或不同文件。繼續保留 1.6.2 的升級修復功能。

安裝：下載本 Release 的 `portable-win-x64.zip`，解壓並運行 `Folio.exe`；也可使用應用內更新。識別和校準仍在本地運行。複雜或低清藝術目錄可能需要人工複核，保存 PDF 後書籤才寫入文件。
