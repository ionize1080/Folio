# Folio PDF Studio 0.4.0

Windows 11 x64 便携版。完整解压后双击 Folio.exe，勿只移动 EXE。版本在窗口和「帮助」中可见。

## 本版实现

- **目标校准**：顶部「目标校准」或书签右键。按标题寻找原目标页的首次文字出现位置，支持 mm/pt 留白、忽略空白和全半角、正则去编号、页眉页脚排除、可选前后 0–20 页查找。未匹配项保持原样；原始动作转换需勾选。逐项候选与原／新位置预览，设置更改后自动更新。校准采用文字行顶部落点。
- **通用多级规则**：默认一个普通章节规则。增加、删除、停用、重排层级；每层独立正则、标题模板、粗斜体、颜色和留白。启用层级连续编号，资源上限 10,000 条规则而非固定业务层数。行业规则只作为主动加载的示例预设。支持规则冲突优先／跳过、孤儿跳过／提升，以及可选跨行拼接。
- **多选样式**：右侧属性栏可统一修改粗体、斜体和颜色；显示混合状态，只修改用户操作的字段，可包含后代。
- **去重**：整理菜单／书签右键，支持同页同标题、完整目标、同页坐标容差。比较同父项、选择项、子树或整棵树；可选保留项，合并子项，祖先后代不互相合并。生成书签时只吸收新生成的重复项，保留原有树中的存量重复项。
- **拖拽**：前／子项／后落点扩大；左侧 24px 区域移至根层；显示落点与移动数量，悬停 600ms 展开，边缘连续滚动，Esc 取消。树仍按可见行呈现。
- **OCR 重复修复**：按空间与文字过滤重叠块；原生文字与已校对 OCR 采用区域覆盖；文字行提取识别明显栏间距，不再直接拼接同高度的双栏。不会通过删除标题中的重复字词来去重。
- **OCR 引擎核实**：RapidOCR 3.9.2 + ONNX Runtime 1.30.0 CPU；内置 PP-OCRv6 small、PP-OCRv5 mobile ONNX 模型与方向分类模型。不是 PaddlePaddle 推理后端。
- **OCR 调度**：一次传递／落盘 PDF，工作进程内复用 PDF 与模型；多页并行、推理线程和文字行批量可调。自动／低占用／高性能／自定义模式；按可用内存限制并发，内存压力增加时额外进程停止接收新任务。并发结果按页序呈现。
- **OCR 内存与续做**：识别结果逐页保存到本机应用数据目录；界面只加载当前校对页，不再每页重建全文选项列表或自动渲染全部处理页。相同文档内容与参数可续用已完成结果和校对；失败页重试、停止保留结果。完成后应用文字层才进入文档撤销／保存状态。
- **OCR 校对界面**：参数可折叠；后台活动页与校对页分开；按页浏览、低置信度导航，原图／文字框／识别文字独立开关。再次打开已应用的 OCR 可直接校对，无需重新识别。
- **统一选页**：OCR、多级生成、经典生成、页面操作与缩略图入口共用。全部／当前／所选／当前至末尾／已标记范围，起止控件、奇偶过滤，保留自定义语法。缩略图每组 24 页加载，支持 Shift 连选、点击加选／取消、全选／反选；顶栏可标记起点和终点。页序和已有标签并列显示。
- 保留既有高清分块渲染、旧画面保留、原件保护、覆盖保存、基础对象编辑、撤销重做与恢复功能。

## 验证与边界

- 自动化核心测试、实际中文扫描 OCR、并行／续做／取消与浏览器界面测试结果见同目录 v4 报告及 VALIDATION-0.4.md。
- 已验证生成的双层 PDF 可搜索，并在四页中文扫描样本上保持原图渲染像素一致；不代表所有文档的识别准确率。
- **未进行真实 Windows 11 启动、Windows 文件锁／覆盖、显卡驱动及多显示器 DPI 验收**。连续缩放检查在 Linux Chromium 中执行。程序未签名。
- **没有拿到用户 758 页原 PDF，也未做该文档的内存／速度实测**。不承诺提速倍数或准确率；新增每页阶段耗时和任务速度供验证。
- 自动并发为保守资源估算，不是通过 CPU 占用反馈维持某个百分比；最低一个 OCR 进程也需要足够内存。最终应用／保存 PDF 仍可能出现内存峰值。
- 双栏与跨行处理是几何启发式；复杂多栏、表格、多行长标题需检查预览。跨行开关最多拼接三条相邻行。目标校准落点是匹配文字所在行顶部，不能保证精确到行内单字的 X 坐标。
- 校准与去重界面展示前 500 项／组，其余按默认选择处理；大范围可分批操作。多级生成保留前 200 项预览与最多 3,000 条诊断。
- 位置容差去重要求相同页面及可比较的定位模式／有效坐标；同页模式忽略坐标和缩放。同名标题位于不同父项时，可选择整棵树比较，但不同章节下的同名入口可能有实际用途，应查看预览。
- 局部 OCR 不因其他区域有文字而跳过；整页「跳过已有文字」仍采用文字量判断，未实现所有复杂混合页面的智能完整性检测。
- 识别缓存会保留以供续做，随文档内容和识别参数区分；不包含自动清理缓存界面。扫描图像不被 OCR 校对修改。
- 完整页面管理、分屏、商业级正文重排、表格导出、GPU OCR、数字签名不属于本版新增范围。
