## 本构建的边界

- 尚未启动 Windows EXE。真实系统缩放、微软拼音/其他输入法候选框、多显示器切换，以及强制退出后恢复仍需 Windows 验收。
- 系统字体以引擎能读取的字面为准；TTC 多字面选择和部分可变字体实例尚未扩展。缺字详情最多展示前 300 处，字数统计为完整计数。
- 原字体子集不能覆盖的新增文字会明确替代；原字体复用沿用 0.8 的支持范围，不承诺任意 PDF 字体都可任意续写。
- 表格增高针对简单有线表格。复杂裁切路径、倾斜变换、跨行合并单元格及跨页表格尚无全面保证；无法形成可靠输出时保留草稿并报错。
- 对照为本段编辑前/后，格式吸取为字符样式。全页变化高亮、段落格式刷、结构拆分/合并/锁定以及统一图片属性仍保留在待办中。
- 几何重叠可以保留；源对象身份过期、重复修改同一源对象、无效坐标或排版/写入失败仍明确报错。这些错误不会假装保存成功。

## 复现

1. `npm test`
2. `python tests/native-v9.py`
3. `python tests/native-v8.py <年鉴PDF路径>`
4. 设置 `FOLIO_CHROMIUM` 指向本机 Chromium，安装 Playwright 后运行 `npm run test:ui`。
5. 设置 `FOLIO_YEARBOOK` 为年鉴路径后运行 `node tests/ui-v9-yearbook.cjs`。
6. `npm run build:win`；`node scripts/verify-package.mjs`。

测试记录位于 `docs/validation-v9/`。源码不附带用户的年鉴 PDF。Linux 测试若依赖安装在用户级目录，测试进程需配置相应 `PYTHONPATH`；交付的 Windows 包内依赖已齐备。
