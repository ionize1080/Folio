## Folio PDF Studio 2.3.0

文档工作台加入本地 Office 转换、AI 结构复核与归档验证，并同步开放 MCP 能力。

- Word 导出支持保留页面布局或重建流动文本；AI 复核标题和有原文依据的表格。Excel 保留前导零、字面公式文本、合并单元格和原文依据工作表。扫描件可先本地 OCR。字符覆盖率不代表视觉保真评分，复杂文件仍需检查。
- Word、Excel、PowerPoint、OpenDocument、Markdown、文本、CSV、HTML 与常见图片转 PDF。混合格式合并支持排序、自定义文件书签和保留原书签。
- PDF/A-1b、2b、3b 转换后必须通过 veraPDF 独立验证。支持任意元数据、线性化、精细压缩预设、加密、基本表单与图像/文字导出。
- Chromium 网页转 PDF 提供精致文章阅读模式，可由 AI 选择排版参数，保留原文事实。
- OCG 图层管理、标签结构树与替代文字、文档语言和阅读顺序编辑；veraPDF 验证 PDF/UA 机器规则。PDF/X-1a、X-3、X-4 支持 CMYK ICC 输出与**部分结构预检，不代表完整 ISO 认证**。
- MCP 字体能力包含目录、覆盖、度量、字体表、字形轮廓、预览、子集、可变实例、Unicode 映射修复，以及带预检和撤销的段落字体替换。
- 同一 AI 对话实时跟踪活动文档、可见页面、文字选区矩形和对象选区。页面渲染包含未保存修改。长任务自动续跑并对写操作去重，重复失败或无进展时停止。
- 可搜索工具库、统一图标、适配窄窗口的对话框，以及字体、图层和标签界面。

发行包包含便携转换组件及许可证说明。原有 qpdf 解密不变。文件级处理另存副本，重写会影响签名。PDF/UA 的阅读顺序和替代文字质量仍需人工复核。本版本不声称完整复刻 Acrobat/PDF-XChange，也不承诺所有 PDF 都能完美转换；实测结果见验证报告与对标记录。
