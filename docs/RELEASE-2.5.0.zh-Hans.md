## Folio PDF Studio 2.5.0

- 修复编辑图像时鼠标悬停使图片变白；右键可直接进入快速调整、裁剪或图像工作室。打开工作室及替换回 PDF 时保持旋转、镜像、裁剪路径与原有放置位置。
- 图片选择器显示缩略图、页码及尺寸；读取页面对象时仍可立即新建作品。两个工作室默认使用 PDF 参考背景，增加直接可见的平移、适合画布、画布大小及位置尺寸控制。
- 菜单关闭后清除高亮；统一下拉框样式与对齐，工作室界面字体跟随 Folio 的语言和系统字体，数字控件保持统一字宽。
- **组织 → 插入空白页** 支持继承参考页、标准纸张或自定义尺寸，设置横纵向、数量，以及在指定页之前或之后插入。书签跳转随页序调整。
- **Chatbox 设置 → 生图模型提供方** 可明确配置 Qwen Token Plan、DashScope 和兼容生图接口。保存地址、模型和密钥后，可测试并直接查看预览。已使用真实服务验证 Qwen 生图及参考图编辑。
- 段落编辑按需检查单页，复用有界缓存，并在编辑命令获得焦点时提前准备。保持原字体标识稳定；修复书签坐标序列化误差阻断文档快照和 AI 页面渲染的问题。
- 统一 JPEG2000 的 WASM 解码配置，段落预览及保存重开保持照片可见；修复行尾空格导致的假溢出，并改善编号小节与正文的分段。
- Windows Actions 并行构建两个 Rust/WASM 引擎，执行 15 组验收；最终程序在两个隔离通道中复测，通过后发布便携包、源码、校验值与验证报告。

详见[工作流与验证说明](https://github.com/ionize1080/Folio/blob/main/docs/WORKFLOW-2.5.0.md)及[工作室指南](https://github.com/ionize1080/Folio/blob/main/docs/CREATIVE-STUDIO.md)。
