# v0.2 改进与新特性清单

## 已实现

- 五种阅读布局、封面独页、页间距；布局与缩放分离。
- Ctrl+滚轮锚点缩放、Shift+滚轮横移、连续自然滚动、单页边界手势保护、按屏导航。
- 独立的页导航与视图历史；记住每文档位置/缩放/布局。
- 参考 PDF 的文字层透明选区、缩放后的坐标同步；按实际选区页建立书签目标。
- 懒加载缩略图、PDF 页标签、全文匹配位置导航、F3 上下结果。
- 临时视图旋转与永久旋转分离；全屏、按住空格拖动。
- Acrobat / PDF-XChange 风格快捷键、输入框/书签树/阅读区焦点优先级、Tab 焦点、自定义和冲突检查、配置交换。
- 书签右键菜单、行内改名、同级/子级新建、多选升降级、子树剪切复制粘贴、排序移动。
- 删除整棵子树、删除父项保留子项、仅删子项；长标题两行显示。
- 当前视图/选中文字设置目标；目标提示线拖动微调。
- 批量逐参数保持/绝对/相对/null；显式转换原始本地动作；查看差异再应用。
- 原字典中的字节串十六进制显示，与已解码的当前中文标题并列，不再把原始字节直接误显示成乱码。
- 多级正则规则，每条规则的级别、捕获组标题模板、字形颜色、留白值；规则启停、重排、增删。
- 页范围与奇偶子集、排除页眉页脚、可选右边界、pt/mm 留白、旋转后的原生方向换算。
- 当前页测试/范围生成预览、点击预览目标区域；冲突、缺失父项和忽略原因。
- 可保存/加载/导入/导出规则预设；根末追加、替换、选中前后、首个子项插入。
- 后台正则超时终止、关闭窗口取消扫描；界面逐页让出事件循环。
- Ctrl+S 更新当前工作文件；Ctrl+Shift+S 另存；原文件保护默认开启，首次输出不同副本。
- 同目录临时写入、flush 与重命名替换；失败保留未保存标志；保存后更新文件名。
- 保存基线关联撤销/重做；可选修改摘要；本机未保存编辑恢复快照。
- 左右面板展开/窄列/隐藏、拖动宽度与偏好记忆；属性应用按钮固定在可见区域底部。
- 虚拟页面和虚拟书签列表、画布缓存上限、旧渲染取消与画布释放。

## 本次未完成或仍有限制

- FitB/BH/BV 在本阅读界面仍按页面边界近似；未增加真正的「适合可见内容」。
- 页面布局切换保持内容锚点，但旋转时未保证同一个文字点始终停留在屏幕原位置。
- 原始 PDF 字典仍只读，未增加任意底层对象/动作链编辑器。
- 自动识别不处理同一行多个行业代码和跨行标题的语义归属；诊断不会保证识别所有表格歧义。
- 书签去重依据本次生成结果的同父级、同标题、同完整目标；未提供跨现有树的智能合并。
- 临时视图选项和快捷键已对齐常用逻辑，未对 Acrobat/PDF-XChange 的每个动作进行逐项实机比对。
- OCR、智能表格、多步骤流水线、分屏、多文档、任意正文、表单签名继续不在本次范围。

## 验证结果

14 项核心测试和 19 项浏览器检查通过。参考文件为 258 页行业分类原始 PDF；第 11–13 页测试生成 61 个分级书签。保存后独立解析和 5 页像素一致性检查通过。尚未完成真实 Windows 11 桌面的验收。
