# Folio PDF Studio 2.8.2

修复已有书签包含高精度跳转坐标或缩放值时，编辑段落后提示「内容预览的原始书签来源发生变化」而无法保存的问题。

原因是原生编辑引擎生成内容预览时，把未修改书签的数值舍入了。现在保留原有数值精度，同时覆盖间接数值和命名目标；不会修改原始读取对象，也不全局替换 PDF 库的行为。真实的书签来源变化仍会被拦截。

本机使用反馈中的183页、33个书签的文档副本，在关闭源文件保护时，为第153页第一段追加「合计付款」，完成首次保存、二次编辑、撤销、重做、重新打开后再编辑保存。五份保存结果的全部书签目标保持一致。MuPDF逐页核对文字与画面，未编辑页面另与原文件比较；PDFium独立核对编辑页面。用户原文件保持不变。

公开 CI 使用具有相同精度坐标的生成样本，不上传用户 PDF。回归测试先复现旧版舍入错误，再验证多次原生重写、实际段落编辑，以及真实来源变化仍会被拒绝。发布须通过完整并行回归，并对最终便携 ZIP 分五组执行34个验收脚本。附件提供源码、验收证据和 SHA-256 校验值。
