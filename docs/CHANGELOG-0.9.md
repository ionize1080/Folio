# 0.9.0 — 编辑稳定性、字体保真与工作区重构

2026-09-14 · 可测试构建，Windows 真机验收待完成。

## 修复

- 找到正则失焦触发点：自动预览曾禁用规则窗口中的全部输入控件。现在仅管理任务按钮，规则输入保留焦点、光标与选区。
- 约 300ms 防抖、中文组合输入期间暂停预览、忽略过期结果、正则未完整时行内提示；取消任务与关闭窗口分离。
- 编辑格式栏取消固定高度裁切与横向滚动。常用字体/字号/颜色/对齐保留在顶部；间距、分栏、方向、位置与叠放放入格式面板。面板关闭入口滚动时保持可见。
- 根据正文区域实际宽度收纳阅读工具，保留用户已有侧栏宽度，新的默认侧栏宽度为 250px。状态栏显示当前页、缩放；画布/缓存诊断移至悬停详情。
- 字体/字号/颜色调整保留正文选区。替换混合格式选区时继承第一段被替换文字的格式；插入和续写继承相邻文字。选区格式操作不改动未选文字。

## 本版增量

- 字体搜索与文档/内置/系统/最近使用分组；读取系统字体的中英文名称别名。选区换字体，或为后续输入选择字体；支持中文等非拉丁文字与拉丁文字分别设置。新增文字可沿用附近样式或保存的默认样式。
- 缺字替代列表展示原字体、实际字体、文字位置，可点击定位。原字体或所选字体能够覆盖字符时优先使用；只有必要字符使用替代字体。
- 自动书签使用规则列表、编辑区、结果区；窄窗口切换规则/结果。预览展示原文、标题、层级、页码；保留冲突与忽略诊断。规则草稿自动保存在本机，结构修改支持撤销/重做。
- 自动/向下/向右/固定框；显示预选理由，可手动切换和重新评估。本地版式分析在后台进行，结果不改变已经开始输入的段落策略。
- 几何遮挡改为提示；可接受当前冲突，或在当前编辑会话仅作标记。文字可拖动和设置坐标/尺寸；支持编辑文字的层级、相对原页面上/下方放置，以及重叠段落切换选择。
- 固定框溢出可选择显示并保留，保留文本内容、按页面边界显示；无效排版/写入失败继续报错并保留草稿。
- 简单有线表格行高联动，保留原边框、底色和后续行文字；表格外内容不自动移动。增高后的遮挡检测使用新行位置，并提示下方覆盖及页外风险。
- 字体、方向、位置、层级、表格变化接入当前段落撤销及既有文档撤销。活动编辑草稿保存文字、样式、几何和选区；规则草稿按文档恢复。
- 本段原文对照、字符样式吸取/应用，作为候选功能的首批实现。

## 继续保留的工作

- Windows 原生中文输入法、字体集合多字面、真实系统缩放的最终验收。
- 图片/表格/文字在统一属性栏中的完整上下文联动；逐结果的冲突标签精细化。
- 全页变化高亮、完整段落格式刷、版式拆分/合并与锁定。
- 复杂表格的合并单元格、倾斜坐标与跨页联动。不要把简单表格的通过结果理解为所有 PDF 表格均适用。

OCR、渲染调度、内容缓存、保存复用、基础原字体复用及基础单元格编辑属于已有能力，本版未将这些重新列为新增功能。
