# Folio PDF Studio 1.9.0

## 编辑与书签

- 上下方向键跨短行、空行时保留横向位置；Home/End 和 Shift 选区按实际排版行移动。
- 输入法合成结束正确标记草稿，并保持一次撤销；忽略重复的最终 input 事件。合成期间按 Escape 不会取消整段编辑。
- 中文句末后的双字首行缩进可识别为新段落；修复论文链接、样式片段边界处标点与拉丁字母之间丢失空格。
- 未解析字体提供“选择整段替代字体”入口，明确选择并支持撤销。
- 修复双栏论文跨栏合并、小型大写标题连入正文；保存后恢复软/硬换行与字体映射，支持扩框后再次编辑。
- 修复中文重排后复制文字重复，以及重开后的连字符与旧裁切框影响继续编辑。
- 字体面板显示当前作用范围、搜索空结果，适配窄窗口与暗色模式；修复异步加载覆盖用户字体选择的问题。
- 表格单元格保存重开后保留逻辑换行，支持继续编辑；中文标点的半字宽负字距按实际字形宽度校验。
- 修复原位等长替换后，标准 PDF 提取和重开编辑多出词内空格的问题，保留其他字形的位置。
- 修复保存后连字符语义改变、带换行替代文字被拆散，以及含内联图片页面重开异常。
- 书签批量缩放支持继承、固定比例、适合页面/宽度/高度/可见内容；支持范围选择、差异预览、撤销重做和保存。原始本地动作或命名目标需明确转换，外部及未解析目标跳过。
- 新增 Unicode 标题大小写转换、粘贴到同级前后、展开/折叠所选子树。
- 新增独立 HTML 目录导出，保留层级、标题样式和相对页码链接；与同名 PDF 放在一起即可使用。外部动作仅显示文字。
- 书签缩放补全八种模式；修复筛选范围、坐标转换、预览失效与首次应用点击问题，补强剪贴板保护和窄屏菜单。

## 测试范围与限制

使用本机 Online Samples、已安装的 Acrobat Pro 和 PDF-XChange，结合桌面操作、真实浏览器键盘输入、原生 PDF 保存重开和发布包测试。[对比分析与样本范围](COMPARISON-1.9.0.zh-Hans.md)及 release 验证附件记录具体结果和哈希。

追加样本覆盖 23 个代表页，并验证保存后再次编辑和实际安装包。样本结果不代表全文件通过。特殊字体编码、需 OCR 的扫描页、没有足够安全排版空间的段落不计入成功编辑。换字体可能改变换行。本机搜狗输入法已实测候选选择、一次撤销和组词期间 Escape；其他输入法未逐一认证。本版不宣称完整复刻 PDF-XChange：动作链编辑、从书签创建 PDF 目录页、按书签重排页面及其专用交换格式仍未实现。

完整解压便携包后运行 Folio.exe；已有版本也可检查更新，无需另装 Python 或 Node.js。
