# Folio PDF Studio 1.5.0

本版修复便携版安装退出、未保存图像预览在缩放后空白，并重做色阶、曲线和页面裁剪交互。

- 更新：解压、包校验成功后才关闭旧版；主图像工作进程随退出停止；独立安装窗口显示阶段；检查新版界面启动，失败时保留或恢复原目录，并记录日志。安装目录保持不变，因此桌面快捷方式正常情况下不需要修改。
- 图像速度：缓存解码后的 1200 像素预览、复用 PDF 原文句柄和当前页；预览结果直接用于页面合成，去掉第二次完整图像计算；正式应用仍使用原分辨率。空间滤镜预览会按缩小比例调整半径，细节请以应用结果为准。
- 色阶：直方图下黑／灰／白三角手柄、输出双手柄、数字同步、RGB／单通道、键盘微调、输出反相及三种取样器。
- 曲线：点曲线、自由铅笔绘制、平滑、粗／细网格、输入／输出数值、可移动端点、删除及切换控制点、直接在图像上取样并上下拖动。
- 裁剪：页面角点／边缘手柄、框内移动、比例约束、三等分／黄金比例／网格、旋转、拉直、四角透视裁剪；Enter 确认、Esc 取消，保存前可恢复裁剪。
- 缩放：编辑会话保留最后一帧，在页面重建后立即恢复；未应用参数不随页面画布销毁。

## 下载和升级

下载 `Folio-PDF-Studio-1.5.0-portable-win-x64.zip`，解压后运行 `Folio.exe`。源码、同提交 Windows 验收报告和 SHA-256 校验文件随发行版提供。

1.3 内置的旧安装器不能在运行前被本版替换。如果你已经遇到点“安装并重启”后退出，请完全关闭 Folio，把旧目录改名留作备份，将本版解压后的 `Folio-PDF-Studio` 放回原来的 D 盘路径，再双击其中的 `Folio.exe`。快捷方式目标仍指向该路径即可，无需改变解压目录名称。文档另行保存，用户设置位于用户配置目录。

从 1.5 开始的更新会等待安装准备完成、确认新窗口启动，并在启动失败时回退。日志位于用户配置目录的 `updates/install.log`，旧程序保留在安装目录旁的 `.backup-*` 目录。

## 范围和限制

操作遵循桌面 Photoshop 常用交互；图像计算为 Folio 自有实现，不宣称 Adobe 算法逐像素一致。编辑工作流是单个 PDF 图像对象，不是 PSD 图层工作区。暂不提供内容识别补边、生成式扩图或 CMYK／16 位专业调色工作流。

普通裁剪是 PDF 裁剪路径，保留源像素；透视校正会生成新的图像资源，可通过文档撤销返回。均不改变 PDF 页尺寸，不栅格化前景文字和矢量。复杂复合对象继续遵循既有安全可编辑范围。

预览直方图来自缩小图像，正式输出保留源分辨率并转换为 8 位 RGB。性能报告提供 1200 万像素样本的实测数据；不同图片压缩格式、电脑和调整组合的耗时会不同。
