# Folio PDF Studio 2.8.2

修復既有書籤包含高精度跳轉座標或縮放值時，編輯段落後提示「內容預覽的原始書籤來源發生變化」而無法儲存的問題。

原因是原生編輯引擎產生內容預覽時，把未修改書籤的數值捨入了。現在保留原有數值精度，同時涵蓋間接數值和命名目標；不會修改原始讀取物件，也不全域替換 PDF 程式庫的行為。真實的書籤來源變化仍會被攔截。

本機使用回報中的183頁、33個書籤的文件副本，在關閉來源檔案保護時，為第153頁第一段追加「合计付款」，完成首次儲存、二次編輯、復原、重做、重新開啟後再編輯儲存。五份儲存結果的全部書籤目標保持一致。MuPDF逐頁核對文字與畫面，未編輯頁面另與原檔比較；PDFium獨立核對編輯頁面。使用者原檔保持不變。

公開 CI 使用具有相同精度座標的產生樣本，不上傳使用者 PDF。迴歸測試先重現舊版捨入錯誤，再驗證多次原生重寫、實際段落編輯，以及真實來源變化仍會被拒絕。發佈須通過完整平行迴歸，並對最終可攜 ZIP 分五組執行34個驗收指令碼。附件提供原始碼、驗收證據和 SHA-256 校驗值。
