# 图片、矢量图与文档组合

工具栏「图片 / 矢量图」可查看页面对象，设置目标页、位置、尺寸、旋转和不透明度，应用后支持撤销。坐标采用 PDF 点，原点在页面左下角。矢量图的描边和线宽修改作用于含描边的元素；更精细的节点、渐变色标、线端和路径参数使用 SVG 源码或 Chatbox 的按 ID 属性修改。

「配置图片服务」可选择 OpenAI 兼容、DashScope、Token Plan 或 Chatbox 当前图像服务。填入接口地址、模型名与密钥，也可选择本地密钥文件。OpenAI 服务支持 URL 或 base64 图片回包；参考图可选标准 multipart 编辑接口或兼容 JSON。额外 JSON 参数用于服务商扩展，不能覆盖模型、认证或提示词。默认提供千问 Token Plan 地址及 qwen-image-3.0-pro 模型；其他服务需按其实际文档配置。使用者的密钥与聊天记录不包含在发布包中。

Chatbox 可以一次传入最多四个提示词并行生图，再逐次插入文档；文档写入串行执行并核对版本，避免并行修改相互覆盖。图片资产按数量与内存限制缓存。付费生图不自动重试。可用提示词：

> 并行生成一张蓝色陶瓷杯和一张绿色叶子插画，插入第 2 页空白处；第一张旋转 25 度，不透明度 70%；在下方添加红到蓝的矢量渐变矩形与白色横线，检查效果。

合并/拆分输出新文件，原文保留。合并列表可调整顺序；拆分支持每份页数或 `1-3;4-6;7,9` 分组，包含当前编辑并重新定位书签。每次最多 100 份。

## 与 PDF-XChange 的对应范围

参考官方 [选择内容的编辑](https://help.pdf-xchange.com/pdfxe11/editing-selected-items.html) 与 [内容编辑工具](https://help.pdf-xchange.com/pdfxe10/content-editing-tools_ed.html)，重点对齐对象选择、精确位置尺寸、旋转和属性编辑流程；[页面编辑说明](https://www.pdf-xchange.com/index.php/knowledgebase/415-Can-I-use-PDF-XChange-Editor-to-edit-pages)用于页面操作对照。

| 工作流 | Folio 2.2.0 实现与边界 |
| --- | --- |
| 图片属性 | 位移、旋转、尺寸、变换矩阵、裁切、透视、调色、透明度和 PDF 混合模式；常用值通过面板，完整已支持参数通过 Chatbox。 |
| 旧图片与重复实例 | 删除或调整选中的图片实例；共享图片的其他实例保留。内嵌图片可导出、调色与删除。 |
| 跨页移动 | 可编辑图片与矢量图指定目标页和坐标；原图像使用完整像素，不以页面截图代替。复杂外部裁剪的移动不保证保留原裁剪形状。 |
| 矢量图 | 自包含 SVG、直线、线性及径向渐变、多色标和透明度；保留 SVG 源码和原生 PDF 路径/渐变，支持重开编辑。 |
| 合并与拆分 | 多文件排序合并、页范围或固定页数拆分、书签重新定位、当前编辑快照；未实现按文件大小或顶层书签自动拆分。 |
| 交互 | 页面原有选择工具与精确属性面板，侧栏拖动、键盘调宽和宽度记忆；并非 PDF-XChange 的完整功能替代。 |

不能编辑任意 PDF 的任意底层属性。复杂嵌套、特殊绘制模式及受保护对象可能只读；SVG 外部资源、脚本、滤镜等未支持特性会被拒绝。原始 PDF shading 的任意节点修改与全实例批量同步编辑不在本版范围。

## 验证与聊天中断

新增测试覆盖旧图片/inline 删除、共享实例隔离、图片变换与调色、矢量渐变保存重开、跨页移动、撤销、过期写入拒绝、密钥保护与通用接口、侧栏拖动、合并拆分。真实 Qwen 主模型调用两个并发图片请求后插入并编辑；独立检查保存 PDF 的图像、原生 shading、可编辑 SVG，并渲染人工查看。

OpenAI 兼容流在网络层检查结束标记，避免底层模型库将残缺响应归为正常停止。工具轮数由 10 增至 32。模型输出到达长度/工具上限，或连接结束却缺少正常完成标记，会显示任务可能未完成；已应用修改保留，用户可发送“继续”。异步保存现在依序等待，避免旧的流式消息写入覆盖最后完成状态。OCR 和文档组合生成的临时原文在成功或失败后释放。历史记录缺失完成标记本身不足以区分手动停止、退出、连接中断或旧版上限。
