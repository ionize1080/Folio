# Folio PDF Studio 2.8.6

[English](RELEASE-2.8.6.md) · [简体中文](RELEASE-2.8.6.zh-Hans.md) · [繁體中文](RELEASE-2.8.6.zh-Hant.md)

## 查找工具

打开「更多工具」或按 **Ctrl+Shift+K**。滚动筛选结果时，搜索框保持可见。按 Esc 可返回功能区。

## 调整圆角

进入「偏好设置 → 通用 → 界面圆角大小」，在 **0–16 px** 之间拖动滑块，默认 **8 px**。拖动时界面实时预览，点击「应用设置」保存，取消会恢复原值。按钮和菜单的轮廓与直边平滑衔接。

## 选区与正文搜索

右键点击 PDF 文字选区可添加高亮或下划线，右键点击搜索结果可复制匹配文字或创建书签。正文搜索支持正则表达式和全词匹配，更改查询会取消旧搜索。批量关闭文档标签页时，在未保存提示中点击「取消」即可停止。
