更新：2026-09-14，0.9.0 实施与验收状态。
版本定位：**编辑稳定性、字体保真与工作区重构**。

本清单仅依据用户重新贴出的上一轮讨论，以及随后确认的“冲突由用户决定、智能预选扩展方向”。撤回上一稿将整个项目历史需求并入本版的处理。本轮已恢复 0.8.0 源码与完整运行包，完成下述改动并进行原生 PDF、浏览器 UI 和样本文档回归。复选框表示已实施；Windows 真机验收单独列示，不等同于已经通过。

## 3. FOCUS-01：正则输入与编辑选区

用户反馈：输入正则时焦点经常被抢夺，需要多次点击才能继续输入。已确认自动预览曾禁用整窗的输入控件，导致正在输入的正则框失焦；现已改为仅管理任务按钮，并处理组合输入与过期结果。

开发待办：

- [x] 排查输入控件/规则卡片重建、异步预览自动聚焦、弹窗焦点管理与全局快捷键，修复实际触发点。
- [x] 自动预览仅更新结果区域；保留正在输入的光标、选区、中文候选状态和滚动位置。
- [x] 中文组词期间暂停校验，提交文字后再更新；约 300 ms 防抖作为初始交互目标。
- [x] 过期预览不得覆盖最新规则；暂时不完整的正则仅在输入框附近提示。
- [x] 字体、字号与颜色操作保留正文选区，设置完成后继续原处输入。

应验证的行为：连续输入、中间插字、中文输入、粘贴、撤销与预览并发都不需要重新点输入框；已有复杂正则取消/超时能力仍有效，不作为全新功能重复开发。

- [x] 编辑格式栏取消横向滚动；宽度不足时收纳次要操作，完成/取消始终可见。
- [ ] **部分完成**：文字/表格编辑上下文与属性面板已调整；图片裁切/替换及所有对象工具的统一联动尚未完成。已有工具调整位置不算新增底层功能。
- [x] 调整默认侧栏与顶部密度，保留用户已经设置的宽度；长书签标题省略时可查看全文。
- [x] 将性能耗时等诊断信息移入详情，状态栏优先显示当前页、缩放、保存和需要处理的问题。

| 位置 | 内容 | 要求 |
|---|---|---|
| 主工具栏 | 打开、保存、撤销/重做、编辑、OCR、页面、书签 | 紧凑且样式一致 |

| 状态栏 | 当前页、缩放、保存状态、问题入口 | 诊断展开查看 |

应验证的行为：Windows 100%/125%/150%/200% 缩放及窄窗口下没有裁切；侧栏已有调整、记忆和收起能力不退化；正文搜索不重新独占常驻横条；PDF 自身滚动与工具栏溢出分开处理。

## 5. FONT-01：字体选择与继承可控

现有基础：0.8.0 已记录部分原字体复用、字号/间距/混合样式继承、缺字逐字符回退以及替代字数提示。本版不能再把“有原字体继承”整体当作从零开发。

开发待办：

- [x] 将字体名称展示升级为可搜索的选择框，提供文档字体、系统字体、最近使用分组，支持中英文名称检索。
- [x] 显示完整名称及可编辑、内嵌子集、缺失等状态；多字体选区显示“混合”。
- [x] 用当前选中文字预览字体效果及换行变化；选中字体对选区或后续输入生效并可撤销。
- [x] 提供中文、英文字体分别设置，以及空白新增文字的“沿用附近样式”和用户默认样式。
- [x] 替代字数成为可点击入口：定位被替换文字、原字体、实际字体与处理选择。
- [x] 修正验证中发现的样式继承缺口，明确混合格式替换规则；不得无提示地统一替换整段。

继承规则：

| 场景 | 默认行为 |
|---|---|
| 原文中插入 | 继承光标处字体、字号、字重、颜色和字符间距 |
| 替换选区 | 继承被替换文字格式；混合格式采用明确规则 |
| 段末续写 | 延续当前段落样式 |
| 空白新增 | 可沿用附近样式或用户默认样式 |
| 混合选区 | 显示混合，操作仅改变用户指定属性 |
| 主动换字体 | 对选区或后续输入生效，保留选区与撤销能力 |

应验证的行为：原字体可用时新增文字保持样式；字体子集缺字时仅处理必要范围，不能只显示原字体名而隐瞒实际替代；字号、字距、行距、首行缩进与中英混排在预览和保存后对应。不能承诺任意 PDF 原字体无损续写。

## 7. CONFLICT-01：冲突提示，用户决定

本轮明确决定：边界相交或内容重叠不能直接禁止用户输入、调整、应用或保存。允许用户有意制造叠字、图文覆盖等效果。

开发待办：

- [x] 统一编辑、应用、保存的前后端判断，取消仅由几何冲突导致的硬性拒绝。
- [x] 实际遮挡以局部标记和可展开提示呈现，提供定位、调整、保留重叠。
- [x] 有冲突仍可选择保存；已接受的相同冲突不在每次保存时反复询问，新增冲突可重新提示。
- [x] 提供当前编辑会话只提示的选择，并允许随时重新查看问题。
- [x] 对有意叠放补齐必要的上移/下移、置顶/置底和重叠对象切换选择；已有对象层级能力直接复用。
- [x] 保存结果忠实保留选择的重叠和层级，不自动修正用户效果。

| 情况 | 处理 |
|---|---|
| 文本框相交、实际字形未遮挡 | 正常编辑保存，不持续报警 |
| 实际内容遮挡 | 提示位置，由用户调整或保留 |
| 超出页面可见范围 | 预览裁切并说明可见边界，允许用户决定；不静默删除框外文本 |
| 无法生成有效输出或写入失败 | 如实报错并保留草稿，不假报保存成功 |

应验证的行为：有意重叠时仍能调整字体、拖动、应用、保存和重开；前端放行后后端不会再次以几何冲突拒绝。

## 8. GROW-01：智能预选扩展方向

现有基础：已有保持栏宽、寻找下方空白的向下扩容。本版新增方向选择和预选机制。

开发待办：

- [x] 支持自动、向下、向右、固定文本框，当前对象的生效策略清楚可见。
- [x] 向下保持栏宽并增加高度；向右扩大文本框右边界，尽量保留原行，不拉伸字形。
- [x] 固定框保留尺寸，溢出可见、可处理，不静默缩字号或截断文字。
- [x] 本地版式 AI 辅助识别标题/正文/表格，几何计算评估右侧和下方空间、邻近对象、栏界及原有换行。
- [x] 预选理由简短可见，两种扩展效果可预览、可切换；低置信度保留原有策略。
- [x] 开始编辑或主动重新评估时确定方向，连续输入期间保持稳定；空间不足时建议切换，不擅自改变方向。
- [x] 用户指定优先；模型不可用时几何规则回退，输入不等待 AI，不重复对全页推理。
- [x] 对居中、右对齐、旋转文字明确锚点；增长方向与文字书写方向分开处理。

| 场景 | 默认建议 |
|---|---|
| 单行标题/标签，右侧留白充足 | 向右 |
| 多行正文 | 固定栏宽向下 |
| 单元格 | 换行并联动行高 |
| 严格对齐的金额、代码或图注 | 尊重原框和对齐约束，不一律右扩 |
| 双栏正文 | 保持所属栏，避免自动扩入另一栏 |
| 两个方向均不足 | 显示备选效果，由用户选择调整或保留重叠 |

应验证的行为：方向不抖动、不抢焦点、手动选择即时生效，保存对应预览；不默认缩字号、移动无关对象或跨栏跨页。

## 13. 版本安排与验收

原计划先修复再重构；本次已将修复合入 0.9.0 测试构建，未单独发行 0.8.1。原计划分工保留如下：

- **0.8.1**：焦点、工具栏裁切与多 DPI 适配，优先解除几何冲突硬拦截。
- **0.9**：字体选择及继承一致性、书签工作区、方向预选、局部排版控制、表格行高联动和新操作撤销。
- 中优先级候选按核心体验完成情况安排，未实施时明确保留状态。

本版验收清单（验证点，不代表新增功能）：

1. 正则连续输入、中文输入法、预览刷新、选区和撤销互不干扰。
2. 多 DPI、缩窄窗口和侧栏切换后控件完整可见，完成/取消固定可用。
3. 原字体可用与缺字回退两类场景均能知道实际字体，保存不发生未提示的样式变化。
4. 故意重叠可继续调整并保存，重开后层级与效果保留。
