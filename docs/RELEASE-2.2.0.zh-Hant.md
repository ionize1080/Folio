## Folio PDF Studio 2.2.0

內建 Chatbox 可並行呼叫圖片模型、將結果插入 PDF，並編輯既有圖片。圖片服務可設定網址、API 金鑰與模型，支援 OpenAI 相容介面和千問原生協定；直接輸入的金鑰由 Windows 加密儲存。

- 圖片移動、縮放、旋轉、裁切、調色、不透明度、混合模式和刪除，涵蓋舊圖片及內嵌圖片，可跨頁移動。
- SVG 線條及原生 PDF 線性/徑向漸層，支援透明度；儲存重開後仍可編輯或刪除插入的向量圖。
- 依順序合併 PDF，依頁數或頁碼範圍分割；包含未儲存修改並保留、重新定位書籤。
- 側欄寬度可拖曳；增加工具工作步數，對連線異常結束、輸出截斷和達到上限提供說明；釋放臨時 OCR 與合併分割文件的快取。

驗收包含原生與介面測試、Chatbox 驅動真實千問並行生圖、儲存 PDF 的獨立檢查、打包程式及更新器測試。結果見本次發行 validation.json。

複雜裁切或巢狀內容仍可能唯讀；SVG 支援經驗證的子集，不宣稱完全等同 PDF-XChange。[操作與對標範圍](https://github.com/ionize1080/Folio/blob/main/docs/GRAPHICS-2.2.0.md)。
