## Folio PDF Studio 2.3.0

文檔工作臺加入本地 Office 轉換、AI 結構複核與歸檔驗證，並同步開放 MCP 能力。

- Word 導出支持保留頁面佈局或重建流動文本；AI 複核標題和有原文依據的表格。Excel 保留前導零、字面公式文本、合併單元格和原文依據工作表。掃描件可先本地 OCR。字符覆蓋率不代表視覺保真評分，複雜文件仍需檢查。
- Word、Excel、PowerPoint、OpenDocument、Markdown、文本、CSV、HTML 與常見圖片轉 PDF。混合格式合併支持排序、自定義文件書籤和保留原書籤。
- PDF/A-1b、2b、3b 轉換後必須通過 veraPDF 獨立驗證。支持任意元數據、線性化、精細壓縮預設、加密、基本表單與圖像/文字導出。
- Chromium 網頁轉 PDF 提供精緻文章閱讀模式，可由 AI 選擇排版參數，保留原文事實。
- OCG 圖層管理、標籤結構樹與替代文字、文檔語言和閱讀順序編輯；veraPDF 驗證 PDF/UA 機器規則。PDF/X-1a、X-3、X-4 支持 CMYK ICC 輸出與**部分結構預檢，不代表完整 ISO 認證**。
- MCP 字體能力包含目錄、覆蓋、度量、字體表、字形輪廓、預覽、子集、可變實例、Unicode 映射修復，以及帶預檢和撤銷的段落字體替換。
- 同一 AI 對話實時跟蹤活動文檔、可見頁面、文字選區矩形和對象選區。頁面渲染包含未保存修改。長任務自動續跑並對寫操作去重，重複失敗或無進展時停止。
- 可搜索工具庫、統一圖標、適配窄窗口的對話框，以及字體、圖層和標籤界面。

發行包包含便攜轉換組件及許可證說明。原有 qpdf 解密不變。文件級處理另存副本，重寫會影響簽名。PDF/UA 的閱讀順序和替代文字質量仍需人工複核。本版本不聲稱完整復刻 Acrobat/PDF-XChange，也不承諾所有 PDF 都能完美轉換；實測結果見驗證報告與對標記錄。
