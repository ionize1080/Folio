## Folio PDF Studio 2.3.0

The document workbench brings local Office conversion, AI structure review and archival validation into Folio and its MCP tools.

- Export editable Word with page-layout or reading-flow reconstruction. AI reviews headings and source-referenced tables. Excel preserves leading-zero identifiers, literal formula text, merged cells and a source-evidence sheet. Scans can receive local OCR before conversion. Fidelity varies by document; coverage measurements are not a visual-fidelity score.
- Convert Word, Excel, PowerPoint, OpenDocument, Markdown, text, CSV, HTML and common images to PDF. Combine mixed formats in a reorderable list, with file bookmarks and retained source outlines.
- Convert PDF/A-1b, 2b or 3b and require independent veraPDF validation. Inspect arbitrary metadata, optimize/linearize, encrypt, fill/create basic forms, export text/images and choose detailed image-compression settings.
- Chromium website printing includes a refined article mode with optional AI typography selection. Extracted article content is preserved without factual rewriting.
- Inspect and edit OCG layer states, names and ordering; inspect and update tagged structure, language, alternative text and reading order. Validate PDF/UA machine rules with veraPDF. PDF/X-1a, X-3 and X-4 production includes CMYK ICC selection and **partial structural preflight**, not complete ISO certification.
- MCP font engineering exposes catalog, coverage, metrics, OpenType tables, outlines, previews, subset generation, variable instances and cmap repair. Safe paragraph font replacement uses the native layout engine, preflight and undo.
- Same-chat context follows the active document, visible page, text-selection rectangles and selected objects. MCP rendering returns actual pixels including unsaved edits. Automatic continuation retains completed tool results, deduplicates writes and stops repeated failures or no-progress cycles.
- Searchable tool library, consistent icons, responsive dialogs, keyboard navigation and dedicated font/structure controls.

The release includes portable Ghostscript, LibreOffice, Temurin Java and veraPDF with their notices. Existing qpdf decryption remains unchanged. Rewriting a document can invalidate signatures; file utilities save copies. PDF/UA semantic quality requires human review. This release does not claim complete Acrobat/PDF-XChange parity or perfect conversion for every PDF. See the validation JSON and practical benchmark for measured results.
