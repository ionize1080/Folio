# Folio PDF Studio 2.0.2

- 從固定 Chatbox 開源源碼構建，與 Folio 共用一套 Electron，移除重複運行時。
- 移除空的“Folio Qwen”預設；API、模型和會話採用穩定用戶目錄，升級保留真實配置。
- 無額外模型 token 的本地進度提示；修復 AI 遮擋更多工具和未保存確認彈窗、刷新後審批圖標不同步。
- 校準、留白、書籤樣式和目錄識別直接調用已有本地引擎；僅複核歧義/低置信項。補齊圖片座標說明、分頁讀取、OCR/快照緩存，避免整樹回傳和反覆查詢。
- 在原 PDF MCP 源碼基礎上增加批量讀取和原子批量編輯，共 62 個文件工具；源文件保護、失敗回滾、分頁和新路徑檢查。

- 重繪自動書籤、AI 和重複圖標；統一對齊、控件尺寸、中性選中態及菜單鍵盤導航，覆蓋三種語言與明暗主題。僅自動審批圖標標紅。

真實 Qwen、桌面鼠標/鍵盤、10 份真實 PDF 樣本已用於本地驗收；Windows Actions 再執行源碼構建、迴歸、真實 API、便攜包和更新器驗證後發佈。詳細結果及校驗和隨發佈提供。未單獨驗證 Windows 10 21H1。

配置位置：`%APPDATA%/Folio/Chatbox`。首次升級從舊的版本目錄複製，原目錄保留用於回退。
