# Folio PDF Studio 0.7.0 · 页面内编辑重写

顶部“页面编辑”现在直接在主阅读区工作，不打开文字编辑对话框。

- 点击页面上的段落即可定位光标；直接输入、退格、拖选、双击选词、复制粘贴。中文输入法组词期间保留候选位置。
- 字符、换行、分栏、选区与光标统一使用 MuPDF Story 的 PDF 字形坐标。页面预览为矢量 SVG；应用时嵌入同次生成的可搜索 PDF 片段，无第二次排版。
- 字号、行距、粗斜体、颜色、对齐与单/双/三栏在阅读区上方调整。右下角手柄修改宽高。“接续段落”后点击下一段，将其加入当前文本流。新建文字在空白处点一下开始。
- 在同一文本流内增删内容会重新换行，并在栏之间连续填充。独立段落、独立栏及其他页面不会自动移动。
- 点击另一段、完成编辑或保存 PDF 时应用草稿。Ctrl+Z / Ctrl+Y 在输入时撤销/重做本段操作；完成后可使用原有文档撤销/重做。Esc / 取消本段放弃当前草稿。缩放后维持输入与选区。
- 本地 AI 使用 Paddle PP-Structure PicoDet CDLA + RapidLayout + ONNX Runtime CPU，区分正文、标题、表格、图片、图题、表题、页眉、页脚、参考文献和公式区域；与原生文字坐标共同产生候选。模型不生成或改写文字。
- 修正 Office PDF 的文字空间字号未乘变换矩阵导致的串行、错误分组、过大范围；保留共享文字组的完整来源签名，包括空白操作符。可处理无裁剪的填充加描边文字组。
- 溢出、缺字、字形到原文映射不完整、来源变化、与其他文字/表格线/图片碰撞时阻止应用。修正 Story 恰好落在线框底部时的续排边界；数字与西文单独使用 DejaVu 字体，避免继承 CJK 字体特定上下文替换问题。
- 排版与 PDF/OCR 使用独立的常驻进程，快速输入时合并请求并丢弃旧版本的结果。

## 使用与边界

完整解压 Windows 包，运行 Folio.exe。无需安装 Python、Node 或下载模型。建议解压到新目录。

当前支持未旋转、原点为零、UserUnit=1 的横向原生文字页。扫描图像的文字仍需 OCR 校对，不能直接变成可擦除的页面段落。复杂嵌套和裁剪保留为只读。

编辑段落采用内置中西文字体和整段格式，尚不能完整保留任意原字体、段内混合样式、字符间距和特殊排版。少数原文范围在替换字体后可能溢出，需要调行距/字号/范围或接续相关段落；软件不会自动缩字并静默提交。

表格与公式检测用于保护边界，尚不是单元格语义编辑或公式结构编辑。没有跨页文章续排、任意形状避让、整份 PDF 导出 Word，也不能视为 Acrobat 全功能替代品。

继续修改已应用文本流请保存 .folio 工程；普通 PDF 输出后的 Form 片段不保证能重新恢复相同段落模型。尚未提交的当前输入草稿在程序异常终止时不能保证恢复，请完成编辑或保存。
