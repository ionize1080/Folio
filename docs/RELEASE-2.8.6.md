## Find a tool

Open **More Tools** or press **Ctrl+Shift+K**. The search field stays above the ribbon while you scroll through filtered results. Escape returns focus to the ribbon.

## Set the corner radius

Open **Preferences → General → Corner radius**. Use the slider from **0 to 16 px**, with **8 px** as the default. Changes preview immediately. Apply saves the value and Cancel restores the previous value. The curve meets its straight edges smoothly, including on short buttons.

## Work with selections and search results

Right-click a PDF text selection to highlight or underline it, or use a result’s menu to copy the matched text or create a bookmark. Full-text search supports regular expressions and whole words. Editing a query cancels the previous scan. Closing multiple document tabs stops when you cancel an unsaved-document prompt.
