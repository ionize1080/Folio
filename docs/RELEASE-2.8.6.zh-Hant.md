# Folio PDF Studio 2.8.6

[English](RELEASE-2.8.6.md) · [简体中文](RELEASE-2.8.6.zh-Hans.md) · [繁體中文](RELEASE-2.8.6.zh-Hant.md)

## 尋找工具

開啟「更多工具」或按 **Ctrl+Shift+K**。捲動篩選結果時，搜尋欄會保持可見。按 Esc 可返回功能區。

## 調整圓角

前往「偏好設定 → 通用 → 介面圓角大小」，在 **0–16 px** 之間拖曳滑桿，預設為 **8 px**。拖曳時會即時預覽，按「套用設定」儲存，取消則恢復原值。按鈕和選單的輪廓與直邊平滑銜接。

## 選取範圍與內文搜尋

在 PDF 文字選取範圍上按右鍵可加上醒目提示或底線，在搜尋結果上按右鍵可複製符合的文字或建立書籤。內文搜尋支援正規表示式與全字匹配，變更查詢會取消舊搜尋。批次關閉文件分頁時，在未儲存的提示中按「取消」即可停止。

跨頁選取文字並加上醒目提示時，各頁只會標記實際選取的文字。在頁面整理器按空格鍵可預覽目前焦點所在的頁面，再用方向鍵瀏覽相鄰頁面。

## 拖曳 Windows 視窗

拖曳首頁頂端的文件標題或文件分頁旁的空白處即可移動 Folio。視窗最大化時，向下拖曳可還原。切換文件後，頂端的最小化、最大化或還原、關閉按鈕仍可正常使用。
