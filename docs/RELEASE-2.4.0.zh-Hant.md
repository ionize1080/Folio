## Folio PDF Studio 2.4.0

- 圖像與向量工作室直接整合於 Folio。支援新增、匯入、編輯、複製、移動及刪除；修復工具、選取與遮色片、圖層與智慧濾鏡、高位元深度色彩、貝茲節點、布林運算、文字、漸層與效果均提供人工介面及 MCP 操作。
- 統一標題列與精簡工具列，移除巢狀編輯器的重複介面。書籤與組織有獨立分類；AI 保留顯眼的獨立入口。
- 畫布可顯示透明格線、純色或 PDF 頁面，並調整疊加強度。新增適合作品／PDF 頁面、寬高適配、置中及自訂縮放；圖像最高 12800%，向量最高 64000%。縮放不會改變 PDF 放置位置。
- PDF 僅儲存最終作品；`.folio` 保留可繼續編輯的圖層、遮色片及來源。替換現有物件時保留原有繪製順序。
- 縮圖組織支援多選、拖曳排序、插入、刪除、擷取、取代、複製、旋轉、反序、分割、裁切、尺寸及頁面標記。
- Word／Excel 匯出具有直接入口，預設本機處理，無須 LibreOffice；完整發行包保留用於 Office 匯入的轉換元件。修正 Qwen 多輪工具呼叫的上下文順序，並讓 AI 辨識目前的編輯工作階段。
- 13 組獨立測試與兩個編輯引擎建置平行執行；發行前再次驗證實際執行檔。

詳見[編輯工作區說明](https://github.com/ionize1080/Folio/blob/main/docs/CREATIVE-STUDIO.md)。格式與效果的相容性以整合引擎為準，不宣稱與 Adobe 產品完全一致。
