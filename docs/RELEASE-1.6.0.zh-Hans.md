# Folio PDF Studio 1.6.0

[English](RELEASE-1.6.0.md) · **简体中文** · [繁體中文](RELEASE-1.6.0.zh-Hant.md)

本版默认使用英文，提供英文、简体中文和繁体中文即时切换。

## 改进

- 顶部常驻地球图标和语言名称，首选项提供同一设置。支持语言自称、键盘操作、焦点提示及明暗主题。
- 语言选择保存在本机。切换更新按钮、提示、弹窗和状态，不重新打开文档，不重置未保存的修改。
- 离线语言包覆盖书签规则、文字与图像编辑、表格、OCR、大文件和更新提示。文档内容、名称、输入值和 OCR 校对不参与翻译。
- 便携版安装器使用所选语言；更新窗口根据界面语言显示本版对应发行说明，缺少对应版本时回退英文。
- README、文档索引和发行说明默认英文，提供简体、繁体中文直接链接。
- 新增占位符一致性、默认与回退行为、内容保护测试。实际 Windows EXE 验收覆盖语言记忆、弹窗覆盖、键盘、不同窗口宽度和明暗主题，并继续运行编辑回归。

## 升级

下载 `Folio-PDF-Studio-1.6.0-portable-win-x64.zip`，完整解压后运行 `Folio.exe`。发行附件包含源码、验收结果和 SHA-256 校验值。已有语言选择保留，尚未选择的用户默认进入英文界面。

安装保持原程序目录名称，因此指向该路径的快捷方式保持有效。设置位于用户配置目录。1.3 的旧安装器不能在运行前被替换；如果此前点击安装后退出未重启，请完全关闭 Folio，将旧目录改名备份，再把新解压的 `Folio-PDF-Studio` 放回原路径，启动其中的 `Folio.exe`。

## 范围与限制

本版提供三套完整界面语言包。其他语言需要完成翻译审阅与界面验收后才会加入选择器。OCR 语言设置独立，不扩展识别模型能力。Windows 原生对话框遵循系统语言，底层技术诊断可能保留原文。历史发行说明保留当时的表述。

原有 PDF、字体和 OCR 边界继续见 README。Windows 自动化不能替代真实硬件、混合 DPI 和输入法验收。附件报告标识实际测试的源码、EXE 和应用包；不将旧版本通过记录计作本版证据。
