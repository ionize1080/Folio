# Folio PDF Studio 2.8.1

關閉原檔保護時，首次儲存也會在核對原始位元組後直接附加修改，後續繼續增量儲存。外部程式變更過檔案時，仍會阻止不安全的覆寫。

- 相鄰文字選取合併為連續的行色塊，段落編輯後也適用。閱讀偏好設定新增獨立的選取邊框開關，預設關閉；複製內容保持原樣。
- 拖曳選取時重用本次手勢的頁面和字元測量結果；一般捲動不再重複測量、重繪未變更的選取。
- 長書籤只在確實放不下時佔兩行，短標題維持原行高；清單仍按可見區域載入。偏好設定分類切換立即完成，避免控制項在點擊過程中移動。
- 合併最新 modern design 的字型工作台、預覽控制項及視窗尺寸調整。字型資訊重用，字元覆蓋檢查不再單獨請求；長文字在大字號下仍顯示可容納的預覽。

本機完成 9 個 PDF、99 輪儲存檢查，涵蓋指定的已整理金融報告、表單、掃描檔，以及文字、影像、向量、OCR 層、書籤修改、復原重做、完整重寫及重新開啟。MuPDF、PDFium、pypdf 獨立核對輸出。三個同時開啟的文件也通過並行儲存、實際本機 OCR、修改隔離及 18 次分頁切換。測試編輯副本，原始樣本未變更。

本機小型樣本的一次 30 步文字拖曳中，字元幾何測量從 686 次降至 35 次；一般捲動無需測量選取字元。按實際處理時間排程儲存後，1 萬條新書籤的序列化從約 1.44 秒降至 0.19 秒（三次本機測量）；後續單條改名只附加一個物件。這些是指定情境的測量結果，並非對所有 PDF 的速度承諾。

發佈必須通過同一提交的 GitHub Actions 並行檢查。最終可攜 ZIP 另分五組執行 33 個驗收腳本。公開 CI 使用產生樣本與固定版本的公開 PDF，不上傳使用者本機文件。附件提供原始碼、驗收證據及 SHA-256 校驗值。
