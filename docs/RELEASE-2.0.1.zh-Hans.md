# Folio PDF Studio 2.0.1

修复 AI 侧栏输入与中文输入法焦点，移除侧栏和更新器的 PowerShell 运行依赖。

侧栏采用独立激活的无边框伴随窗口，跟随 Folio 位置、显示状态和前后台顺序，不再跨进程 SetParent。Chatbox 在任务栏保持单独可见。修复独立窗口切回侧栏的尺寸干扰，以及输入法候选框遮挡。Chatbox 1.20.3 的模型 SDK、网络适配器和出站请求头转发保持不变。

侧栏和更新器使用包内 Python 与 Windows 原生接口，无需目标机安装 Python、PowerShell 或 WebView2。更新保留路径安全检查、SHA-256 与版本校验、明确提交确认、新窗口健康检查和失败回滚。

已通过 268 项单元测试、侧栏切换与输入回归、设置与审批、真实 Qwen API、真实模型 PDF 书签创建与看图、60 项 PDF 工具，以及实际成品更新与失败回滚。computer-use 已用鼠标点击真实侧栏输入框，输入中英文并按退格；实际按 n、i、空格，显示搜狗候选框并将“你”上屏。

目标环境：Windows 10 21H1 x64，PowerShell 进程被禁用，无 WebView2。本次验证在现有 Windows 主机完成，未在独立的 21H1 目标机现场验证；其他输入法、多显示器和其他缩放组合仍需目标环境复核。

安装：完整解压便携 ZIP 到可写目录，运行 Folio.exe。旧版本更新器仍依赖 PowerShell，因此在禁用 PowerShell 的机器上，请手动解压本版进行首次升级；从 2.0.1 发起的更新使用新运行时。确认文档与 API 配置正常前保留旧目录。
