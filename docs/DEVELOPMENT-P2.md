## 已实现

- 未嵌入字体按完整名、PostScript 名、家族别名和粗斜体匹配系统字面；显式支持 Times New Roman / Arial / Courier New 的度量近似后备，明确区分嵌入、标准、系统同名、度量近似和未解析来源。未知字体无法解析时保留草稿，要求明确选字体，避免静默换成通用字体。
- 字体来源进入字符样式和编辑状态栏；短编号标题与长正文采用保守的段落边界判定，普通视觉换行仍接续。
- RapidOCR 检测框过滤前诊断，保留空/低分结果；疑难裁切复用检测做 0°/180°识别比较，候选冲突和疑似穿越表格线进入复核。方向候选携带相应 PDF quad；未确认疑点不能写入最终文字层。
- 大于 768 MiB 的 PDF 自动进入独立大文件工作区：原生按页渲染、跳页/缩放、书签修改/删除子树/新增/撤销、按层级正则扫描文字预览并追加、另存书签副本。
- 大文件原件以受控句柄管理，不进入前端完整字节数组。书签写回采用磁盘复制 + 增量更新 + 重开验证 + 同目录临时文件替换，保留未修改书签动作字典。支持密码输入，原件改变后拒绝继续操作。
- 修正 `.folio` 拖入与文件选择大小限制不一致。普通工作区限制仍保留；大文件入口暂设 8 GiB 防护上限，**不是已通过 8 GiB 真实文档验收的宣称**。

## 当前边界

- #2 尚未完成任意字体/混合字体/对象保留的全部矩阵，系统同名字体不等于证明字形完全一致；段落边界仍为保守几何启发式。
- #3 暂不自动按单元格重建跨格识别框：可检测的穿线风险交人工复核；无框线/复杂跨格尚未解决。保留候选供选择不等于支持任意单框手动重跑。暂未实现区域补识别与旧人工状态的通用合并。
- 大文件工作区当前只覆盖阅读和书签另存；OCR、段落编辑、工程和恢复仍走普通工作区，不能宣称多 GB 全功能支持。保存仍要复制完整原件，时间和磁盘与文件大小相关。损坏/修复后不能增量保存的 PDF 明确拒绝，目标原文件保持不变。
- 大文件页图像上限 1600 万像素；不复用 PDF.js 的源文件长度字节数组。当前不提供连续滚动、正文选区和全文搜索。
- 关闭大文件窗口后恢复原普通会话；大文件书签尚无自动草稿恢复，应及时另存。
