# Folio PDF Studio 1.9.1

本版集中改善教材內嵌中文字型、分段、原位增刪和帶標籤 PDF 的儲存重開。

- 識別教材中的舊 Apple TrueType 字型格式，保留既有字形，避免整段誤換字型。
- 缺字比對只載入評分所需的字形輪廓，保留相同候選和評分，降低首次推薦等待。
- 寬行距正文按重複行距分段，保留真正段距；換行處六位代碼不再誤認為標題。
- 表格底色不再當成框線，減少虛假小儲存格。
- 支援中文擷取軟換行內長短增刪的局部排版，盡量保持原始基線。
- 原文字已經覆蓋的背景圖片、已證明不含文字的背景複合圖形不再誤報衝突；前景及未知內容繼續檢查。
- 完整連續的同一語義段落可跨多個 MCID 儲存，保留結構樹及 ParentTree；局部標籤範圍和連結仍受保護。
- 統一儲存與重開時的裁切邊界容差；負詞距按實際字形前進量檢查。

[深度編輯測試報告](DEEP-EDIT-1.9.1.zh-Hans.md)記錄 20 個選定頁面、多位置長短插入與刪除、整本儲存、真實鍵盤測試，以及本機 PDF-XChange 與 Acrobat 的實測觀察。阻止和失敗不計作成功，不宣稱已達到完整競品水平。發行附件不包含原始樣本 PDF 或擷取正文。

完整解壓縮便攜 ZIP 後執行 Folio.exe。驗證附件記錄測試原始碼和實際應用程式的 SHA-256 雜湊。
