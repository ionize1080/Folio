# Folio PDF Studio 1.9.1

本版集中改善教材內嵌中文字型、分段、原位增刪和帶標籤 PDF 的儲存重開。

- 識別教材中的舊 Apple TrueType 字型格式，保留既有字形，避免整段誤換字型。
- 保留字型壓縮時的共用字寬，並從已儲存 PDF 的可靠字寬記錄修復舊問題檔案，避免新插入的漢字在再次編輯後疊在一起。
- 儲存檔案未寫明字重時，從內嵌字型還原實際字重，避免原有粗體在再次編輯時被誤換成標準體。
- 共用字型快取完整寫入後再原子發布，避免字型選擇與排版並行時讀到尚未寫完的字型或中繼資料。
- 缺字比對只載入評分所需的字形輪廓，保留相同候選和評分，降低首次推薦等待。
- 介面重新載入或渲染程序退出後釋放遺留原文資源，避免反覆重開觸及資源上限；執行中的原生工作繼續保留所需檔案。
- 寬行距正文按重複行距分段，保留真正段距；換行處六位代碼不再誤認為標題。
- 表格底色不再當成框線，減少虛假小儲存格。
- 支援中文擷取軟換行內長短增刪的局部排版，盡量保持原始基線。
- 原文字已經覆蓋的背景圖片、已證明不含文字的背景複合圖形不再誤報衝突；前景及未知內容繼續檢查。
- 完整連續的同一語義段落可跨多個 MCID 儲存，保留結構樹及 ParentTree；局部標籤範圍和連結仍受保護。
- 統一儲存與重開時的裁切邊界容差；負詞距按實際字形前進量檢查。
- 快速預覽與精排使用一致的缺字推薦，輸入不再等待字型評分完成。
- 背景預覽保留標籤語義上下文；獨立繪製的拼音與基字對應被破壞時明確阻止儲存，避免悄悄標錯字。
- 修復帶書籤中繼資料的整本儲存誤報；連續儲存保留原始書籤目標和縮放參數。
- 局部換行遵守中文行首、行末標點禁則；獨立菱形清單項目分別識別，同一項目的續行保持在一起。
- 不再讓沒有繪製面積的純空格阻擋擴框，頁面實際留白可用於長插入；可見文字、圖形和儲存格邊界仍會限制擴展。

自動化測試中，完成編輯並儲存仍出現數秒至數十秒的等待，包含動作等待與排程。預覽狀態計時未綁定本次輸入，可能捕獲陳舊狀態，不能作為有效的新排版延遲；報告記錄了這一限制和獨立的前台補測。密集練習題、交錯物件仍有分段與編輯限制；獨立注音暫不支援隨基字自動移動。跨原行重排可能遺失 PDF 的逐字間距，裝飾性底色也尚未完整識別為文字容器；帶超框提示繼續完成編輯可儲存超出原框和底色的文字，重開按已儲存文字重新推斷範圍後可能不再提示。

[深度編輯測試報告](DEEP-EDIT-1.9.1.zh-Hans.md)記錄 20 個選定頁面、多位置長短插入與刪除、整本儲存、真實鍵盤測試，以及本機 PDF-XChange 與 Acrobat 的實測觀察。阻止和失敗不計作成功，不宣稱已達到完整競品水平。發行附件不包含原始樣本 PDF 或擷取正文。

完整解壓縮便攜 ZIP 後執行 Folio.exe。驗證附件記錄測試原始碼和實際應用程式的 SHA-256 雜湊。
