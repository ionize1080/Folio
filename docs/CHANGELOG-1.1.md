# 1.1.0 RC1 更新说明

基于 1.0.0 RC1 P2。交付完整源码 ZIP 和完整 Windows x64 portable ZIP。

## 规则与书签

规则草稿按操作分别保存，优先恢复本文档上次输入；新文档可复用最近参数。关闭、取消及重新启动后仍可恢复。计算结果和对象 ID 不持久化，每次重新预览。最近规则最多 20 项，支持命名收藏与清空历史。

书签输入框新增 `.*` 正则及 `Aa` 大小写开关，页码条件独立输入。路径祖先可见，但“选择匹配项”和筛选批量规则只处理真正匹配的节点。非法表达式保留当前可见列表并禁止应用；后台计算超时可终止，旧结果不会覆盖新输入。

## 编辑与字体

PDFium 原始字符原点、基线与边界进入编辑模型。未修改直接退出不创建 PDF 重写；无改动选中段落继续显示原页面。等宽小修订优先保持每字锚点，其他局部修改尝试在原行内吸收变化。不能可靠处理时退回 MuPDF Story，并明确显示“段落重排”。修改字号、框宽、复杂脚本或分栏使用段落排版。用户可在格式中手动切换整段重排。

字体引擎对原字体子集提取标准化轮廓、多字符栅格形状和 advance 字宽；在本机及随包字体中按覆盖率与实际字形排序，名称只用于显示。匹配按样本证据给出置信，不把“样本一致”误称为整套字体绝对相同。原字体已有字符仍用原字体，缺字优先找同形候选，随后找相近字体；替代详情显示实际使用字体。字符仍无覆盖时禁止静默丢字。

## PDF 与数据输出

qpdf 通过 pikepdf 调用随包 libqpdf DLL，密码只在本次请求内存使用。可选原始文件、当前已应用修改或另一 PDF。输出独立的 `-decrypted.pdf`；错误密码允许重试，取消不写文件。引擎校验页数与加密状态，不栅格化页面。含签名文件在另存前提示重写会影响签名有效性。

表格窗口可导出 CSV 和 XLSX。XLSX 单元格统一写为文本，保留 00123、长编号、日期原文和公式样式文本，保留合并范围。CSV 有引号与换行转义，易被解释为公式的开头会增加单引号。

Folio 1.1 新建的 OCR 层带专用标识。对重新打开的文件再次应用 OCR 时，只替换这些已知层；其他来源的隐藏文字层不自动删除。

## 保留的能力

P2 已有的段落合并拆分、结构锁定、同页文本框接续、表格结构编辑、全页输出对照、撤销和原文件保护继续保留。跨页文章重排、任意扫描字形的通用字体识别、字体云服务及文档签名仍不属于本次交付。
