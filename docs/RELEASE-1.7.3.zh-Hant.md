# Folio PDF Studio 1.7.3

本版改善教材、技術手冊與統計年鑑的智慧目錄辨識。

- 智慧目錄入口移至主工具列；目錄 OCR 與較耗時的正文 OCR 分開控制，選項直接可見。
- 雙欄目錄先左後右讀取，跨頁維持層級，辨識教材單元、課號、篇目及手冊章節編號。
- 保留無頁碼的群組標題與漏辨識頁碼的掃描條目，明確標示待複核。
- 密集掃描目錄漏掉細小頁碼時，以較高解析度重辨識頁碼欄，保留 OCR 信心值與人工確認要求。
- 正文比對相容課號、裝飾符號與作者署名；優先完整編號標題，減少表格儲存格及單位署名的誤判。
- 利用字型類別輔助無縮排年鑑的層級判斷；取消勾選父項後，子項不會誤掛至上一章節。
- 快取正文正規化文字，減少重複計算。

已使用本機三本教材、兩本技術手冊、四本年鑑實測，並完成演算法回歸、瀏覽器互動與發行程式真實離線 OCR 檢查。validation 附件記錄實際測試套件雜湊；第三方樣本 PDF 不隨套件散布。

目錄擷取不代表完整、正確的書籤樹。重名標題、低清掃描、中英對照行及複雜年鑑層級仍需複核；正文 OCR 建議先縮小範圍。原 PDF 書籤僅用於獨立評估，未參與生成演算法。

下載 portable Windows x64 ZIP，完整解壓縮後執行 Folio.exe。支援英文、簡體中文與繁體中文。
