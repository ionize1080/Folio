## 隔离与限制

一次带模型运行时的界面测试因尝试连接 Microsoft 遥测地址被自动审核拦截。后续测试由 tests/offline-run.py 在 Linux 内核层拒绝所有 IPv4/IPv6 socket，验证拒绝有效后才启动浏览器和 Python 子进程；这只限制测试环境，不依赖浏览器页面拦截规则。

未完成真实 Windows 桌面启动、系统输入法人工操作、不同 GPU 和混合 DPI 实机验证。字体与复杂 PDF 排版的适用范围见 CHANGELOG-0.8.md。
