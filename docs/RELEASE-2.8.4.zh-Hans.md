# Folio PDF Studio 2.8.4

按 Ctrl+Shift+P 可查找命令。OCR 和书签工作台更新了操作控件，阅读视图增加纸张色调。编辑段落时可用 Ctrl+B 和 Ctrl+I 切换粗体和斜体。

编辑受支持的横排段落时，在准备编辑底图与字体期间即可原位输入或撤销。返回已分析的页面时会复用解析结果。原生进程复用字体名称索引，字体文件有变化时更新索引。启用恢复阅读位置后，会跳过多余的 PDF 打开动作查询。

增量保存会保留原交叉引用格式、文档标识及尾部字典中的元数据，也能读取线性化 PDF 首个尾部字典中的元数据。回归测试覆盖经典交叉引用表、交叉引用流和旧版 Folio 保存的文档。群晖 DS1621+ 中文规格书的段落修改后可重新打开并搜索到新文字，旁栏、上标脚注和其余七页的渲染对比一致。七份 PDF 的书签增量保存通过了 qpdf 检查，MuPDF 逐页比对了全部 305 页的文字、几何尺寸及 0.32 倍渲染，PDFium 比对了 19 个抽样页的 0.5 倍渲染，结果均一致。Adobe Reader XI 尚未实机验证。

对与相邻行共用 PDF 文本对象的无标签段落，当能够还原文本位置和状态时，Folio 会保留内容流的阅读顺序。双栏 NAACL 论文修改后重新打开，按内容流提取的顺序与源文件一致，只有摘要增加了 `Test.`。

Windows 验证流程覆盖文档、编辑、保存和更新，并测试打包后的应用。发布附件包括便携版 ZIP、源码 ZIP、SHA-256 校验值和对应发布提交的验证报告。
