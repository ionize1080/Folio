# Folio PDF Studio 1.2.0 RC1-P4

## 编辑修复
- 点击进入时固定PDF坐标；编辑中按字符位置命中，避免光标跳到行首。
- 未确认的溢出文字限定在编辑框内显示；保留完整草稿，提供扩框或保留溢出选择。
- 窄单元格不再受“两倍字号宽度”限制；支持拖动或输入行高，整行边框和后续行同步移动。
- 仅修改粗体、斜体或颜色且文字、字体度量及段落参数不变时，优先保留原字位，减少不必要重排。
- 点击原文不会仅因进入编辑就自动改变单元格高度。

## 验证
发布前必须通过原生Windows完整回归、打包完整性检查、实际portable EXE的编辑保存及窄单元格扩高保存。Release附带本次成功构建的验证JSON和SHA-256。
此前随机10页实文档测试的范围与限制见 [回归记录](editor-p4-validation.md)。

## 已知边界
- 字体缺字（例如某些文档的℃）仍可能触发替代字体、重排和行高变化，不能保证所有字体完全保真。
- 自动测试不等同于真实输入法、混合DPI和不同显卡的人工验收。
- 沿用P3/P2的大文件、复杂文字和OCR限制，本补丁不声称这些范围全部解决。

## 运行
下载portable-win-x64.zip并完整解压，运行Folio.exe。无需另装Python、Node或OCR模型，请保留整个目录。完整离线源码为单独的source.zip附件，区别于GitHub自动生成的Source code存档。
