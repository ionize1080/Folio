## Folio PDF Studio 2.5.0

- 修正編輯圖像時滑鼠停留使圖片變白；右鍵可直接進入快速調整、裁剪或圖像工作室。開啟工作室及替換回 PDF 時保持旋轉、鏡像、裁剪路徑與原有放置位置。
- 圖片選擇器顯示縮圖、頁碼及尺寸；讀取頁面物件時仍可立即建立作品。兩個工作室預設使用 PDF 參考背景，提供平移、適合畫布、畫布大小及位置尺寸控制。
- 選單關閉後清除反白；統一下拉框樣式與對齊，工作室介面字型跟隨 Folio 的語言和系統字型，數字控制項保持統一字寬。
- **組織 → 插入空白頁** 支援繼承參考頁、標準紙張或自訂尺寸，設定橫直向、數量，以及在指定頁之前或之後插入。書籤跳轉隨頁序調整。
- **Chatbox 設定 → 生圖模型提供方** 可明確設定 Qwen Token Plan、DashScope 和相容生圖介面。儲存位址、模型和金鑰後，可測試並直接查看預覽。已使用真實服務驗證 Qwen 生圖及參考圖編輯。
- 段落編輯按需檢查單頁，重用有限快取，並在編輯命令取得焦點時提前準備。保持原字型標識穩定；修正書籤座標序列化誤差阻斷文件快照和 AI 頁面渲染的問題。
- 統一 JPEG2000 的 WASM 解碼設定，段落預覽及儲存重開保持照片可見；修復行尾空格導致的假溢出，並改善編號小節與正文的分段。
- Windows Actions 平行建置兩個 Rust/WASM 引擎，執行 15 組驗收；最終程式在兩個隔離通道中複測，通過後發佈可攜版、原始碼、校驗值與驗證報告。

詳見[工作流程與驗證說明](https://github.com/ionize1080/Folio/blob/main/docs/WORKFLOW-2.5.0.md)及[工作室指南](https://github.com/ionize1080/Folio/blob/main/docs/CREATIVE-STUDIO.md)。
