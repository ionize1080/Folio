# Folio PDF Studio 2.0.1

修復 AI 側欄輸入與中文輸入法焦點，移除側欄和更新器的 PowerShell 運行依賴。

側欄採用獨立激活的無邊框伴隨窗口，跟隨 Folio 位置、顯示狀態和前後臺順序，不再跨進程 SetParent。Chatbox 在任務欄保持單獨可見。修復獨立窗口切回側欄的尺寸干擾，以及輸入法候選框遮擋。Chatbox 1.20.3 的模型 SDK、網絡適配器和出站請求頭轉發保持不變。

側欄和更新器使用包內 Python 與 Windows 原生接口，無需目標機安裝 Python、PowerShell 或 WebView2。更新保留路徑安全檢查、SHA-256 與版本校驗、明確提交確認、新窗口健康檢查和失敗回滾。

已通過 268 項單元測試、側欄切換與輸入迴歸、設置與審批、真實 Qwen API、真實模型 PDF 書籤創建與看圖、60 項 PDF 工具，以及實際成品更新與失敗回滾。computer-use 已用鼠標點擊真實側欄輸入框，輸入中英文並按退格；實際按 n、i、空格，顯示搜狗候選框並將“你”上屏。

目標環境：Windows 10 21H1 x64，PowerShell 進程被禁用，無 WebView2。本次驗證在現有 Windows 主機完成，未在獨立的 21H1 目標機現場驗證；其他輸入法、多顯示器和其他縮放組合仍需目標環境複核。

安裝：完整解壓便攜 ZIP 到可寫目錄，運行 Folio.exe。舊版本更新器仍依賴 PowerShell，因此在禁用 PowerShell 的機器上，請手動解壓本版進行首次升級；從 2.0.1 發起的更新使用新運行時。確認文檔與 API 配置正常前保留舊目錄。
