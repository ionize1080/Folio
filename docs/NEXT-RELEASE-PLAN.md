本次核对的程序基线：`main bca8f5fa79980cb9b5f7c9488eb34e7755da29f0`（1.2.0 / rc1-p7）。本节是**计划更新，不是功能交付或新一轮运行验收**。版本号、工期与发布范围在实现和验收后确定；不承诺两个周期交付全部近程项目。下面保留原 P7/P6 计划与既有门禁；优先级冲突时以本节为准。

## 评审结论与证据边界

采纳“中文长文档、离线书签与 OCR 校对、可核对的保真编辑”定位。优先完成用户从打开年鉴、生成目录、校对、保存到再次续编的完整过程。书签规则深度是现有优势；扫描表格和大文件闭环是待验证机会，不能直接称为已建立的护城河。

本次读取了当前计划、P7 审计、页面操作入口、主进程/桥接口、表格检测和导出、OCR worker/诊断等关键源码，没有运行 Windows EXE，也没有重新执行报告列出的性能或准确率测试。外部报告的市场价格、用户论坛评价和横向质量排名不作为已验证事实纳入发布说明。

| 外部意见 | 处置与修正 |
| --- | --- |
| 先修字体、段落续编与 OCR，再扩展功能 | 采纳；与原计划 P0 合并，避免另建一套重复任务 |
| 无打印、页面整理有限、1,000 单元格限制、页码标签缺少编辑入口 | 关键入口/校验代码与评审相符；纳入任务，但将打印与页面结构操作拆开 |
| 当前扫描表不能直接进入有线表编辑/导出 | 采纳现状判断；当前调用默认 find_tables 和矢量横线推断。不能推导为 PyMuPDF 只能检测矢量线表：官方另有 text 策略，须在项目固定版本上验证 |
| OCR“完全没有图像预处理” | 改为“缺少用户可控的纠偏/去噪/对比度流水线”；worker 已有渲染/裁切，诊断还有方向候选，不能抹去引擎内部缩放及方向处理 |
| 固定段落 ID 解决保存拆段 | 有条件采纳；ID 只提供归属，必须同时保存字符顺序、空白、逻辑行及片段映射，并验证普通 PDF 与工程两条重开路径 |
| F01 所有未改字符几何都不变 | 区分局部纠错与用户主动重排：局部路径保护未改 run；重排区域允许明确告知后的几何变化，区域外必须不受影响 |
| F08 规则包得分最高，应较早做“市场” | 降为内置示例与本地导入导出；没有用户验证前不做市场、账号或在线分发，也不挤占 P0 |
| F21 打印、删除、重排、插页、拆分可行性均为 5 | 不接受这一合并估算；页面结构操作会改变书签/链接/标签/编辑状态，属于独立事务改造 |
| F10 引用型工程 = ZIP64 | 拆开：引用工程解决原件重复存储与身份；ZIP64 解决大归档格式上限，二者均不能单独解决内存或流式写回 |
| F18 无障碍全部远期 | 文档自动标签远期；键盘、焦点、可访问名称和状态播报纳入近期 UI 验收 |
| “多数竞品整段重映射”“明显优于多数开源/国产工具”“市场空位已确认” | 降为待验证假设。论坛/专利/SEO 文章可以提示场景，不能证明普遍缺陷、需求规模、准确率或性能优势 |

评分 I/U/F 不再简单相加决定顺序：数据正确性和依赖先行，再考虑收益、工作量及证据置信度。没有原型和固定样本之前，F01/F02/F03/F04/F09/F10/F11/F21 的可行性与周期均需实测校准。

## 阶段 C：大年鉴和扫描表闭环（以依赖决定顺序）

| 任务 | 对应评审 | 前置条件与验收 |
| --- | --- | --- |
| C1 统一页身份、文件句柄与任务状态 | F10/F11 的基础 | 普通/大文件共享页身份与能力接口，文件句柄租约、任务版本、磁盘预算、检查点和取消语义明确；不要求一次重写全部工作区 |
| C2 大文件阅读增强 | F05 | 连续虚拟阅读、按需文本选区/当前页搜索优先；全书搜索采用可取消的页级索引。无文字层的页面明确提示，避免整本 PDF 进入前端内存 |
| C3 大文件目录页 OCR → 书签 | F06/F11 的先行切片 | 只识别用户选定的少数目录页，磁盘缓存候选并接 B1；依赖 C1/B1，可早于全书 OCR 和引用工程完整交付。直接解除超大纯扫描年鉴必须手工逐项建书签的限制 |
| C4 原件引用型工程 | F10 | 相对路径/重定位、原件指纹、源文件被移动/替换/修改时校验、编辑增量与资产分离；指纹不能只依赖文件名。便携打包另评估 ZIP64；引用工程不承诺自带原件 |
| C5 页级 OCR 和可靠输出 | F11 / Issue #5 | 有界解码/渲染/识别队列，输出留磁盘，不传整文件 Base64；前台交互优先，任务可暂停/恢复；磁盘不足/中断保持原件和完整检查点 |
| C6 扫描表重建与校对导出 | F09 | 先支持清晰有框线扫描表+人工调栅格，随后再扩无框线/多级表头/跨页；CDLA 版面候选不等于单元格拓扑，须单独验证结构模型或规则。保留单元格源坐标、文本/置信度与校对状态 |
| C7 表格规模和数值列 | F09 补充 | 1,000 格限制分前端模型/检测/导出逐层改为预算，不直接删上限；虚拟网格、分页/分块导出与可取消任务。先验收 40×30（1,200格）和更大稀疏表，再定上限；数值转换可选、逐列预览，默认保留原文 |
| C8 多文件队列 | F12 | 依赖稳定单文档任务和检查点；输出命名/冲突处理、单文件失败隔离、暂停/取消与结果报告，避免一个坏文件阻塞整批 |
| C9 对照报告 | F14 | 像素、文本/字形、区域外变化、未决疑点分别导出；标明引擎/版本/缩放/容差/输入输出哈希，文本相等不能代替字形正确 |

大文件路径的推荐依赖：C1→C3（配合 B1）→C4/C5；C2 可独立切片推进，**不将连续滚动完成设为目录 OCR 的硬前置**。真正多 GB 文件与稀疏占位文件分开记录，降低“只测偏移却宣称可处理整本”的风险。

## 实测、性能和发布门禁补充

1. 固定回归集与探索集分开：固定集承接 P6 65 页、P7 20 页及 Issue #2/#3 私有复现；探索集覆盖金融、计算机、艺术、数学、法律的原生/扫描/混合 PDF，登记来源、授权、哈希、页号和选样方法。发现问题后做最小复现，避免挑选成功页。
2. 普通操作覆盖短替换、长插入、整段删除、数字/标点、样式、窄表、多次撤销、保存重开；书签覆盖生成、批改、分层拆分、目标校准；OCR 覆盖方向、漏检、跨格、补识别与人工结果保护。未运行项标未运行。
3. OCR 真值分别记录字符错误率、检测遗漏、跨格归属和数值单元格完全匹配；数值前导零、负号、小数点和缺失符号单列。没有人工真值不得输出“准确率”。
4. 大文件在 16/32 GB Windows 机器用真实 0.75/1.5/3/>4 GiB 样本测首屏、跳页/滚动 P50/P95、整棵进程树峰值 RSS、磁盘峰值、OCR吞吐、取消耗时及恢复。冷/热缓存分开；指标阈值由基线确定，不捏造秒数或提速倍数。
5. A1/A2/A3 的受支持用例若出现未解释的内容丢失、区域外改动、字体静默替换或写回与预览不一致，阻断发布；A5 人工校对丢失/重复文字层同样阻断。受限样本保留明确限制，不能靠删除失败测试关闭 Issue。
6. 保留当前源码/portable ZIP、Windows 同提交 EXE 验收、验证记录与 SHA-256 交付方式。程序功能验收和本次文档核查分开记账；本次更新不触发新版能力声明。

## 市场判断的使用方式

- 价格表仅作外部报告的历史快照；正式对外材料需重新核对厂商、区域、税费、永久使用权/维护与大版本差异，本计划不复述未核实价格。
- 论坛、Trustpilot、专利与搜索文章只作痛点线索；无竞品并排实测就不宣称准确率、速度或保真胜出。
- 后续用同一合法样本和相同步骤比较 Folio、PDF-XChange、ABBYY/Acrobat：任务完成时间、人工修改量、输出错误、资源占用、离线条件分别记录，价格独立比较。
- 以真实目标用户的目录生成、数值校对和续编任务验证价值，验证前不以市场评分替代工程验收。
