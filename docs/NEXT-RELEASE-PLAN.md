## P1：冷启动、长文档与工作区

- 分开测量首次页面分析、首次字体推荐、连续输入和复用请求的 P50/P95；不将缓存命中当作冷启动提速。
- 在 16/32 GB Windows 机器上扩充真实 0.75/1.5/3/>4 GiB 文档；记录内存、磁盘、保存和中断恢复，保持大文件通道与普通编辑能力边界清晰。
- 继续拆分 `app.mjs`，缩小忙碌状态影响范围，改善取消、关闭和对话框焦点；保护已有草稿与最近一次完整恢复快照。
- 提升字体替代说明、混合字体选择反馈、OCR 疑点导航与低质量提示。
- 真实 Windows 中文输入法、混合 DPI、不同缩放、强退恢复和覆盖保存人工验收。

## 后续能力

受控跨页文章续排、复杂表格、公式结构编辑、可继续编辑的 DOCX/HTML/Markdown 输出分阶段开展。语义候选与确定性排版/写回分开；未完成能力不得写入已实现功能。

## 每次发布的共同门禁

1. 保存原始输入、预览、实际输出和再次打开后的证据；分别核对内容、字形、字位、空白、段落归属、未修改区域和页面数。
2. 自动书签、批量规则/预览/记忆、目标校准、加密打开、图片颜色、表格及撤销继续回归。
3. Windows 同一程序提交完成单元、原生、界面、包检查和实际 EXE 验收；发布附件核对 EXE/app.asar 与完整 ZIP 哈希。
4. 交付完整源码 ZIP、Windows portable ZIP、验证记录及 SHA-256；保留旧分支和 Release，公开剩余限制。
