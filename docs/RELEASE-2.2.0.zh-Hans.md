## Folio PDF Studio 2.2.0

内置 Chatbox 可并行调用图片模型、把结果插入 PDF，并编辑原有图片。图片服务可配置接口地址、API 密钥和模型，支持 OpenAI 兼容接口及千问原生协议；直接填写的密钥由 Windows 加密保存。

- 图片移动、缩放、旋转、裁切、调色、不透明度、混合模式和删除，覆盖旧图片及内嵌图片，可跨页移动。
- SVG 线条与原生 PDF 线性/径向渐变，支持透明度；保存重开后仍可编辑或删除插入的矢量图。
- 按顺序合并 PDF，按页数或页码范围拆分；包含未保存修改并保留、重定位书签。
- 侧栏宽度可拖动；增加工具工作步数，对连接异常结束、输出截断和达到上限给出说明；修复临时 OCR 与合并拆分文档的缓存释放。

验收包含原生与界面测试、Chatbox 驱动真实千问并行生图、保存 PDF 的独立检查、打包程序及更新器测试。具体结果见本次发布 validation.json。

复杂裁剪或嵌套内容仍可能只读；SVG 支持经过验证的子集，不宣称与 PDF-XChange 完全等同。[操作与对标范围](https://github.com/ionize1080/Folio/blob/main/docs/GRAPHICS-2.2.0.md)。
