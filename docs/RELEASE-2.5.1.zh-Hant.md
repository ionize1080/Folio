## Folio PDF Studio 2.5.1

- 書籤篩選區分搜尋、頁碼與比對條件、結果操作；箭頭與文字統一 8 像素間距。改善焦點回饋、明暗主題和放大介面的可達性。
- 可在 PDF 閱讀畫面拖曳圖像或向量作品、拖曳四角縮放，支援鎖定寬高比、旋轉、鏡像、傾斜與 Esc 取消。每次套用調整均可復原。
- 工作室 PDF 參考背景長邊提升至引擎支援的 2048 像素。頁面拖曳使用閱讀器的 PDF 渲染。
- Word、Excel 匯出可跳過本次 OCR 疑點確認，或跳過 OCR 僅匯出已有文字。跳過確認可能保留錯字；原文件待校對資料不變。
- 修正文檔工具短視窗裁切、圖示與文字對齊，統一下拉箭頭，區分歸檔、印刷、驗證與匯出圖示。
- 關閉前可明確放棄未套用編輯，再決定是否儲存已套用修改；顯示關閉錯誤，長時間等待後提供繼續等待或強制退出選項。
