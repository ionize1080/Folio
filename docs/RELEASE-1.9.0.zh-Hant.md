# Folio PDF Studio 1.9.0

## 編輯與書籤

- 上下方向鍵跨短行、空行時保留橫向位置；Home/End 與 Shift 選取依實際排版行移動。
- 輸入法組字結束正確標記草稿，並維持一次復原；忽略重複的最終 input 事件。組字期間按 Escape 不會取消整段編輯。
- 中文句末後的雙字首行縮排可識別為新段落；修復論文連結、樣式片段邊界的標點與拉丁字母之間遺失空格。
- 未解析字型提供整段替代字型入口，明確選擇並支援復原。
- 修復儲存後連字號語義改變、含換行替代文字被拆散，以及含行內圖片頁面重新開啟異常。
- 書籤批次縮放支援繼承、固定比例、符合頁面/寬度/高度/可見內容，以及範圍、差異預覽、復原重做與儲存。原始本機動作及命名目的地須明確轉換，外部與未解析目的地略過。
- 新增 Unicode 標題大小寫轉換、貼到同層前後、展開/摺疊所選子樹。
- 獨立 HTML 目錄保留階層、標題樣式與相對頁碼連結；與同名 PDF 放在一起使用。外部動作僅顯示文字。

## 驗證與限制

本機 Online Samples、Acrobat Pro、PDF-XChange 桌面操作，以及瀏覽器輸入、原生 PDF 往返與發佈包驗證。請參閱[比較與範圍](COMPARISON-1.9.0.zh-Hans.md)及 release 驗證附件。

測試僅覆蓋指定頁面，並非全文件通過。特殊字型編碼、需要 OCR 的掃描頁與安全排版空間不足的段落不計為成功編輯。替代字型可能改變換行。中文輸入法候選窗未自動化實測，已驗證組字事件順序。動作鏈編輯、從書籤建立 PDF 目錄頁、依書籤重排頁面及 PDF-XChange 專用交換格式不在本版範圍內。

完整解壓便攜包後執行 Folio.exe，或從現有版本檢查更新。無須另裝 Python 或 Node.js。
