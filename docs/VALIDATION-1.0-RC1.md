日期：2026-09-15。开发基线：用户提供的 0.9.0 源码和完整 Windows 运行包。

## 验证结论与边界

本轮实现已通过所列自动化和浏览器界面回归，可交付 Windows x64 RC1 测试包。**未在 Windows 真机启动本包，不能据此宣布正式稳定版验收完成。**

测试环境为 Linux、Python 3.12、Chromium 153 的无头浏览器；界面调用真实 PDF、字体、原生编辑和排版服务。Electron 文件对话框与系统事件通过测试接口模拟。运行包包含 Electron 44.3.0、Python 和原有离线模型；构建时检查可执行文件元数据、归档内容与源文件哈希。

## 截图检查后的修正

- 范围栏固定为紧凑输入与快捷选项，修正网格样式竞争造成的输入框拉高。
- 修正单位换算过长小数、深色范围按钮对比不足，以及正则框中文字体缺失。
- OCR 设置可折叠，校对属性区减少多余间距；当前结果与编辑按钮不随页面滚动消失。
- 修正字体真实预览监听器初始化错误、说明文字缺字和对比度偏低，保留中文名称、键盘焦点和实际字体样例。
- 新增界面统一焦点可见样式；小窗口保留完成/取消入口，高级字段放入可滚动面板。

## RC1 的具体限制

- Windows 启动、系统文件拖拽、微软/搜狗输入法、真实 DPI 和不同显卡仍待真机验收；模拟测试不能代替这些检查。
- 自动归行仍是几何启发式。0.9 字高不是通用默认值；表格跨单元格关联、复杂竖排和倾斜文字没有全面准确率保证。
- 结构纠正现覆盖文本区域、元数据与边界锁定；栏号和顺序作为工程结构记录，不等于已经重写 PDF 的无障碍标签或整篇语义阅读顺序。任意图片/表格区域的结构重分类仍需继续完善。
- 表格结构限可靠的有线矩形区域。插入行列保持表格总范围；复杂跨页、无边框、异形边框和结构编辑后自动挪动表格外正文不在本次验证范围。
- 同页文本链、拆分入口已实现；复杂混排的拆分边界需预览，容不下文字时不提交。跨页自动续排不属于本次交付。
- 全页对照检查的是实际待保存输出，按需渲染所选页；没有在每次保存后自动全书重渲染，也没有对每一种颜色空间、透明蒙版和排版组合作保真承诺。
- 字体覆盖不足仍会逐字替代。系统字体在不同 Windows 安装中的可用性不同；特殊 Type1 编码或非标准变换无法可靠恢复时会保留回退提示。
- 书签拆分支持核心独立正则语义、规则启用/标志、导入导出、预览和子项迁移；按层自定义样式、跳过未命中层后自动提升及超大批量虚拟化仍是后续增量。

## Windows 验收建议

完整解压后运行 Folio.exe，依次检查拖入 PDF、中文输入与字体选择、第 14 页反复进入编辑、保存和重新打开、OCR 连续滚动及 125/150/200% 系统缩放。发现问题保留页面、操作步骤和截图，避免仅记录“偶发失败”。
