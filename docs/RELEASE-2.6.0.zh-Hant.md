# Folio PDF Studio 2.6.0

修正黃金新聞第 2 頁 Adrian Day 段落編輯錯誤及首字母遺漏。段落辨識支援 Chromium 段落標籤與單色 Type3 向量字型，連結底線不再誤拆段落，允許保留原有的小幅字形越界。

開啟文件後於閒置時逐頁分析字型，持續重用字形評分、本機字型對應與瀏覽器字型處理結果。背景工作以低優先順序執行，編輯操作可優先處理。原位文字改為批次寫入，密集表格改為依空間位置查詢。

本機驗證涵蓋 32 份文件、95 頁，其中包含 17 份固定雜湊的公開文件：303 次編輯成功、136 次受限，完整性檢查無失敗，全部原文件保持不變。Actions 使用 6 路引擎迴歸、4 路公開樣本及獨立介面測試，並檢查最終 Windows 發行套件。詳見[架構分析與測試報告](https://github.com/ionize1080/Folio/blob/v2.6.0/docs/EDITING-2.6.0.md)。

尚未證明全面達到 Acrobat 水準。跨連結／複雜標籤、交錯覆蓋繪製、特殊編碼與部分複雜字形仍有限制；本版不包含自動跨頁重排。
