# Folio 1.9.0 书签补充验收

日期：2026-10-19。本记录针对继续测试期间发现的书签完整性与界面问题；桌面程序最终验收和发布结果以整体 release 验证报告为准。

## 修复与补齐

| 问题 | 最终行为 |
| --- | --- |
| 开启筛选后，右键缩放/大小写默认处理所有匹配项，超出当前选中范围 | 右键与一般批量入口优先选中项；筛选栏的“批量处理”明确使用匹配项 |
| 恢复固定缩放收藏规则后，百分比输入仍可能隐藏 | 恢复历史后同步显示固定比例输入及保存的数值 |
| 文本输入已完成预览，点击应用时失焦 `change` 再次禁用按钮，首次点击无效 | 已预览的相同字段值不重复触发失效，首次点击可应用 |
| 输入法合成开始后仍可能应用旧预览 | 合成开始即禁止应用/报告导出并清空旧差异；合成结束重新计算 |
| 参数无效时旧差异仍留在界面 | 更新中清空旧差异；出错时保持应用与导出禁用 |
| 缩放菜单缺少可见内容宽度/高度 | 补齐 FitBH、FitBV；共八种缩放选择，保留对应 X/Y 参数 |
| XYZ → FitH/FitBH 差异报告按数组下标比较，把原 X 误标成原 Y | 根据参数含义对照，标明新增/移除参数；未改变的 Y 不虚报修改 |
| 仅选择外部动作时，非法缩放输入可能绕过检查 | 先校验模式与比例；外部动作仍跳过，逐参数修改也拒绝把外部动作变成本地动作 |
| 剪切源被删除后粘贴静默无效 | 明确提示源已删除；目标为自身/子项时右键粘贴禁用；撤销删除后可继续 |
| 菜单操作过长、常用项排在末尾 | 编辑与剪贴板优先，按用途分组，禁用无效操作；限制在窗口内，可滚动、键盘首尾/上下导航 |
| 大小写转换拆开辅助平面的 Unicode 字母 | 按完整 Unicode 码点转换词首字母 |
| 差异预览可能把与界面标签同名的书签标题翻译 | 标题明确保留文档原文；新状态与参数标签补充英文、繁体中文 |

## 已执行验证

`tests/bookmark-completeness-v190.test.mjs` 的六项新增测试通过：八种缩放坐标、外部动作与非法输入、跨模式差异语义、Unicode 大小写、多根子树插入/移动、深层 HTML 结构与转义。与当时工作区其余测试一起运行，共 220 项 JavaScript 单元测试通过。

`tests/bookmarks-v190-ui.cjs` 的十组浏览器流程通过，未发现未处理的页面异常：

1. 筛选开启时右键范围与筛选栏范围各自正确。
2. 固定缩放收藏恢复、非法参数清除旧预览、撤销重做完全恢复。
3. 合成输入中禁止应用，结束后一次点击应用完整文本。
4. 展开/折叠不改书签数据；复制/剪切完整子树到同级前后，结构和顺序正确；撤销重做一致。
5. 剪切后通过实际 Delete 操作删除源，粘贴拒绝执行，撤销恢复。
6. 继承、固定、Fit、FitH、FitV、FitB、FitBH、FitBV 经界面逐项设置后，真实 PDF 保存重开，页码、模式及参数逐项相同。
7. HTML 导出完整，链接为相对 PDF 页码链接，无脚本标签。
8. `Online Samples` 中 `pdf.js__nested_outline__8e7862.pdf` 的大写批量预览、应用、撤销保留原始目标；未修改样本源文件。
9. 英文缩放界面没有未翻译的中文界面文字。
10. 800×600 暗色窗口与 1120×768 标准窗口菜单不越界，滚动与 Home/End 可达全部可用操作；英文预览仍保留中文文档标题“关闭”。

## 与 PDF-XChange 仍有的差距

本版补齐常用书签批量处理与树操作，不宣称完整复刻。仍缺少完整动作链编辑、外部 GoToR/GoToE 缩放修改、从书签生成 PDF 目录页、按书签重排页面、从高亮生成书签及 PDF-XChange 专用交换格式。剪贴板限当前文档，打开另一份 PDF 会清空；跨文件可使用现有 JSON 导入，原始动作按导入规则转换。HTML 导出只提供本地页码链接，不执行外部动作。
