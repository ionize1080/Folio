## Folio PDF Studio 2.1.0

- 在「開啟」中多選 PDF 或 Folio 專案，或將多個檔案拖入視窗。每份文件獨立保留閱讀位置、選取的書籤、復原紀錄和未儲存的編輯。Ctrl+Tab 切換文件，Ctrl+W 關閉目前分頁。
- 偏好設定提供鈷藍、青瓷、琥珀、桑葚、石墨五組配色與自訂強調色，可搭配系統、淺色或深色外觀。工具、書籤、核取方塊與鍵盤焦點使用一致的狀態色彩。
- 介面語言預設跟隨 Windows。可在偏好設定中指定簡體中文、繁體中文或 English，升級時沿用既有選擇。
- Chatbox 可以透過 MCP 列出開啟的文件，取得目前頁面與選取的書籤、文字、物件及頁碼，並依文件 ID 讀取其他分頁。寫入操作會核對文件版本。操作進度顯示於輸入區上方。
- 長書籤清單的批次選取與變更比對使用索引，切換分頁時重用已開啟的編輯器。
- Chatbox 可預覽並微調圖片色彩、曲線、濾鏡與銳利度，替換局部像素，增強掃描及加入 OCR 文字層。選用的生圖功能使用已設定的圖像創作服務。SVG 與流程圖以可編輯向量嵌入，重開 PDF 後可繼續修改。文件摘要提供附頁碼的摘錄與本機檢索。

### 發行驗證

Windows 發行流程通過 12 個真實 Qwen 測試，涵蓋書籤、跨文件閱讀、掃描增強與 OCR、局部換圖、原圖解析度調色，以及重開流程圖後修改節點。獨立圖像生成服務的線上效果仍待驗證。
