# Folio PDF Studio 0.6.0

本版完成主要保存、书签、阅读和 OCR 校对改进，并加入段落流式编辑初版。完整解压 Windows x64 运行包后双击 `Folio.exe`，无需另装 Python 或下载模型。不要只移动 EXE。建议使用新的解压目录，保留 0.5.1 以便比较。

## 这版修复与改进

- **OCR 应用后保存**：复用已生成的内容 PDF，保存时再合成最新书签、批注、旋转和属性，不重复生成 OCR 文字层。无改动时普通保存直接返回；保存前选择位置，显示阶段与耗时，保留临时写入和安全替换。
- **OCR 双向定位**：点击右侧识别结果，左侧对应区域自动进入视口；点击左侧框，右侧列表跟随。保留缩放和校对字段，选中切换不重绘整页。
- **完整书签标题**：自动生成默认把同一视觉高度的片段合为一行，按水平位置排序，普通间隔为一个空格、大间隔为两个空格。正则可提取“代码 + 名称”；不需要独立表格模式。双栏正文可选择“按阅读栏分开”或限制范围。
- **规则预览**：支持整行、匹配部分和捕获组模板作为标题；缺失必填捕获组会提示原因。预览紧凑左对齐、分页搜索，点击可查看来源片段和捕获内容；目标可指向捕获组所在片段。行业规则只是可主动加载的示例。
- **复制**：页面选中文字后右键提供“复制 Ctrl+C”“复制为单行”。“框选文字并复制…”可按区域提取、编辑预览，选择用制表符表示大间隔。
- **清晰滚动**：提高基础画布像素预算，保留附近高清页面与分块，优先绘制可见区域，后台准备临近区域。缩放替换尽量保留旧清晰画面。首次跳到远处、快速连续跳页或内存不足时仍可能短暂细化，不承诺任何文档始终瞬时高清。
- **OCR 辅助操作**：局部识别支持鼠标重新框选并同步数值；混合页跳过增加正文覆盖启发式，减少只有页眉或页码就整页跳过的情况；偏好中可查看、手动清理非当前 OCR 任务缓存。

## 新功能：段落流式编辑

顶部新增 **“流式编辑”**，原来的对象编辑入口改为 **“编辑对象”**。

1. 打开含原生文字的未旋转页面，点击“流式编辑”。
2. 在左侧点选段落，或在候选列表中 Ctrl / Shift 多选，点击“编辑所选段落”；也可新建文本框。
3. 修改整段文字、字号、颜色、粗斜体、对齐、行高、文本框位置和大小。右下角手柄可调整框大小。
4. 选择 1–3 栏。文字按左栏到右栏连续填充；删字后后续文字向前补齐。初版栏高相同，范围限定在同一页。
5. 点击“更新 PDF 预览”，核对实际排版，再“应用到 PDF”。文字溢出、缺字、来源已变更或与未选文字冲突时会阻止应用。
6. 应用后可以整次撤销、重做，或在“继续编辑已应用的文本流…”中重新修改。

**继续工作请保存 `.folio` 工程**：在“导入 / 导出”中选择“保存工作工程 .folio”，以后通过“打开”恢复。它保存原 PDF、已应用修改、OCR 校对和段落模型。普通“保存 PDF”输出可阅读、搜索和复制的成品；重新打开该 PDF 不保证自动恢复同一个可编辑段落模型。工程包含原始内容，体积可能大于成品 PDF，目前未压缩。

可导出**当前文本流**的 HTML、Markdown 和排版参数 JSON。尚不是整份 PDF 转 Word / HTML / Markdown。

## 为什么初版没有增加 AI 或 Story

本版使用原生文字与几何关系生成段落候选，使用应用已有的 Chromium 排版和 PDF 输出能力，再由原生后端局部替换原文字。预览与写回使用同一个排版片段，避免出现“预览一种效果、保存另一种效果”。这条路径不增加模型加载和安装体积，支持中文换行与同页分栏。

没有在运行包中加入新的版式 AI、Story 或 PyMuPDF。AI 辅助结构重建仍是后续可插拔分析方向；本版不自动改写原文。

## 初版范围

支持普通横向原生文字、坐标原点为零且单位为 1 的未旋转页面；字体使用内置思源黑体衍生字体与现有回退字体，整段采用统一样式，不能完整保留任意原字体和段内混合格式。复杂嵌套、特殊裁剪、扫描图片里的文字仍不能直接变成原位可编辑段落；OCR 文字层不等于扫描图像已被替换。

尚未提供跨页文章续排、任意形状文本框、图片自动避让、公式结构编辑、表格语义编辑、全文 Word 转换或自动多语言模型选择。文本框不会覆盖未选择的原生文字，但对图片和复杂矢量障碍的自动避让尚未完成，应用前需看预览。

## 验证情况

已通过 34 项 Node 回归、真实原生 PDF 写回、浏览器界面流程、隔离 Python OCR 及 Windows 包静态校验。300 页、2,400 条 OCR 文字层应用后，每页均可搜索，原图像素一致；应用约 133.8 秒，随后复用内容保存约 3.2 秒，再修改书签保存约 2.0 秒。这些是本次 Linux 测试数据，不是 Windows 耗时保证，应用和保存是不同阶段。

同页中英文分栏、溢出阻止、删除原文、重复续编、撤销重做、工程恢复及未修改区域像素一致均有回归。排版控制器首次约 718 ms，复用后约 12 ms；不包含整个界面预览、字体首次下载或复杂文档的总耗时。

**尚未进行真实 Windows 启动、显卡/混合 DPI 和原生覆盖保存验收。** Windows 包中的 EXE 版本、依赖、模型和源码一致性已经静态检查。详细步骤与报告见运行包 `docs/VALIDATION-0.6.md`。
