## 用縮圖翻頁

按 **Ctrl+T**，或在左側欄點 **縮圖**。點預覽圖即可跳頁。在側欄內按住 **Ctrl** 捲動，或拖曳滑桿，可調整預覽大小與每列欄數。正文保留自己的縮放比例。點 **選擇頁面** 可依頁碼範圍執行 OCR 或產生書籤。

## 調整側欄與切換工具

滑鼠按下即可切換功能區索引標籤，也可以用鍵盤切換。固定頁面縮放時，拖曳側欄會重新定位可見頁面並重用既有畫布。縮放定位支援混合紙張尺寸、旋轉頁與雙頁配置。

Windows 發行流程建置一次可攜版 ZIP，在六個平行工作中檢驗同一份壓縮檔，並將公開 PDF 編輯語料分成四組測試。兩個壓縮檔均附有 SHA-256 校驗值，驗收報告記錄對應的提交。
