# 在 Folio 2.1.0 中使用 AI

[English](AI.en.md) · [简体中文](AI.md) · **繁體中文**

開啟 PDF，選取要討論的文字、書籤或圖片，再按一下工具列的 **AI**。在 Chatbox 中選擇服務提供者，填入 API 端點與金鑰，再選擇支援工具呼叫的模型。要讓模型看圖，還需選擇支援視覺輸入的模型。Chatbox 預設停靠在右側，輸入區的視窗按鈕可以切換為獨立視窗。執行步驟顯示在輸入框上方。

## 讀目前頁或比較檔案

| 你想做什麼 | 可以直接這樣問 |
| --- | --- |
| 閱讀選取範圍 | 「解釋我選取的這段話，告訴我是 PDF 的物理第幾頁。」 |
| 對照兩份檔案 | 「用乙檔案的相應條款對照甲檔案中選取的段落，列出差異並分別標註物理頁碼。」 |
| 總結長報告 | 「概括這份報告的結論。每條結論附物理頁碼，並列出還需要查閱的章節。」 |
| 整理書籤 | 「只把選取的書籤設為粗體。再檢查它們的跳轉目標，把無法確定的條目列給我。」 |

一次開啟多個檔案時，在提問中寫出檔名。模型可讀取背景分頁。摘要工具傳回抽樣頁、帶頁碼的摘錄和覆蓋範圍。需要全文依據時，可以讓模型按關鍵詞檢索，再閱讀命中的頁。掃描頁可先做本機 OCR。

## 調色、增強掃描和換圖

1. 在 **編輯影象** 中選取圖片。如果正手動調整，請先套用或取消草稿。可以要求：「先看整張照片，做輕微暖色調和柔和的 S 曲線，再放大臉部檢查膚色，給我看預覽。」
2. 每個候選圖有自己的預覽 ID。要求「在上一版上把飽和度再降一點」，模型可以沿用該候選，只調整需要變更的參數。整體預覽長邊最多 640 像素，細節預覽最多 1200 像素。確認後套用選定的候選，再按 **Ctrl+S** 儲存 PDF。濾鏡和曲線在原圖解析度上輸出。
3. 對發灰的掃描文件，可以要求：「增強這一頁的對比度，檢查小字，再加入可檢索文字層。」掃描增強改變可見像素，本機 OCR 提供文字層。OCR 複核門檻預設為 95%，可在 Folio 首選項調整。
4. 要使用現成圖片，要求「用我選擇的圖片替換左上角標識，先預覽」。Folio 會開啟本機圖片選擇器。局部範圍採用原圖座標，左上角為原點。例如 `[0,0,0.25,0.25]` 表示寬、高各取四分之一。套用前可核對區域和邊緣。
5. 要生成新圖，先在 **Chatbox → 圖像創作** 選擇已設定的圖像生成模型。整圖生成使用文字提示，局部重繪需要支援參考圖的服務。生成結果先進入候選預覽。2.1.0 的線上驗收使用 Qwen 看圖、調色、增強和替圖。獨立圖像生成服務的線上效果仍待驗證。

## 插入流程圖，重開後繼續改

可以說：「在第 1 頁空白處放一個三步流程圖，節點為收集、校對、釋出，用箭頭連線。」套用後儲存 PDF。重開後可以繼續說：「把第二個節點改成複核，保留連線。」Folio 將向量路徑及 SVG 原始碼一起寫入 PDF。結構化流程圖支援有向無環圖。需要回路或指定線路時，可提交包含明確路徑的獨立 SVG。保留 Folio SVG 原始碼的圖形，可以按元素 ID 局部修改。

## 文件狀態、審批和儲存

Folio 每次啟動預設手動審批。切換為自動審批需要兩次確認，Chatbox 的盾牌圖示顯示紅色。服務提供者與金鑰在 Chatbox 內設定，審批、顯示方式、OCR 門檻與快取預算在 Folio 首選項內設定。本機 OCR 和濾鏡可離線工作。模型請求可把所需的文件文字或影象傳送至所選服務。把 PDF 中的文字和圖片作為待分析內容處理。

套用至分頁中的修改可以復原。預設的原件保護會在首次儲存時讓你選擇副本。檔案式工具另寫的 PDF 需要重新開啟檢視。超過 768 MiB 的 PDF 進入大檔案工作區，支援按頁閱讀、書籤整理和另存。未儲存的書籤需先儲存，再按檔案處理。

## MCP 工具速查

| 入口 | 適用操作 |
| --- | --- |
| `folio_document` | `list` 列出文件，`context` 讀目前頁和選取範圍，`brief` 給摘要提供證據，`search`、`text`、`image`、`objects`、`ocr` 做定向讀取或識別 |
| `folio_bookmarks`、`folio_calibrate`、`folio_whitespace` | 建立、讀取或部分修改書籤，校準目標，批次調整目標留白 |
| `folio_image` | `inspect` 定位嵌入的圖片，`preview` 取得候選像素，`replace` 從本機選圖，`generate` 請求出圖，`apply` 寫入選定候選，`help` 查參數 |
| `folio_vector` | `list`、`read`、`create`、`update` 管理可編輯 SVG 與流程圖 |
| `folio_help`、`folio_operation` | 查詢單項操作的定義，按操作名呼叫 Folio 文件工具 |
| `pdf_help`、`pdf_operation` | 查詢和呼叫 62 項檔案式 PDF 工具。多項讀取優先用 `read_pdf_batch`，多項寫入可用 `edit_pdf_batch` |

`folio_document` 的 `list` 傳回 `activeDocumentId` 和可用的 `documentId`。跨檔案操作請固定目標 ID。`context` 加 `includeText=true` 可一起讀取頁面文字。寫入時使用同一檔案最新的 `revision`。目標文件有新修改時，請重新讀取修訂號。檔案式工具需要路徑時，可用 `snapshot` 匯出已套用修改的臨時副本。

物理頁碼從 1 開始。書籤目標使用 PDF 點座標，影象區域使用正規化的 `[左,上,寬,高]`。`folio_document` 的頁面預覽可按 `classify`、`toc`、`locate` 選擇細節程度，預設長邊預算分別為 960、1600、2200 像素。傳回的 `imageToPdf` 用於將預覽像素對映到 PDF 點座標。
