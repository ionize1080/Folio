## Folio PDF Studio 2.1.0

- 在「打开」中多选 PDF 或 Folio 工程，也可把文件一起拖入窗口。每个文档独立保留阅读位置、书签选择、撤销记录和未保存编辑。Ctrl+Tab 切换文档，Ctrl+W 关闭当前标签。
- 首选项提供钴蓝、青瓷、琥珀、桑葚、石墨五套配色和自定义重点色。可分别选择系统、浅色或深色外观。选择工具、书签、复选框与键盘焦点共享同一套状态色。
- 界面语言默认跟随 Windows。可在首选项手动选择简体中文、繁體中文或 English，旧版已保存的选择继续生效。
- Chatbox 可通过 MCP 列出打开的文档，查询当前页、所选书签、文本、对象和页码，并按文档 ID 读取其他标签。写入需要对应文档的版本。操作步骤显示在输入区上方。
- 长书签列表的批量选择和变更比较使用索引，切换标签直接复用已打开的编辑器。
