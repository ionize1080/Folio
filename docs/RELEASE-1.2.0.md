# Folio PDF Studio 1.2.0

Windows x64 正式通道；完整 portable 和离线源码分别交付。发布由同一次 Windows 测试运行门控，附件 validation.json 记录程序提交、测试范围及 EXE/app.asar 哈希。历史 RC 发布保留。

## 新功能

- 文本框移动：Shift 拖动按主位移锁定水平或垂直；移动手柄获焦后方向键 1 pt、Shift＋方向键 10 pt；文字输入框中的方向键仍移动光标。移动可撤销/重做。
- 图片实例调整：亮度、对比度、直方图、黑白场/伽马色阶、可拖动曲线、灰度、高斯模糊、锐化；扫描彩色增强和灰度增强预设；原图对照与重置；沿用图片替换与可恢复裁剪。
- 预览与写回共用图片处理函数；保存只替换选中图片实例，保留透明度并隔离跨页共享资源。扫描件 JBIG2 使用随包 MuPDF 解码，无需额外安装工具。

## 修复

- 原文档上下文中的 Form 判定用于单页预览，减少预览可改但保存拒绝的差异；整段删除不再要求非空排版片段。
- 生成的多行段落保存重开后恢复可编辑分组；恢复自身生成的 CID/CFF 字体；默认重绘保持原绘制位置。
- 导出合字使用完整 Unicode 字符序列，保留换行处空格；尊重原字体显式字重，避免常规中文字体误判粗体。
- 完整单一 MCID 范围位于文字对象内部时可保持原标签归属安全重排；部分范围和复杂嵌套仍明确拒绝。
- 同一 TJ 内固定列间距按独立跨度保留；无法维持列位置时明确拒绝并保留草稿，可由用户选择段落重排。
- 未嵌入字体的度量替代需要在重绘前明确选定；符合条件的原字体资源局部纠错仍可直接保存。
- OCR 重识别按内容/位置匹配保留人工修改与排除状态；空白分隔的栏区按阅读顺序组织；反复替换清理失效 OCR 资源。
- 原生任务请求身份、异常响应和过期响应隔离；打包清单及校验加入 OCR 合并/阅读顺序模块。
- 辅助文字对比度、明暗主题、大文件工作区配色、忙碌提示位置和移动手柄焦点改善。
- 保留 qpdf 解密与导出无密码副本功能。

## 验证口径与限制

- Windows 实际打包 EXE 自动化：P4/P5/P6/P7、P8 移动与图像界面，以及既有功能回归。只有全部成功才生成发布附件；这不等于所有显卡、中文输入法或混合 DPI 的人工验收。
- 固定回归包含此前公开文档；新增固定随机种子 20260929 从 OCRmyPDF 语料池抽取 8 份公开文件，覆盖扫描、旋转/倾斜、JBIG2、遮罩及高分辨率图片，并记录 URL/哈希。
- 新增 TI 数据手册、IRS W-4 和 GNU Make 手册的随机抽页连续编辑探索。通过、显式拒绝和中途拒绝分开记录；不将拒绝计作编辑成功。部分 MCID 范围和 TeX 混合字体映射仍有受限情况。
- 图像功能作用于选中的可编辑图片；不是完整 Photoshop，不包含通用图层蒙版、任意透视矫正或全书批量扫描增强。保存到 PDF 后继续调整以保存图像为输入；跨保存保留原始参数需使用工程/原件。
- 复杂透明 Form、任意标签结构、倾斜/纵排、签名有效性、完整表格重构及真实数 GB 文件性能仍按现有限制处理。增强预设不承诺每份扫描件 OCR 准确率一定提高。
- 最新发布计划为多阶段路线图。本版交付编辑/OCR一致性与可靠性切片、新移动/图片功能及部分 UI 修复；增量保存、完整事务控制器、全面 IPC 契约及剩余 UI 任务继续保留。
