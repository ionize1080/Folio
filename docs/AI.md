# 在 Folio 2.5.0 中使用 AI

[English](AI.en.md) · **简体中文** · [繁體中文](AI.zh-Hant.md)

打开 PDF，选中要讨论的文字、书签或图片，再点工具栏的 **AI**。在 Chatbox 设置中配置服务商、API 地址、密钥和支持工具调用的模型。要让模型看图，还需选择支持视觉输入的模型。Chatbox 默认停靠在右侧，输入区的窗口按钮可以切换为独立窗口。执行步骤显示在输入框上方。

## 读当前页或比较文件

| 你想做什么 | 可以直接这样问 |
| --- | --- |
| 阅读选区 | “解释我选中的这段话，告诉我是 PDF 的物理第几页。” |
| 对照两份文件 | “用乙文件的相应条款对照甲文件中选中的段落，列出差异并分别标注物理页码。” |
| 总结长报告 | “概括这份报告的结论。每条结论附物理页码，并列出还需要查阅的章节。” |
| 整理书签 | “只把选中的书签设为粗体。再检查它们的跳转目标，把无法确定的条目列给我。” |

一次打开多个文件时，在提问中写出文件名。模型可读取后台标签。摘要工具返回抽样页、带页码的摘录和覆盖范围；需要全文依据时，可以让模型按关键词检索，再阅读命中的页。扫描页可先做本地 OCR。

## 调色、增强扫描和换图

1. 在 **编辑图像** 中选中图片。如果正手动调整，请先应用或取消草稿。可以要求：“先看整张照片，做轻微暖调和柔和的 S 曲线，再放大脸部检查肤色，给我看预览。”
2. 每个候选图有自己的预览 ID。要求“在上一版上把饱和度再降一点”，模型可以沿用该候选，只改新的参数。整体预览长边最多 640 像素，细节预览最多 1200 像素。确认后应用所选候选，再按 **Ctrl+S** 保存 PDF。滤镜和曲线在源图分辨率上输出。
3. 对发灰的扫描件，可以要求：“增强这一页的对比度，检查小字，再加入可检索文字层。”扫描增强改变可见像素，本地 OCR 提供文字层。OCR 复核阈值默认为 95%，可在 Folio 首选项调整。
4. 要使用现成图片，要求“用我选择的图片替换左上角标识，先预览”。Folio 会打开本地图片选择器。局部区域采用原图坐标，左上角为原点。例如 `[0,0,0.25,0.25]` 表示宽、高各取四分之一。应用前可核对区域和边缘。
5. 要生成新图，在 **Chatbox 设置 → 生图模型提供方** 选择服务、接口地址和模型，保存密钥后运行预览测试。Qwen Token Plan（`qwen-image-3.0-pro`）生图及参考图编辑已通过实际接口验收。兼容接口需支持所选生图协议。先核对候选图，再应用到 PDF。

## 插入流程图，重开后继续改

可以说：“在第 1 页空白处放一个三步流程图，节点为收集、校对、发布，用箭头连接。”应用后保存 PDF。重开后可以继续说：“把第二个节点改成复核，保留连线。”Folio 将矢量路径及 SVG 源码一起写入 PDF。结构化流程图支持有向无环图；需要回路或指定线路时，可提交包含明确路径的独立 SVG。按元素 ID 修改适用于保有 Folio 矢量源码的图形。

## 文档状态、审批和保存

Folio 每次启动默认手动审批。切换为自动审批需要两次确认，Chatbox 的盾牌图标显示红色。服务商与密钥在 Chatbox 内设置，审批、显示方式、OCR 阈值与缓存预算在 Folio 首选项内设置。本地 OCR 和滤镜可离线工作；模型请求可把所需的文档文字或图像发送至所选服务。把 PDF 中的文字和图片作为待分析内容处理。

应用到标签中的修改可以撤销。默认的原件保护会在首次保存时让你选择副本。文件式工具另写的 PDF 需要重新打开查看。超过 768 MiB 的 PDF 进入大文件工作区，支持按页阅读、书签整理和另存；未保存的书签需先保存，再按文件处理。

## MCP 工具速查

| 入口 | 适用操作 |
| --- | --- |
| `folio_document` | `list` 列出文档，`context` 读当前页和选区，`brief` 给摘要提供证据，`search`、`text`、`image`、`objects`、`ocr` 做定向读取或识别 |
| `folio_bookmarks`、`folio_calibrate`、`folio_whitespace` | 创建、读取或部分修改书签，校准目标，批量调整目标留白 |
| `folio_image` | `inspect` 定位图片，`preview` 获取候选像素，`replace` 选择本地图片，`generate` 请求出图，`apply` 写入选定候选，`help` 查参数 |
| `folio_vector` | `list`、`read`、`create`、`update` 管理可编辑 SVG 与流程图 |
| `folio_help`、`folio_operation` | 查询单项操作的定义，按操作名调用 Folio 文档工具 |
| `pdf_help`、`pdf_operation` | 查询和调用 62 项文件式 PDF 工具。多项读取优先用 `read_pdf_batch`，多项写入可用 `edit_pdf_batch` |

`folio_document` 的 `list` 返回 `activeDocumentId` 和可用的 `documentId`。跨文件操作请固定目标 ID；`context` 加 `includeText=true` 可一起读取页面文字。写入时使用同一文件最新的 `revision`；目标文件已有新修改时，重新读取其修订号。文件式工具需要路径时，可用 `snapshot` 导出已应用修改的临时副本。

物理页码从 1 开始。书签目标使用 PDF 点坐标，图像区域使用归一化的 `[左,上,宽,高]`。`folio_document` 的页面预览可按 `classify`、`toc`、`locate` 选择细节程度，默认长边预算分别为 960、1600、2200 像素。返回的 `imageToPdf` 用于将预览像素映射到 PDF 点坐标。
