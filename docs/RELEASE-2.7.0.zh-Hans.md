# Folio PDF Studio 2.7.0

本版增加增量保存、书签质量检查和更完整的页面整理，并压缩界面横栏，提高文档的纵向可阅读高度。

- **增量保存**：追加变化对象，复用未变的图片、字体等资源，覆盖原生页面编辑快照及页面整理输出。内容未变时复用已解析快照；资源处理、序列化、文件校验和写入显示进度。首选项保留完整重写模式。
- **书签统计 / QC**：重复或空标题、层级、目标页和动作检查，可主动检查公网链接；支持批量尝试修复、仅删除节点或删除子树。新增每 N 页生成、标题模板、页码筛选和保持树结构的排序。
- **阅读体验**：按字符精确命中，统一颜色的文字选区；滚轮行数、定位线显隐及颜色可调。书签跳转先计算最终坐标，再一次定位，修复页顶抖动。
- **页面整理**：范围、奇偶和鼠标框选；插入、空白页、逐页配对替换、批注与表单选项、旋转、裁剪、保持比例缩放、仅调整纸张、提取和拆分。
- **高亮与批注**：内置配色及自定义颜色、透明度、线宽和线型；支持下划线、波浪线、删除线、矩形、墨迹及半透明手绘标记。
- **图像 / 矢量工作室**：在 PDF 背景上用手柄调整画布；自动扩展只在内容越界时增大画布，不自动缩小。保持作品绘制比例，避免圆形因放置尺寸不同变成椭圆。同一会话可反复打开，保存 `.folio` 工程会保留可编辑源文件和自动画布选项。
- **紧凑界面**：Windows 自绘标题栏常驻保存、撤销、重做，连接文件标签和窗口按钮；阅读工具移至底栏，常用页仍保留对应操作。采用清晰文字层级、统一间距、可见焦点和克制动效。
- **更新**：兼容 Chrome 的请求头、经过校验的并行下载和断点续传、Markdown 更新说明。
- **打印**：缩略图多选、范围及奇偶筛选、份数、逐份、灰度和长／短边双面。讲义支持自定义行列、四种排列顺序、边框、页边距、间距、子页面尺寸，并可拖动位置及等比缩放。小册子支持左右装订、自动补白、分帖和正反面分开打印。预览和输出使用同一布局，也可存为 PDF；直接选择打印机可保留应用内设置，同时保留系统对话框入口。

本地完整性验证使用 3 份实际 PDF，覆盖 69 个连续修改状态、4,960 页比对：MuPDF 逐页比较普通保存与增量保存的文字和画面；PDFium 独立检查抽样页渲染；pypdf 遍历可达对象引用。范围包括文字及原生段落编辑、图片、矢量、OCR 文字、批注、表单、元数据、书签，以及页面插入、删除、排序、替换、旋转、裁剪、缩放、提取和撤销。这是对已测样本的验证，不代表任意 PDF 均无兼容问题。

96 MiB、300 页、1,000 个书签的本地基准中，修改一个书签标题只追加 **414 字节**、更新一个对象。序列化及内存组装约快 **3 倍**；该数字不含磁盘校验与刷盘，实际总耗时随文件和磁盘变化。

发布流程改为只构建、归档一次，由四个并行任务验证同一 ZIP，安装与更新检查单独并行。原先较慢的界面、作品放置和页面整理测试也拆开执行。最后发布阶段校验提交、运行编号及文件哈希，不再重复构建和执行整套测试。

实际调用 Microsoft Print to PDF 驱动验证：8 页小册子输出为 4 个页序正确的 A4 横向打印面，四页一面的灰度讲义输出为 2 个 A4 纵向打印面。独立像素检查验证了页面位置、颜色和物理尺寸，并据此修复系统对话框覆盖方向、驱动 DPI 不匹配导致打印缩小的问题。自动化还覆盖右侧装订、补白、手动背面、边框、间距、拖动与 PDF 输出。

增量文件会保留历史修订；需要清除旧内容或回收历史体积时，请使用完整重写。网络链接被阻止访问时标记为“无法确认”。打印采用渲染页面，默认 300 DPI，可选 150 / 600，并限制单页内存；不会改变原 PDF 中的矢量内容。实体打印机的双面进纸与驱动特有能力仍需设备验证。本版不宣称已完全覆盖 Acrobat 或 PDF-XChange 的全部功能。
