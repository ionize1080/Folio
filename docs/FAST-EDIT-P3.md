# RC1-P3 快速编辑预发布

本次围绕页面文字编辑改造。仍是预发布版本，不宣称覆盖 Acrobat 的全部编辑能力。

## 使用

点击“页面编辑”，再点击段落。普通横排、中英文固定框、90° 倍数旋转文字及基础竖排进入本地快速路径。输入、选区粗体/斜体、字体、字号、颜色和字距直接更新原页画布；使用原生输入框处理中文输入法。

暂停输入后，普通横排自动在独立排版进程计算精排候选。结果可用时出现“预览精排”，预览期间选择“保留快速排版”或“应用精排”后继续编辑。后台结果带段落 ID 与编辑版本，过期结果不会覆盖新输入。精排不成功时当前草稿仍可编辑。

“完成编辑”会生成实际 PDF 文本对象，随后“保存”写入文件。显示溢出、重叠提示与原文对照仍可用。格式面板新增横排、竖排向左换列、竖排向右换列选项。

## 算法与开销

- 按文字矩阵和字位判断基线方向、旋转及基础竖排，方向不同的对象分组处理。
- 沿阅读方向投影，建立“对象→行→段落”的局部连接。栏间空白、标题、勾选项、单元格和横线约束连接；原行边界存为显式换行。
- 几何连接先排序，每个对象只查询最近 32 个活动行/段落，避免对象两两比较。稠密或异常页面可能保守分段，不能将“闭合边界”等同于语义段落。
- 快速排版按当前段落字符与样式段线性扫描，测量缓存以字体、字号、字符为键。保留兼容的原字位；变化超出原字槽时在本段重排。未实现通用增量脏行树。
- 字体名称规范化并匹配同样式；命中同名系统字体时快速路径优先使用它。按需加载字体，已加载字体与字符宽度复用；不在每次按键时做轮廓相似度搜索。同名不意味着版本、轮廓和字宽完全相同，替代状态仍可查看。
- 本地预览画布只分配编辑区域，限制为 800 万像素。页面去字背景仅组合当前页；输入时不重写整本 PDF。遮挡检查在短暂空闲和提交时执行。
- 画布预览与导出的 PDF 使用同一套字符坐标、字体键、粗斜体和旋转参数，避免两套布局独立推导位置。

## 字体和边界

PDF 的粗体可能来自粗体字面，也可能来自填充加描边。本版本提取并保留两类来源；嵌入的常规字体没有粗斜体字面时，明确绘制合成粗体/斜体。选择常规样式但原字体本身为粗斜体且缺少常规字面时使用可用替代字体，并显示替代信息。

保留显式换行、空行与 UTF-16 选区。中英文标点避头尾处理为轻量规则，不是完整中文出版排版标准。基础竖排为字符逐个直立排列，尚无完整 OpenType 竖排替换、竖中横与混合方向嵌套。

阿拉伯文、希伯来文双向混排、复杂连字及任意倾斜角度尚不属于已验证快速编辑范围；不会自动转为横排保存。组合符号等复杂字形由既有精排路径处理，映射不完整时保留草稿。表格自动增长、多栏串接和特殊叠放继续使用既有排版路径。页面本身带旋转、非标准原点或 UserUnit 的限制仍然存在。

## 测试与发布

新增测试覆盖：碎片连接与栏边界；标题和勾选项分离；保留换行/空行；混合字号、粗斜体与选区继承；UTF-16；竖排命中；旋转后的实际 PDF 方向；失效字位拒绝导出；当前页去字背景；连续输入后台请求数量；精排预览取舍和实际保存回读。

性能测试记录 10,000 个对象的几何连接和 12,000 字符段落排版耗时；界面测试记录 15 次连续输入的各次耗时，要求不触发逐次原生排版。具体测量值来自测试机器，不承诺所有硬件上的固定延迟。

Windows 发布流水线必须通过全部单元、原生、浏览器、打包和实际 EXE 保存测试。发布包提供源码、Windows x64 便携包、验证记录与 SHA-256；不包含用户提供的 PDF。
