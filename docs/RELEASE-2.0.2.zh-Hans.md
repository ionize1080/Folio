# Folio PDF Studio 2.0.2

- 从固定 Chatbox 开源源码构建，与 Folio 共用一套 Electron，移除重复运行时。
- 移除空的“Folio Qwen”预设；API、模型和会话采用稳定用户目录，升级保留真实配置。
- 无额外模型 token 的本地进度提示；修复 AI 遮挡更多工具和未保存确认弹窗、刷新后审批图标不同步。
- 校准、留白、书签样式和目录识别直接调用已有本地引擎；仅复核歧义/低置信项。补齐图片坐标说明、分页读取、OCR/快照缓存，避免整树回传和反复查询。
- 在原 PDF MCP 源码基础上增加批量读取和原子批量编辑，共 62 个文件工具；源文件保护、失败回滚、分页和新路径检查。

- 重绘自动书签、AI 和重复图标；统一对齐、控件尺寸、中性选中态及菜单键盘导航，覆盖三种语言与明暗主题。仅自动审批图标标红。

真实 Qwen、桌面鼠标/键盘、10 份真实 PDF 样本已用于本地验收；Windows Actions 再执行源码构建、回归、真实 API、便携包和更新器验证后发布。详细结果及校验和随发布提供。未单独验证 Windows 10 21H1。

配置位置：`%APPDATA%/Folio/Chatbox`。首次升级从旧的版本目录复制，原目录保留用于回退。
