# Folio PDF Studio 1.6.0

[English](RELEASE-1.6.0.md) · [简体中文](RELEASE-1.6.0.zh-Hans.md) · **繁體中文**

本版預設使用英文，提供英文、簡體中文和繁體中文即時切換。

## 改進

- 頂部常駐地球圖示和語言名稱，首選項提供同一設定。支援語言自稱、鍵盤操作、焦點提示及明暗主題。
- 語言選擇儲存在本機。切換更新按鈕、提示、彈窗和狀態，不重新開啟文件，不重置未儲存的修改。
- 離線語言包覆蓋書籤規則、文字與影象編輯、表格、OCR、大檔案和更新提示。文件內容、名稱、輸入值和 OCR 校對不參與翻譯。
- 便攜版安裝器使用所選語言；更新視窗根據介面語言顯示本版對應發行說明，缺少對應版本時回退英文。
- README、文件索引和發行說明預設英文，提供簡體、繁體中文直接連結。
- 新增佔位符一致性、預設與回退行為、內容保護測試。實際 Windows EXE 驗收覆蓋語言記憶、彈窗覆蓋、鍵盤、不同視窗寬度和明暗主題，並繼續執行編輯迴歸。

## 升級

下載 `Folio-PDF-Studio-1.6.0-portable-win-x64.zip`，完整解壓後執行 `Folio.exe`。發行附件包含原始碼、驗收結果和 SHA-256 校驗值。已有語言選擇保留，尚未選擇的使用者預設進入英文介面。

安裝保持原程式目錄名稱，因此指向該路徑的快捷方式保持有效。設定位於使用者配置目錄。1.3 的舊安裝器不能在執行前被替換；如果此前點選安裝後退出未重啟，請完全關閉 Folio，將舊目錄改名備份，再把新解壓的 `Folio-PDF-Studio` 放回原路徑，啟動其中的 `Folio.exe`。

## 範圍與限制

本版提供三套完整介面語言包。其他語言需要完成翻譯審閱與介面驗收後才會加入選擇器。OCR 語言設定獨立，不擴充套件識別模型能力。Windows 原生對話方塊遵循系統語言，底層技術診斷可能保留原文。歷史發行說明保留當時的表述。

原有 PDF、字型和 OCR 邊界繼續見 README。Windows 自動化不能替代真實硬體、混合 DPI 和輸入法驗收。附件報告標識實際測試的原始碼、EXE 和應用包；不將舊版本透過記錄計作本版證據。
