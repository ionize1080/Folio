# Folio PDF Studio 2.6.0

修复黄金新闻第 2 页 Adrian Day 段落编辑报错及首字母遗漏。段落识别支持 Chromium 段落标签和单色 Type3 矢量字体，链接下划线不再误拆段落，允许保留原有的小幅字形越界。

打开文档后在空闲时逐页分析字体，持久复用字形评分、本机字体映射和浏览器字体处理结果。后台任务低优先级运行，编辑操作可抢占。原位文字改为批量写入，密集表格改为按空间位置查询。

本机验证覆盖 32 份文件、95 页，其中含 17 份固定哈希的公开文件：303 次编辑成功、136 次受限，完整性检查无失败，全部原文件保持不变。Actions 使用 6 路引擎回归、4 路公开样本和独立界面测试，并检查最终 Windows 发布包。详见[架构分析与测试报告](https://github.com/ionize1080/Folio/blob/v2.6.0/docs/EDITING-2.6.0.zh-Hans.md)。

尚未证明全面达到 Acrobat 水平。跨链接/复杂标签、交错覆盖绘制、特殊编码和部分复杂字形仍有限制；本版不包含自动跨页重排。
