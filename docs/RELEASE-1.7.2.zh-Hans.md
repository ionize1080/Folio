# Folio PDF Studio 1.7.2

本版重点保证已应用修改、预览与最终 PDF 一致。

- 追加 PDF 保留文字、表格、图像和 OCR 修改，包括同一会话先保存再追加；保存、追加和页面对比共用带版本校验的导出快照。
- 表格切换失败立即清空旧预览，迟到结果不能启用错误目标；保留网格以外的勾号等装饰，共用路径无法可靠分离时提示使用单元格文字编辑。
- 普通与流式保存均在替换前验证文件身份和 SHA-256，发现外部改写、替换或删除时提示另存副本或重开。
- 新文字超出原 PDF 裁剪时明确拒绝并保留草稿；补上引擎可能省略的原始裁剪追踪，防止预览有字、保存截字。
- 通用图像入口保留透视参数，过期替图读取不写入新选中的对象；三种适配模式的替图均可在保存 PDF 后冷重开再编辑。
- 编辑背景每张限制 6MP、单边 8192px；中性替图、调整及透视共享解码前尺寸保护。
- 目录原链接不能绕过重名、页眉或短标题疑点，OCR 与条目识别证据共同约束自动勾选；手动页码状态即时更新。
- 修复书签连续 Shift 多选、输入法组合输入守卫、模态标题、菜单焦点、键盘调栏宽、双侧栏联合预算、空规则名与 FitR 目标页尺寸。
- 源码包仅采用受控清单和明确运行资源，附逐文件哈希；新增 main/PR 验收及 quick/full 命令，更新修复工具的版本提示随配置变化。
