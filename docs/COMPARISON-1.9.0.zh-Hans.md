## 方法与覆盖

采用定页抽样，不代表整个目录、整份文件或全部段落通过。首轮 12 个页面定位问题，追加最终样本组覆盖 23 个代表页。每页至多尝试 8 个候选段落，分别替换和插入已有字符，必要时显式指定替代字体。成功要求：完整段落语义恰好出现一次、整页字符变化符合预期、编辑区域外像素不变、实际相邻页像素不变、保存后可重开、源文件哈希不变。保护跳过不算成功。

最终单次运行覆盖 16 个文件的 23 页：16 页替换与插入均通过，3 页仅替换通过，4 页未完成编辑验收。35 次成功编辑均完成保存重开、文字核对和编辑区外像素检查，34 次可检查的实际相邻页像素也保持不变。最终逐页结果和限制记录在 release 的 validation.json，样本覆盖如下：

## 桌面编辑流程与排版分析

下面是可见操作与排版行为的观察，不能据此断言商业软件的私有算法实现。竞品修改未保存覆盖源文件；本轮没有系统验证竞品保存往返。

| 维度 | Acrobat | PDF-XChange | Folio 1.9 |
| --- | --- | --- | --- |
| 进入编辑 | 编辑 PDF 后显示文本框，点入输入 | 主页富文本编辑，框选后进入输入 | 分析当前页后点选段落；保留/重排和字体替代信息可见 |
| Beyond SAEs 摘要 | 提示 LMRoman10-Regular 不可用，选择 Minion Pro 后整段重排 | Abstract 标题与正文合为大文本框，插入 test 后整块重排 | 标题与正文分开；嵌入字体优先，缺字替代单独提示，空间不足显示溢出 |
| 北京报告 | 特殊编码字体未完成有效输入，不判定成功 | 可以插入中文并改变后续换行，可访问性文字仍有编码乱码 | 因自定义编码无法建立可靠中文语义基准，本轮跳过语义编辑验收；未据此认证界面的编辑拦截行为 |

| 光标与输入 | 桌面直接输入、撤销 | 桌面直接输入、撤销 | 按渲染字形导航，短行/空行保留横坐标；一次输入法提交形成一次撤销 |
| 保存后续编 | 本轮未系统验证 | 本轮未系统验证 | 软/硬换行、字体映射、连字符、中文语义及扩框后二次编辑有回归 |

Folio 分段依据基线、字号、栏间距、障碍、缩进与字体样式。本轮修复中文句末双字缩进没有分段、小型大写标题连入正文，以及侧栏短行干扰导致左右栏合并。USTB 第 3 页跨栏段落从 9 降至 0。论文链接边界的 `(SAEs) explain` 几何空格也得到恢复。中文标点的合法半字宽负字距按字号与实际字形宽度校验，不再被固定下限误拒绝；无穷值、越界和负字形前进距离仍被拒绝。

实际搜狗输入法验证：在中文年报段落中输入拼音并从候选窗选择“测试”，字符数由 266 增为 268，一次撤销回到 266；组词期间 Escape 仅关闭候选，编辑状态保持。结果只覆盖本机搜狗，其他输入法未逐一认证。浏览器另测合成事件顺序、重复最终 input 和快捷键边界。

字体面板增加整段/选区/后续输入的作用范围、搜索空结果提示和窄窗口滚动布局，改善暗色状态文字；异步加载期间防止字体选择被迟到的初始化结果覆盖。界面验证覆盖 1024×700 字体面板和 800×600 英文暗色书签菜单。Acrobat 也实际打开了 Folio 保存的中文年报页面，正文和表格正常显示。

字体替代会改变字宽和换行，本版不承诺替代后的像素等价。复杂公式、竖排、受保护共享语义和异常字库仍存在限制。四个未完成编辑验收的代表页分别为北京报告的自定义编码、HSK 的无文本层扫描页、French 的共享文字组，以及 W3C 的完整 MCID 范围保护。USTB 第 3 页和 DECADE 第 2 页仅替换通过，所试插入受公式、邻文遮挡或字位映射限制。

## 书签差距与本版实现

PDF-XChange 本机界面提供从文本/每 N 页/表格/高亮生成、标题处理、缩放、目标转换、查找替换、排序、校验、合并、生成目录、链接、页面排序和 HTML/TXT 导出。Folio 已有规则生成、文本目录导入、前后缀/正则/编号、层级排序、去重、目标校准、精细坐标、样式和 JSON/TXT 交换。

本版补齐并验证以下工作流：

- 八种缩放：继承、固定比例、适合页面、宽度、高度、可见内容、可见内容宽度和可见内容高度。支持选中/子树/全部/筛选范围、差异预览、参数验证、撤销重做及 PDF 保存重开。固定比例 8.33%–6400%；原始本地/命名目标须显式转换，外部及未解析目标跳过并计数。
- Unicode 大小写转换、编号与字面前后缀；预览与应用一致，标题中的 `$` 等字符不被当作替换指令。
- 复制/剪切后粘贴为子项或同级前后，保留层级；保护循环粘贴及失效剪切来源；展开/折叠所选子树。
- 独立 HTML 目录保留层级、颜色、粗斜体、中文标题和相对 PDF 页码链接，正确转义标题，外部动作只显示文字。与同名 PDF 放在一起即可使用。
- 修复筛选后的默认范围、缩放参数坐标语义、旧预览失效、应用点击被 change 事件吞掉及文档标题被误翻译。优化菜单分组、禁用状态与窄窗口布局。

仍未覆盖：完整动作链编辑、修改外部 GoToR/GoToE 缩放、从书签生成 PDF 目录页、按书签重排页面、从高亮生成、跨文档剪贴板和 PDF-XChange 专用交换格式。跨文档结构转移可用 JSON 导出/导入。没有用菜单占位表示功能已经完成。

## 验证与复现

快速验收包含 228 项 JavaScript 检查和 7 项 Python 发布/归档检查。原生检查覆盖共享 Form、裁切、语义、CFF/OTTO/连字、旋转页、图片、UTF-16、字体缓存和连续保存；浏览器覆盖编辑键盘、字体面板、目录导入、页面校准和 10 组书签完整工作流。书签细节见 [BOOKMARK-VALIDATION-1.9.0.md](BOOKMARK-VALIDATION-1.9.0.md)。最终检查数量及 EXE/app.asar 哈希记录在发布附件。

锁定依赖安装后执行 `node scripts/acceptance.mjs full`，可设置 `FOLIO_PYTHON`、`FOLIO_CHROMIUM`、`FOLIO_CORPUS`。23 页复测使用 `tests/corpus-editing-followup-v190.py`；连续重开使用 `tests/reopen-editing-v190.py`；安装包使用 `tests/packaged-corpus-v190.cjs`，指定 `FOLIO_EXE` 和 `FOLIO_CORPUS`。独立运行嵌入式 Python 脚本应显式加入 tests 路径；统一验收入口已自动处理。
