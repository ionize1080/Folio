# Folio PDF Studio 2.8.0

保留并完善现代界面：功能区、三栏书签规则编辑器、OCR 校对工作区和页面组织器统一了视觉风格，支持明暗主题。

- **连续打开文件更稳定**：新文件在后台准备好第一页后，才切入同一个窗口。加载期间原文档保持可用。标签页保留页码、选区、撤销记录和未保存修改；重复打开同一路径会回到原标签。密码对话框可正常操作，加载失败或取消会保留原文档。
- **功能区切换更跟手**：各分类控件只创建一次，切换时复用，不再反复拆装，也不会改变文档显示区域。键盘切换、收起状态和按钮可用状态保持一致。
- **书签工作区**：未变化的书签行复用；调整目标坐标只更新定位标记；规则预览缓存文字提取结果并自动刷新。修复颜色预设不标记修改、连续改名残留重复行等问题。
- **页面组织**：支持键盘排序、空格预览、缩略图缩放、框选以及拖入 PDF 和图片。旋转复用缩略图缓存，关闭时清理待完成绘制。页面调整可以直接应用到当前文档，之后再保存。
- **性能与可靠性**：滚动只检索附近页面，减少重复激活和文字布局复制；OCR 缓存清理保护正在使用或写入的结果。Electron 更新至 44.11.3，并修复锁定依赖中的已知问题。

本机 Windows 小型 PDF 样本实测：已打开文档切换中位耗时约 **4–8 ms**；功能区点击处理 P95 约 **0.5 ms**，下一帧约 **13 ms**；三种语言共 96 次切换中，功能控件重复拆装为 **0 次**。这不是所有文件的速度承诺，首次打开仍受文件复杂度、存储、解密及渲染影响。

发布须通过同一提交的 GitHub Actions 并行验证，包括原生编辑、OCR、保存完整性、打印、AI 工作流和现代界面。最终便携包另行通过四组并行测试，共 **29 个验收脚本**，并校验文件哈希及测试来源。发布附件包含便携包、源码、验收报告和 SHA-256 校验值。
