# Folio 2.1.0 的真实模型与文档验收

正式发布包另在 Windows Actions 上完成 12 个真实 Qwen 场景，结果和程序哈希见[发布验证](VALIDATION.md)。以下次数、耗时和像素数据取自本地运行。

本地验收使用 Windows x64、提交 `ecbfaea` 和 Chatbox 中配置的 `qwen3.8-flash`。由模型通过真实 API 选择工具，调用经过 Folio 的 MCP 服务并作用在打开的文档上。下表是一次完整运行。MCP 次数包含读取和核对，耗时包含模型响应及本地处理。相同要求在另一轮运行中可能选择不同的工具。

| 用户任务 | MCP 调用 | 耗时 | 独立核对 |
| --- | ---: | ---: | --- |
| 校准书签目标 | 2 | 8.9 秒 | 6 个目标逐一落在对应页标题区 |
| 给书签再加 3 mm 留白 | 2 | 5.1 秒 | 比较每个目标前后的 PDF 坐标 |
| 顶层书签加粗 | 2 | 7.8 秒 | 核对子节点、颜色、斜体和目标 |
| 读取上半页图像 | 1 | 3.7 秒 | 实际裁剪范围、模型读出的标题 |

## 从调用记录发现的问题

- **生成书签时反复查询参数。** 在先前一轮中，模型先后查询 `generate`、`folio_bookmarks` 和完整操作名。工具现直接说明规则结构，并识别简写。相同任务的两次运行分别用了 8 次和 3 次 MCP 调用，文字回包从 7,844 字节降至 1,142 字节。
- **总结时传回了大量逐行坐标。** 增加按页摘录、字面检索和带覆盖范围的概要后，两轮合计文字回包从 38,198 字节降至 23,505 字节。后一轮模型额外检索了附录，用时 37.7 秒，前一轮为 28.7 秒。精确坐标仍可按需查询。
- **模型需要看到当前选择和真实像素。** MCP 返回活动页、文字选区、书签、选中对象及其坐标，同时支持按文档 ID 读取后台标签。另一次测试直接选中 PDF 正文 Chapter 1 和页面上的两个文字对象，逐项核对了 MCP 返回的值。
- **全分辨率反复发图成本较高。** 单独的彩色校样测试使用 2400 × 1600 原图。Qwen 先看两张 640 × 427 的全图，再检查 1200 × 142 和 923 × 164 的局部预览。最终采用暖色滤镜、饱和度 −8 和五点 RGB 曲线。导出后核实图片仍为 2400 × 1600，平均红通道增加 14.42、蓝通道降低 10.90，相邻页渲染像素完全一致。

## 页面与保存结果

扫描样本由公开标准的摘要页栅格化并降低对比度得到。增强后重开的 PDF 中，亮度第 99.5 与第 0.5 百分位之差由 73 增至 195，OCR 层可检索 AES。局部替换测试使用独立的原始扫描页，修改 68,310 个像素，指定区域外逐像素一致。标准原件取自 [NIST FIPS 197 的发布页](https://csrc.nist.gov/pubs/fips/197/final)。

文件切换另用一份 315 页、4,000 个书签的测试 PDF。单次冷打开至编辑器就绪用时 1.03 秒，当时创建 27 个书签行和 1 个可见页画布。与 NIST 标准来回切换 30 次，主进程确认切换的中位数为 4.4 ms，P95 为 6.4 ms。该计时在显示器绘制前结束。

真实服务验收覆盖 Qwen 看图、调色、增强、替换、OCR 和矢量生成。独立的像素生图服务需要在 Chatbox 图像创作中选择相应模型，独立服务的线上生成与局部重绘仍待实测。
