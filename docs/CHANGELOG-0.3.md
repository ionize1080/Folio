# Folio PDF Studio 0.3.0

Windows 11 x64 便携版 · 2026-09-11

| 改进 | 实现与入口 |
|---|---|
| 放大清晰度 | 按可见区域高清分块重绘，匹配屏幕像素倍率，最高 1200%。PNG 单独高清导出。 |
| 缩放闪屏 | 新画面绘制完成后替换旧画面，取消过期渲染任务；偏好中新增关闭硬件加速的显卡兼容模式，重启生效。 |
| 批量修改详情 | 原值→操作/换算→结果，完整规则和跳转参数；可导出全部 JSON 修改报告。 |
| 存量书签视觉留白 | 顶部「留白」及书签右键；mm/pt、预设、处理范围、旋转方向换算、修改前后页面预览、跳过原因、整批撤销。 |
| 覆盖保存 | 同目录临时写入和刷新；Windows 使用 ReplaceFileW 替换已有文件，区分原件保护、权限和占用错误。 |
| 内容编辑 | 顶部「编辑内容」选择实际文字/路径对象；文字、字号、颜色、变换矩阵、路径节点、填充/描边、新增/删除。复杂裁剪、嵌套或特殊模式只读。 |
| 离线 OCR | 内置 PP-OCRv6 small、PP-OCRv5 mobile 与方向分类模型，CPU 推理；范围、分辨率、局部区域、跳过已有文字、可停止。 |
| OCR 原位校对 | 置信度、修改文字及四角 PDF 坐标、排除条目、原位预览开关；输出隐藏文字层，保留原扫描图像。 |
| 统一文档状态 | 书签、对象和 OCR 共用保存、撤销重做、恢复快照和保存摘要；保留 v0.2 阅读和多级书签规则。 |

文字替换使用基于 Noto Sans SC 的内置字体，可能改变原有字形；不支持的字符会明确报错。该字体处理了 Unicode 别名映射，避免同字形字符造成中文搜索失配。OCR 是按行定位的双层 PDF，不是扫描图像的可重排 Word 化编辑。

测试：18 项核心测试、19 项旧界面回归、8 项新界面流程、7 项原生集成检查。参考扫描页识别 31 行，输出可搜索，测试页渲染像素与原扫描页一致。实际报告随包提供。

运行：完整解压后双击 Folio.exe，保留 resources、locales 和 DLL，无需另外安装 Python/Node/OCR 模型。EXE 不能单独移动。

尚未进行真实 Windows 11 启动、原生覆盖保存、显卡驱动与多显示器 DPI 验收。程序未签名；当前内容编辑是基础对象级，不含商业软件级段落重排、复杂嵌套编辑、智能表格结构重建或 GPU OCR。
