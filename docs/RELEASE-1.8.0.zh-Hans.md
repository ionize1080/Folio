# Folio PDF Studio 1.8.0

本版支持一键跳过全部 OCR 待校对建议，修复目录漏页和书签层级问题，并统一更换折页式图标。

- 新增“跳过全部待校对并应用”：保留识别文字、原置信度及未确认状态，不必逐条处理数千条建议。缺字检查仍保留；应用后可撤销，保存 PDF 后才写入文件。
- 改进带空格的点引导线、西班牙语目录标题、字母附录编号、稀疏目录尾页，以及通栏摘要下方的偏心双栏目录。
- “篇／部分”标题成为数字章节的父级；同页后半部分的图表或示例索引不再混入主目录。修复 xcolor 手册第 3 页目录遗漏。
- 候选目录页增加勾选框，便于补页、排除误选页后重新提取。
- 修复 Type1 字体的 PDF 编码覆盖和子集连字：编辑相邻文字时，原文 ff 连字不再少字。加入普通排版、快速排版及保存重开的回归检查。
- 工具栏、欢迎页、窗口和 Windows 程序资源统一使用原创折页图标，并提供小尺寸图标。

## 测试范围

新下载 CTAN 与 R 项目的 20 份公开 PDF，另检查本地 29 份不重复 PDF。覆盖目录提取、层级、真实页面正文编辑、OCR 可搜索文字层、书签保存重开、原生引擎和浏览器交互。4 份公开手册没有印刷目录，不生成目录书签属于预期。最终结果及程序哈希见 validation 附件；不附带第三方样本或私人文档内容。

自动勾选数量不代表准确率。扫描年鉴抽查 21 页目录／检测页与 12 页正文，并非逐页遍历全书；模糊目标仍需核对。无法解析的原字体需要明确选择替代字体，纯扫描页需先 OCR 才能编辑其文字。

## 安装

完整解压 Windows x64 portable 压缩包，运行 `Folio.exe`，保留所有资源目录和 DLL。支持英文、简体中文和繁体中文。保留供旧版使用的 update-repair 修复包，升级说明参见 1.6.2 发布说明。
