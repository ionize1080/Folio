# Folio PDF Studio 1.0 RC1 更新说明

2026-09-15。基于 0.9.0 开发。RC1 为可供 Windows 实机验收的测试构建。

## 书签与日常操作

- 自动书签使用通用的局部基线、字高、行距与重叠检查，提供自动、严格、宽松和手动容差。没有引入行业分类专用列或词语规则；旧的行业快捷预设入口改为可编辑的通用层级示例。
- 修复跨行标题连接时丢失文字片段坐标，以及正文提及被优先选为目标的问题。校准界面显示推荐依据、实际匹配片段，并可保留原目标；刷新时尽量保留人工选择。
- 范围选择置于自动书签窗口顶部，记住同一文档的上次范围。当前页测试与范围预览分开，改变范围或规则后旧结果不能应用。
- 偏好设置新增默认留白单位 mm/pt；生成、校准和跳转留白遵循首选项，下拉仍可临时切换，反复切换不累计舍入。
- 支持拖入 PDF 或 Folio 工程，沿用统一打开流程和未保存更改保护；多文件拖入时选择其中一个。
- 新增正则拆分书签：同级分隔、独立规则提取、父子层级；各规则始终读取完整原题。包括子项迁移、目标继承、规则保存/导入/导出、超时控制、预览与整批撤销。

## 页面编辑与校对

- 编辑入口检查异步结果所属文档和页面，避免切页后使用过期分析。段落重组改进列表符号和 AI 框边缘文字归属。
- 可验证的 Type1 子集按原字形和字符映射重建可排版字体；不伪造字体覆盖，缺失字符仍单独提示。
- 字体列表优先显示本地化名称，提供中文别名搜索、字体真实样例，以及 TTC 集合中各字面的独立选择。
- 新增同页独立文本框连接、链顺序调整、断开入口、光标拆段预览与段落合并。人工结构可保存、锁定或恢复自动结果，随 Folio 工程和恢复草稿保存。
- 格式刷区分字符、段落和全部；段落设置包含行距、段前后距、缩进、对齐。
- 新增全页输出对照：重新解析当前待保存 PDF，支持并排、叠加、像素变化网格及点击定位。
- 简单有线表格支持行列插入/删除、列宽输入或拖动、矩形合并/拆开、文字修改、实际排版预览和整批撤销。结构编辑保持总范围，空间不足会提示；复杂边框和不可靠对象映射保留原内容。
- 原生图片实例支持替换、适配方式与可恢复裁切。原始资源不被修改，工程保留源图；共享图片的其他实例不受影响。
- OCR 校对新增连续/单页切换、可见附近页面渲染、当前编辑锁定、疑点跳转、确认并下一处、暂缓、键盘操作和断点恢复。校对草稿单独持久化，不因关闭面板丢失。

## 使用入口

| 功能 | 入口 |
|---|---|
| 默认留白单位 | 偏好 → 默认留白单位 |
| 正则拆分 | 选择书签 → 整理 / 右键 → 正则拆分书签 |
| 连续校对 | OCR → 连续滚动；Ctrl+Enter 确认并下一处 |
| 文本框接续与结构 | 页面编辑 → 格式 → 结构与文本链 |
| 段落格式刷 | 页面编辑 → 格式 → 格式刷范围 |
| 全页对照 | 更多工具 → 全页输出对照；或页面编辑 → 格式 |
| 表格结构 | 更多工具 → 表格结构 |
| 图片替换/裁切 | 编辑对象 → 选择图片 |

“完成编辑”和“应用修改”更新当前文档，仍需保存 PDF。需要保留结构纠正、原图和可继续调整的编辑状态时保存 Folio 工程。
