# Folio PDF Studio

[English](README.md) · **简体中文** · [繁體中文](README.zh-Hant.md)

Folio PDF Studio 2.3.0 是 Windows x64 上的本地 PDF 工作台。可以同时打开多份文档，整理长篇书签、编辑页面文字与图片，或把扫描件处理成可检索 PDF。需要模型协助时，从工具栏打开 Chatbox。

[下载 Windows x64 便携包](https://github.com/ionize1080/Folio/releases/download/v2.3.0/Folio-PDF-Studio-2.3.0-portable-win-x64.zip) · [本版说明](docs/RELEASE-2.3.0.zh-Hans.md) · [AI 使用指南](docs/AI.md) · [文档索引](docs/README.md)

## 打开第一组文件

1. 下载便携 ZIP，解压整个文件夹后运行 `Folio.exe`。保留同目录的 DLL、`resources` 和 `locales`。完整便携包已包含本地运行时、字体和 OCR 模型。
2. 在「打开」对话框中多选 PDF 或 `.folio` 工程，也可以一起拖入窗口。用 Ctrl+Tab / Ctrl+Shift+Tab 切换标签，用 Ctrl+W 或标签上的关闭按钮关闭当前文件。各文件独立保存阅读位置、选区和撤销记录。
3. 编辑后先应用，再按 Ctrl+S 写入当前 PDF。原件保护默认首次另存副本。关闭含未保存修改的普通 PDF 时，可选择保存、放弃或取消。需要保留段落结构及 OCR 校对进度时，在「更多工具 → 导入 / 导出」保存 `.folio` 工程。
4. 打开「首选项」设置外观。明暗模式可跟随系统，内置钴蓝、青瓷、琥珀、桑葚、石墨五套配色，也可以自选重点色。界面语言默认跟随 Windows，之前手动选择的语言优先。

同一发布页也提供[源码包](https://github.com/ionize1080/Folio/releases/download/v2.3.0/Folio-PDF-Studio-2.3.0-source.zip)、[校验值](https://github.com/ionize1080/Folio/releases/download/v2.3.0/Folio-PDF-Studio-2.3.0-SHA256.txt)和[验收报告](https://github.com/ionize1080/Folio/releases/download/v2.3.0/Folio-PDF-Studio-2.3.0-validation.json)。检查更新可从「关于与使用说明 → 检查更新」进入。

## 用 AI 阅读与编辑

- **对照文档**。选中一段正文或书签，问“这段话是什么意思？另一份打开的文件怎样表述？请分别标注页码。”Chatbox 可以读取当前页和选区，也可以按文件名查阅后台标签。
- **改图或增强扫描件**。选中图片，要求先预览暖色滤镜或 RGB 曲线，再用局部细节复核。换图时可以选本地图片并指定区域。需要可搜索的扫描件时，同时要求加入本地 OCR 文字层。
- **插入流程图**。说明要放在哪页、有哪些节点、怎样连接。保存并重开 PDF 后，仍可修改 Folio 嵌入的 SVG 元素或流程图节点。
- **模型配置**。在 Chatbox 设置中配置服务商和模型。预览像素需要支持视觉输入的模型。使用生成图片或局部重绘时，还需在 Chatbox 图像创作中选择出图模型。独立出图服务的线上效果仍待验证。

## 已实现功能

下表列出阅读、书签、页面编辑和 OCR 的常用能力。对应的文件范围和实测数据见[发布验收](docs/VALIDATION.md)。

### 1. 阅读、定位与日常文档操作

- PDF 阅读、缩放、适合页面/宽度、连续浏览、缩略图与视图前进/返回。
- 正文搜索、文字选择与复制、书签导航；可收起的书签侧栏和属性面板，明暗主题。
- 页面与高倍缩放瓦片按需渲染，使用缓存预算、缩放锚点和过期渲染取消降低长文档开销。
- 多文件打开时，每份文档进入各自的标签。切换文档后可以继续上一次阅读或编辑。
- 基础批注、指定页面旋转、页面提取、末尾追加另一 PDF、当前页 PNG 导出与文档属性编辑。
- 加密文档的密码处理；通过 qpdf/pikepdf 导出无密码副本，错误密码可重试，取消不写文件。

**页面工具的范围：**提取以原始文档为基础，不包含尚未另存的修改，也不复制整本书签树；追加 PDF 前先保存当前编辑，追加文件的书签不自动合并。PNG 导出以页面画布为基础，未保存批注应先保存并重新打开后再导出。

**大文件工作区：**超过 768 MiB 的 PDF 自动进入独立通道，上限 8 GiB，支持按页阅读、跳页/缩放、书签增删改/撤销、正则自动书签预览追加及另存。当前不提供连续滚动、正文选区/全文搜索、页面编辑、OCR、工程或自动草稿恢复；关闭后回到普通会话。大于 4 GiB 的稀疏样本验证了偏移处理，尚不代表数 GB 真实年鉴的吞吐和内存验收。

### 2. 书签创建、批量编辑与自动生成

书签是核心工作流，**自动书签入口常驻主工具栏**。

| 能力 | 当前实现 |
| --- | --- |
| 树形编辑 | 新增同级/子项、改名、删除、多选、剪切/复制/粘贴、拖动排序、跨层移动、升降级、展开/折叠 |
| 属性与目标 | 批改粗体、斜体、颜色，以及可编辑目标的页码、坐标和缩放；保留并核对原始动作来源 |
| 筛选 | 标题文本或正则、大小写选项、物理页码；可选择真正匹配项并批量处理，祖先路径用于保持上下文 |
| 批量规则 | 查找替换、目标参数调整、修改前后详情预览、报告导出与整批撤销 |
| 自动生成 | 自定义多层级规则、捕获组标题、文字来源选择、当前页测试、页范围扫描预览；支持字号、目录文本和页间隔等入口 |
| 文字重组 | 同行片段拼接与可调基线容差，可选相邻跨行标题合并；提供命中、忽略、冲突与缺少父级诊断 |
| 插入与去重 | 根层追加、替换、插入所选前后或作为子项；生成时跳过重复匹配，整理时按标题、页码及目标位置容差去重 |
| 正则拆分 | 同级分隔、独立规则提取和父子层级拆分；规则读取完整原题，支持预览、子项迁移及目标继承 |
| 目标校准 | 在页面文字中定位候选并核对匹配片段，允许保留人工选择及原目标 |
| 跳转留白 | 按视觉留白调整顶部位置，支持 mm/pt、所选/所选及子项/全部范围，预览跳转前后差异 |
| 规则记忆 | 按操作与文档恢复参数，最近规则、命名收藏及导入/导出；恢复规则后重新计算预览 |
| 交换格式 | 导入/导出 Folio JSON 和目录 TXT；未实现 PDF-XChange 专有书签交换格式 |

坐标、留白与页范围在预览中核对后应用。跨文件导入不会照搬原始动作字典：可解析本地目标转为显式目标，不可解析动作会提示并回退定位，不能承诺跨文件动作完全等价。

### 3. 页面内段落编辑与字体处理

- 直接在阅读区点击段落编辑，支持输入、退格、拖选、复制粘贴及新建文字；输入法组合阶段保留草稿。
- 支持字符范围的字体、字号、粗斜体、颜色，以及段落对齐、行距、段前后距、缩进和格式刷。
- 字体列表按文档、内置、系统和最近使用组织，提供本地化名称、别名搜索、真实样例与 TTC 字面选择。
- 保留原始字符原点、基线和边界。满足条件的小修改尝试保持原字位；需要重新布局时使用 MuPDF Story，并明确进入段落重排。
- 对单对象、单行、等字符数、已有编码且不增宽等受限情形，支持保持原字体资源的局部纠错；不满足条件时采用内容片段路径。
- 支持段落拆分、合并、人工结构锁定，同页文本框连接、顺序调整和断开，以及同一文本流内的分栏续排。
- 文本框支持位置、尺寸、固定范围和扩展方向设置；碰撞、溢出和页外内容默认仅通知，可继续输入、选择、撤销和保存，详情按需展开；单元格默认保持边界，扩展由用户明确选择。
- 提供段落原文对照、字体替代明细，以及全页并排、叠加和像素变化网格对照。

支持的局部修改会沿用原字体和字形位置。复杂段落可能需要重新排版，保存前可用全页对照检查。

现有字体匹配使用覆盖、轮廓、形状和字宽信息。**未嵌入字体解析与混合字体保真仍存在已知问题**，并非任意原字体均能无损续写。

### 4. 图片、对象与简单表格

- 图片支持亮度/对比度、直方图与色阶、曲线、模糊、锐化、扫描增强和原图对照。
- 提供文字、路径等对象的受限编辑入口；图片实例可替换、设置适配方式和可恢复裁切，保留源图供工程续编。
- 简单有线表格支持单元格文字、行高联动、行列插入/删除、列宽调整、矩形合并/拆分、排版预览及撤销。
- 表格可导出 CSV 和 XLSX。XLSX 单元格按文本写入，保留前导零、长编号、日期原文和合并范围；CSV 处理引号、换行及易被解释为公式的开头。
- 表格结构调整约束在当前区域内，空间不足或对象映射不可靠时提示或保留原内容。复杂无框线、倾斜、嵌套及跨页表格不属于已完整支持范围。

### 5. 离线 OCR、校对与双层 PDF

| 环节 | 当前实现 |
| --- | --- |
| 识别引擎 | RapidOCR + ONNX Runtime CPU；提供 PP-OCRv6 small 和 PP-OCRv5 mobile 配置 |
| 范围与资源 | 指定页范围或框选局部区域；180/240/300 DPI；自动、低占用、高性能和自定义并行页数/线程/文字行批量 |
| 诊断与方向 | 保留检测框、低分/空结果和过滤诊断；疑难框提供 0°/180°候选，穿越表格线等疑点交人工确认 |
| 调度 | 独立 OCR 工作者、逐页进度、停止保留结果，以及相同文档和设置的已完成页续做 |
| 跳过策略 | 依据已有文字覆盖判断是否跳过，或选择“任意已有文字”的旧策略；局部区域有独立处理逻辑 |
| 校对 | 单页/连续滚动模式，文字与页面双向定位、疑点跳转、确认下一处、暂缓、人工修改与校对草稿恢复 |
| 语言与字形 | 简中、繁中、英文等校对提示选项；保留其他识别文字；可保留原结果或转换简繁字形 |
| 输出 | 应用校对结果生成可搜索、可复制的隐藏文字层，保留扫描图像；提供文字/识别框预览 |
| 重复应用 | 新建 OCR 层带 Folio 标识，重新打开后可替换已知 Folio 层；不会自动删除其他软件产生的隐藏文字层 |

语言勾选用于校对提示，**不扩展模型本身的语言能力**。字形转换发生在识别之后，原始识别文字和引擎置信度仍保留。修改隐藏 OCR 层不会直接修改扫描图上的可见文字。

可在框选区域识别，逐项比较疑难文字框的方向候选，再确认文字和位置。

### 6. 保存、工程、撤销与恢复

- 原始 PDF 作为会话基线保存，书签、旋转、批注、OCR 和内容修改作为独立状态参与合成。
- `.folio` v2 使用 ZIP STORE 容器，包含原 PDF、状态、内容资产及哈希清单；支持读取旧版 v1 工程，保存为 v2 后旧版程序不能读取。
- 大型 OCR/内容片段通过不可变版本引用参与历史，减少撤销记录中的重复序列化；当前编辑与文档操作分别提供撤销/重做。
- 工程编解码放到 Worker，桌面保存按块传输；写入同目录临时文件并刷盘后替换目标，失败时保护原目标内容。
- IndexedDB 保存按会话区分的恢复草稿，源文档和碎片去重并检查完整性；可选择、恢复或删除草稿。
- 损坏工程、资产缺失或恢复校验失败会停止切换/恢复；配额失败保留上一次完整快照。

工程保存原始内容、编辑状态和非阻断提示，适合续编。完成编辑仅生成修改页预览，保存时合成完整 PDF。普通 PDF 输出不保证重新打开后还能恢复同一段落编辑模型；普通编辑和保留历史的工程也不是安全涂黑。

## 技术与验证

Folio 使用 PDF.js 渲染页面，通过本地原生引擎处理对象、排版和 OCR。Chatbox 与 Folio 共用 Electron 运行时，文档修改按文件 ID 和修订号路由到对应编辑器。详见[架构与数据流](docs/ARCHITECTURE.md)。

Windows 发布任务通过了 12 个真实 Qwen 场景，并验证打包程序、多文档切换和发布 ZIP 升级。结果包含 2400 × 1600 彩色校样、扫描页 OCR、局部替图以及流程图重开编辑。[实测分析](docs/MCP-2.3.0-validation.zh-Hans.md) · [GitHub Actions](https://github.com/ionize1080/Folio/actions/runs/41994404438)

## 已知问题与适用边界

以下涉及 65 页和 45 种字体的数字来自历史 P6 编辑样本。本版独立验收范围见[验证说明](docs/VALIDATION.md)。[P6 编辑审计](docs/RC1-P6-editor-audit.md)

| 问题 | 已确认现象 / 边界 |
| --- | --- |
| 重开后的段落拆分 | 65 个最终文件中，58 页的目标仍在单个编辑块内，GNU/RFC/论文/Unicode 的 7 页目标被拆成多个块；文字保留，连续编辑体验仍需改善 |
| 复杂字形和方向 | 5 个混排用例涉及旋转方向或复杂字符合成粗斜体，保留草稿并提示使用支持的方向或真实字体 |
| 空白与换行 | 65 页中保留词间空白的完整目标检查通过 51 页，保留换行的逐字检查通过 48 页；文本搜索成功不等于代码格式保真 |
| 原样保持 | 43/65 个最终样本没有超过 1 pt 的未改字符移动；放不下的局部插入和扩写仍会重排，不能保证任意修改都保持全部字位 |
| 特殊字体与结构 | Type3、不能核验的字符编码/阅读顺序和非 1 UserUnit 等仍受限；保留原对象并解释原因 |
| 首次编辑与字体推荐 | 缓存主要改善重复请求和编辑后复用，首次页面分析及冷字体推荐仍需时间；未将 45 字体结果外推为千字体保证 |
| OCR 完整性 | 可能漏字、过滤低分结果或跨格合并。请对照扫描图复核。 |

几何通知非阻断，内容归属、字位映射或字体覆盖无法确认时仍保留草稿并拒绝不可靠写回。页外文字可以继续编辑，导出仍受原纸张大小裁切。

其他当前边界：

- 同页文本框连接和同一文本流分栏已实现；跨页文章级自动续排、任意图文绕排仍未完成。
- 页面布局模型提供候选区域，不能替代完整语义结构；公式结构编辑、全文 DOCX/HTML/Markdown 结构化导出尚未实现。
- Folio 尚无完整的交互式表单、安全涂黑和签名界面；文件式 PDF MCP 提供对应上游工具，输出应另存并复核。PDF-XChange 专有书签格式仍未实现。对含签名 PDF 的重写可能影响原签名有效性。
- 隐藏 OCR 层的校对不等于扫描图像可见文字编辑；其他来源的文字层不会被无条件删除。
- Windows 自动化验证已通过，但真实中文输入法、混合 DPI 及所有 Windows 10/11 硬件组合未全部覆盖。
