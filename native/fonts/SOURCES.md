# Font provenance

Noto Sans SC from https://github.com/google/fonts/tree/main/ofl/notosanssc, SIL OFL 1.1 (OFL.txt).
The variable source is instantiated at weight 400. Shared glyph aliases are split into distinct glyph IDs for unambiguous PDFium ToUnicode output; the derived font is named Folio Sans Native. Original copyright records remain. See scripts/normalize-font.py. The internal asset filename is NotoSansSC.ttf.
